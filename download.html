签名软件源

通过 APT 软件源安装

适用于 Ubuntu 24.04（noble）amd64。

你是第一次使用吗？

首次安装需配置独立签名密钥与软件源。复制命令后，在终端执行。

也可在设置客户端搜索「检查更新」，按提示下载并更新。

完整安装说明与密钥核验 ↗
在终端执行
(
set -eu
. /etc/os-release
if [ "$ID" != ubuntu ] || [ "$VERSION_ID" != 24.04 ] || [ "$(dpkg --print-architecture)" != amd64 ]; then
  echo '此软件源仅适用于 Ubuntu 24.04 amd64，请参阅源码构建说明。' >&2
  exit 1
fi
sudo install -d -m 0755 /usr/share/keyrings
key_file=$(mktemp)
trap 'rm -f "$key_file"' EXIT
curl -fsSL https://sunshine134679.github.io/fcitx5-linux-pinyin-input-method/apt/modernime-archive-keyring.gpg -o "$key_file"
sudo install -m 0644 "$key_file" /usr/share/keyrings/modernime-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/modernime.sources >/dev/null <<'REPO'
Types: deb
URIs: https://sunshine134679.github.io/fcitx5-linux-pinyin-input-method/apt
Suites: noble
Components: main
Architectures: amd64
Signed-By: /usr/share/keyrings/modernime-archive-keyring.gpg
REPO
sudo apt update
sudo apt install modernime
)

以前用源码或便携包安装？请先检查安装渠道，再决定是否切换软件源。

也可以下载安装包

在 GitHub Releases 选择与你的系统匹配的 DEB、RPM 或 Linux x86_64 便携归档。版本与可用文件以发行页为准。

便携归档要求 glibc ≥ 2.34 及匹配运行库；其他架构请选择源码构建。

遇到启用问题？
  1. 1

    打开设置客户端

    在应用菜单搜索「ModernIME」。也可在终端运行 modernime-settings。

    用户级安装若找不到命令，请运行 ~/.local/bin/modernime-settings。

  2. 2

    添加并切换输入法

    在 Fcitx5 配置中添加 ModernIME，再切换到它。已有 Fcitx5 可以继续使用。

  3. 3

    找一处输入框试试

    输入 nihao，用空格选词。之后到「候选与外观」挑选自己喜欢的搭配。

    先看看外观体验

输入法尚未出现时，在当前桌面终端运行 modernime-session-init。GNOME 面板首次安装或更新后可能需要重新登录，查看会话说明。

已经在用 ModernIME

更新沿用原渠道。

APT、DNF、源码和便携安装有各自的更新方式。先在客户端搜索「检查更新」；想从源码或便携安装转到系统包时，使用渠道迁移工具。

先检查当前安装来源：

modernime-migrate-channel --check

迁移前会备份并校验数据。失败时回退程序，保留迁移期间的学习、词典和设置，不自动覆盖为旧数据。
