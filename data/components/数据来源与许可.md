# 拆字查字离线数据来源与许可

`component_lookup.tsv` 是 ModernIME 对以下两个开放数据集的派生索引，不是手工示例字表。运行和安装均不访问网络。上游文件原样保存在 `upstream/`，其 Git blob SHA 已与官方仓库响应核对。

| 数据 | 官方来源与固定版本 | 归属与许可 |
|---|---|---|
| 简体拆字表 `chaizi-jt.txt` | [kfcd/chaizi](https://github.com/kfcd/chaizi/tree/e177ab54ce4edf255315a60593ffecbd8167e96b)，提交 `e177ab54ce4edf255315a60593ffecbd8167e96b` | © 2015 開放詞典；[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)，原文见 `upstream/chaizi.LICENSE`、`upstream/chaizi.README.md` |
| 单字拼音表 `pinyin.txt` | [mozillazg/pinyin-data](https://github.com/mozillazg/pinyin-data/tree/fe29ad32bdf352b31a02b9936e537f575432e9a6)，提交 `fe29ad32bdf352b31a02b9936e537f575432e9a6`，版本 0.16.0 | Copyright (c) 2016 mozillazg；MIT，原文见 `upstream/pinyin.LICENSE`、`upstream/pinyin.README.md` |

本项目做了以下转换：保留简体表有效汉字的各个拆分方案，去掉无法显示原字的 `□` 占位目标与含占位部件的方案；将部件拼音去声调，展开多音字的所有读音组合，兼容 `ü → v/u`；以查询键和汉字去重，保留原部件说明，按键和汉字排序。没有更改上游原始文件。派生拆字数据继续保留 CC BY 3.0 署名义务，拼音数据继续附带 MIT 版权与许可声明；上游作者未为 ModernIME 背书。

当前索引共 **63,110** 条，部件查询覆盖 **14,554** 个不同汉字，ASCII 部件拼音查询覆盖 **14,502** 个不同汉字。上游 README 所述 17,803 字是整个原始数据库的说明；简体文件含 2,909 个 `□` 占位目标行，不能将该数字当作本成品的有效字数。没有拼音的少量部件（`⺆㇆㇉龴龷龹𠃋𡕩`）对应方案仍可按原部件查询；ASCII 查询只覆盖拼音表有完整读音的方案。

## 离线重建

在仓库根目录执行：

```bash
python3 data/components/generate_component_lookup.py
```

只使用 Python 标准库，先校验全部上游文件 SHA256，再生成确定性的 UTF-8 TSV；不会下载数据，不依赖第三方 Python 包、LibIME 或系统词库。日常构建直接使用已提交的 TSV，不需重新生成。也可用 `--output /tmp/component_lookup.tsv` 生成副本进行比对。

## 构建与安装接入

`core/src/component_lookup.cpp` 无外部库依赖。`ComponentLookup` 在构造时加载索引，构造应安排在按键热路径之外；随后 `lookup` 只按完整查询键读取内存索引。查询保持拆字顺序，不进行前缀猜测、模糊匹配或递归拆分；返回值是原字与对应部件说明。数据不可读、格式错误或为空时 `available()` 为 false，`loadError()` 给出诊断，查询不返回错误文本。

由 CMake 定义 `MODERNIME_COMPONENT_LOOKUP_PATH` 为安装成品的完整路径，`MODERNIME_COMPONENT_LOOKUP_SOURCE_PATH` 为源码成品的完整路径。默认先使用已有安装成品，再使用源码成品；均不存在时报告安装路径。core-only 构建不因此依赖拼音模块。

安装包至少携带 `component_lookup.tsv`、本说明与两个原始 LICENSE；建议保留 `upstream/` 许可相对路径。原始大表和生成脚本仅供维护重建，无需随二进制安装。
