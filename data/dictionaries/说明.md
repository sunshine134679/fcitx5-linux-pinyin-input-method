# 离线词库包示例

三个领域包默认关闭；`mixed-common` 中英混合整词包默认启用，只对所列完整输入键补充词条。

本目录提供计算机、医学、法律各三个通用术语，以及三个中英混合词，用于展示离线包能力；不代表完整行业词库。词条由项目自编，以 CC0-1.0 提供，不包含外部词典内容。医学、法律词条只供文字输入。

每个包使用 `manifest.ini` 的稳定 `id`、`name`、`source`、`license`、`version`、`entry_count`，搭配 `entries.tsv`（字母输入键、文本、权重，Tab 分隔）。包管理不会导入个人学习频次；本示例权重为零，领域词统一经共享 LibIME 层、原排序和屏蔽政策处理。中英混合词使用完整输入键精确召回，如 `agu`、`txu`、`dockerrongqi`，大小写输入等价，展示大小写保持。

用户包默认保存在 `$XDG_DATA_HOME/modernime/dictionary-packs/user`（未设置时为 `~/.local/share/modernime/dictionary-packs/user`），与个人词典和学习数据库分离。启停、更新和移除通过显式 C++ API 执行。后台按定时请求检查目录/文件状态并准备完整独立引擎，输入线程只发布准备完成的资源和撤销旧页，不在每次击键扫描目录。安装词库只读；对内置包的启停在用户目录建立受管副本。移除用户覆盖包后，内置包恢复其默认状态。
