# ModernIME 图标

`modernime.svg` 使用用户提供的透明底蓝色 MI 原图，内嵌原始像素，通过圆角裁切边界去掉画布外沿散点。字形和内部配色来自原图，不采用重新生成的图案。

16、32、48、64、128、256、512 px PNG 是 SVG 的标准导出，已随源码提交。CMake 直接安装到 `share/icons/hicolor/<尺寸>x<尺寸>/apps/modernime.png`，全新克隆及离线安装无需图片处理工具或网络请求。

系统包使用主题图标名 `modernime`。源码安装的桌面和应用菜单启动器使用对应前缀下的 512 px PNG 绝对路径，以支持自定义安装位置；GTK 窗口与 Fcitx5 输入法条目使用同一图标名。安装清单记录七张 PNG，卸载仅删除这些明确路径；共享主题缓存只刷新、不删除。

官网导航使用相同的 128 px PNG 导出，favicon 使用 32 px PNG。替换时同步本目录、CMake 尺寸清单及官网素材，运行安装生命周期测试和网站专项测试。
