# 输入辅助功能接口（第 5–8 项）

本轮只提供引擎、查询及 SettingsStore 接口，客户端沿用八个模块。不得用默认设置覆盖加载失败的文件；继续通过 `saveWithResult(path, edited, SettingsExpectedBaseline::fromLoadResult(loaded), &loaded.rawLines)` 保存和处理冲突。

## 5. 临时英文

`ModernIMESettings::temporaryEnglishEnabled`（bool，默认 true），配置键 `input.temporary_english`。约 2 秒配置轮询生效。

中文空闲状态按 Ctrl+Shift+E 开始单段 ASCII 输入；有拼音组合时不接管该快捷键。字母大小写、数字和标点按原样保留，`v2` 不触发剪贴板。支持 Left/Right、Backspace/Delete 编辑，最多 128 字节。Enter 提交、Space 提交并补空格，重复快捷键提交当前内容，随后自动回中文；Esc 取消，失焦/重置取消未提交片段，进入敏感状态丢弃片段。关闭该设置会先提交已有片段；总输入开关关闭仍沿用原重置契约。

带 Ctrl/Alt 等修饰键的应用快捷键在提交已有临时片段后放行。片段不记录个人词频，不写用户词典或学习库。

内部接口在 `adapter/fcitx5/include/modernime/fcitx5/engine.h`：`temporaryEnglishMode()`、`finishTemporaryEnglish(bool commitText)`、`KeyKind::ToggleTemporaryEnglish`；客户端只需接入设置字段。
