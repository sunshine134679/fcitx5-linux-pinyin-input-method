# 输入辅助功能接口（第 5–8 项）

本轮只提供引擎、查询及 SettingsStore 接口，客户端沿用八个模块。

| 功能 | Settings 字段 / 配置键 | 输入入口 |
|---|---|---|
| 临时英文 | `temporaryEnglishEnabled` / `input.temporary_english` | `Ctrl+Shift+E` |
| 候选置顶 | `candidatePins` / `candidate.pin.<scheme>.<input>` | 客户端管理规则 |
| 拆字查字 | `componentLookupEnabled` / `input.component_lookup` | `u+`，如 `u+mumu` |
| 离线计算器 | `calculatorEnabled` / `input.calculator` | `v=`，如 `v=(2+3)*4` |

三个 bool 均默认 true；置顶规则默认空。头文件均位于 `core/include/modernime/core/`，通过现有 `modernime_core` 链接，查询与计算无需 Fcitx 插件实例。客户端界面由其他任务接入，本轮没有改动 GTK 页面。

不得用默认设置覆盖加载失败的文件；继续通过 `saveWithResult(path, edited, SettingsExpectedBaseline::fromLoadResult(loaded), &loaded.rawLines)` 保存和处理冲突。

## 5. 临时英文

`ModernIMESettings::temporaryEnglishEnabled`（bool，默认 true），配置键 `input.temporary_english`。约 2 秒配置轮询生效。

中文空闲状态按 Ctrl+Shift+E 开始单段 ASCII 输入；有拼音组合时不接管该快捷键。字母大小写、数字和标点按原样保留，`v2` 不触发剪贴板。支持 Left/Right、Backspace/Delete 编辑，最多 128 字节。Enter 提交、Space 提交并补空格，重复快捷键提交当前内容，随后自动回中文；Esc 取消，失焦/重置取消未提交片段，进入敏感状态丢弃片段。关闭该设置会先提交已有片段；总输入开关关闭仍沿用原重置契约。

带 Ctrl/Alt 等修饰键的应用快捷键在提交已有临时片段后放行。片段不记录个人词频，不写用户词典或学习库。

内部接口在 `adapter/fcitx5/include/modernime/fcitx5/engine.h`：`temporaryEnglishMode()`、`finishTemporaryEnglish(bool commitText)`、`KeyKind::ToggleTemporaryEnglish`；客户端只需接入设置字段。

## 6. 候选置顶

`ModernIMESettings::candidatePins` 是 `std::vector<CandidatePin>`，每条包含 `scheme`（`PinyinScheme`）、`input`、`text`、`fullPinyin`。每个方案及规范输入最多一条，共最多 128 条。`input` 使用 `PinyinMatchPolicy::canonical(rawInput)`；`text/fullPinyin` 应取自完整消费当前输入的中文或用户词典候选，不能取预编辑显示串或部分候选。文本与完整拼音各最多 128 字节，文本为单行 UTF-8 且不含 `|`。

配置示例：`candidate.pin.full.shi=试|shi`；方案键为 `full/xiaohe/ziranma`。新增或替换对应规则即置顶，删除对应规则即取消；通过同一 SettingsStore 冲突保存接口提交，约 2 秒轮询生效。删除时传入 `loaded.rawLines`，存储层会移除旧动态键。

规则只提升本次已召回、未屏蔽且身份匹配的完整中文候选，保留消费范围与原学习资格，不凭规则生成候选。未召回或已经屏蔽的目标不会出现，取消规则后恢复现有排序。全拼和两种双拼分别保存。客户端可在候选操作中采集上述身份字段，或在词典模块管理规则；本轮不新增引擎置顶快捷键。

必要验证：插件增量构建、SettingsStore 规则往返/删除/重复范围拒绝，以及真实 LibIME→Composer→Controller 的置顶、上屏、完整消费和屏蔽不复活用例通过。

## 7. 拆字查字

`ModernIMESettings::componentLookupEnabled`（bool，默认 true），键 `input.component_lookup`。中文状态输入 `u+` 后输入部件拼音，如 `mumu → 林`、`mumumu → 森`、`ririri → 晶`、`riyue → 明`。最多 128 字节，支持大小写、`'`/`+` 分隔、Left/Right、Backspace/Delete；上下及翻页键选择，数字键（开关开启时）、Space/Enter 或点击候选上屏。Esc、失焦/重置、敏感切换或关闭功能取消查询；无匹配/缺失数据提示不能提交。`u+` 只在组合恰为 `u` 时触发，不接管其他拼音或辅助模式。

核心查询位于 `modernime/core/component_lookup.h`：

```cpp
ComponentLookup lookup; // 构造时加载，必须放在按键热路径之外
bool ready = lookup.available();
std::string error = lookup.loadError();
std::vector<ComponentCandidate> matches = lookup.lookup("木木", 30);
// ComponentCandidate { std::string text; std::string components; }
```

支持原部件或完整部件拼音查询，忽略大小写及空白、`'`、`+`；不做前缀/模糊/递归拆分。索引覆盖 14,554 个不同汉字，ASCII 部件拼音覆盖 14,502 字。固定版本数据及许可随仓库离线提供，安装目录 `share/modernime/components/`；来源与重建见 [拆字数据许可](../data/components/数据来源与许可.md)。Fcitx 已有拆字词典由原生拼音引擎使用（[构建入口](https://github.com/fcitx/fcitx5-chinese-addons/blob/master/im/pinyin/CMakeLists.txt)），本轮提供独立只读索引以支持部件说明和客户端查询，不要求加载另一输入引擎。

引擎初始化时构建一次共享索引，各上下文只持有只读指针。内部接口 `setComponentLookup(shared_ptr<const ComponentLookup>)`、`KeyKind::OpenComponentLookup`、`auxiliaryInputMode()/auxiliaryInputActive()/cancelAuxiliaryInput()`。结果使用现有候选页身份和代次选择，角色 `Generated`，不写词频、词典、屏蔽或学习库。

必要验证：插件增量构建、`modernime_component_lookup/typing_features/settings` 三项通过，覆盖原部件与拼音、分隔、上屏、点击、过期选择拒绝、无匹配不提交、敏感取消及原组合保留。数据离线重建与成品一致。

## 8. 离线计算器

`ModernIMESettings::calculatorEnabled`（bool，默认 true），键 `input.calculator`。中文状态输入 `v=` 后输入表达式，如 `v=(2+3)*4` 显示 `20`。数字始终录入表达式，不作为选词键；Enter、Space、末尾 `=` 或点击结果上屏并回中文。支持 Left/Right、Backspace/Delete；Esc、失焦/重置、敏感切换或关闭功能取消。错误保留查询供修正，提示和错误表达式均不能提交。临时英文中的 `v=` 保持字面文本，普通 `v2` 剪贴板及 `v123` 数字宏不变。

独立接口位于 `modernime/core/calculator.h`：

```cpp
CalculationResult result = calculate("(2+3)*4");
// { bool valid; std::string text; std::string error; }
// 成功：valid=true, text="20", error=""
// 失败：valid=false, text="", error=中文错误原因
```

支持小数、`+ - * / %`、括号、一元正负和 ASCII 空白；`%` 是余数，符号随被除数。核心及引擎表达式上限 512 字节、括号嵌套上限 32 层。使用 `long double` 近似计算并显示 15 位有效数字，输出展开的十进制，不提供财务精确小数语义；不支持函数、指数输入或隐式乘法。纯解析，无脚本求值、子进程、文件或网络访问，无新增系统依赖。

内部入口 `KeyKind::OpenCalculator`，状态 `AuxiliaryInputMode::Calculator`，共享前述取消/查询模式接口。结果标记 `Generated`，不进入个人词频、词典或学习库。客户端只需接入设置开关和必要说明，也可直接调用纯接口展示预览。

必要验证：插件增量构建、`modernime_calculator/typing_features/settings` 三项通过，覆盖运算/优先级/小数/非法表达式和上限，以及实际 Fcitx 按键进入、数字不选词、结果提交、错误不提交、错误修正、取消和原数字宏对照。
