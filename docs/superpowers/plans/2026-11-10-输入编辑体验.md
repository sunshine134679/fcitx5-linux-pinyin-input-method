# 输入编辑体验实现计划

目标：按用户确认完成成对标点、智能标点、按应用模式和撤销重选；只提供后端与配置接口，客户端由另一位 AI 接入。

实现沿用 C++、Fcitx5 和 SettingsStore。宿主负责核对文本和执行编辑，Controller 负责本次输入会话，设置仍经过原有校验、冲突保存及热载。直接在 `/home/wsl/ModernIME` 的 main 增量实施，保留已有未跟踪文档。

- [x] 成对标点：扩展 EngineHost 的可选文本编辑接口，支持括号及引号补全、越过本次补出的闭符号、删除空对；不支持编辑或存在选区时退回普通标点。
- [x] 智能标点：保留现有英文/数字规则，补充标识符、路径和 URL 连续标点保护；开放单键映射和独立下划线偏好。
- [x] 应用模式：按 Fcitx `program()` 精确匹配配置默认值，允许会话内记忆手动选择；未知应用沿用全局默认。不给后台写入应用历史。
- [x] 撤销重选：默认 Ctrl+Shift+BackSpace，核对最后提交文本、两侧上下文和剩余拼音后恢复原始组合；失焦、外部编辑、敏感状态失效。负反馈沿现有资格路径，不另设学习库。
- [x] 增量构建受影响目标，运行新功能定向回放及现有引擎、按键、设置检查，提交合入 main，给出客户端接口交接。

必要验收覆盖连续/嵌套标点、已有闭符号、空对退格、选区、光标移动、失焦、快捷键混用、部分候选消费、禁学/敏感及关闭功能后的行为。仅新增这些直接相关用例，不扩大全量矩阵。

涉及契约：`ALG-CONTEXT/GATE/EXTRACT/IDENTITY`、`CAND-SELECT`；新增 `ALG-EDIT-UNDO`。不改召回、排序、拼音切分、衰减、容量、持久格式或标准模糊音学习。撤销为当前会话的单级编辑，不能删除其他位置或其他应用文本。

验证：五项直接相关检查通过；额外拼音集成检查的 yuedign 首选断言在未修改控制器对照中同样失败，详见输入编辑功能接口。只将本轮改动提交到当前主目录 main。
