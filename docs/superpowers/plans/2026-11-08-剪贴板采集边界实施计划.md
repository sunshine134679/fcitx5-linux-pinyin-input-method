# 剪贴板采集边界实施计划

> 执行技能：superpowers:executing-plans；由本会话实现，最终一次独立审查。

**目标：** 阻断不具备采集资格时的剪贴板读取与恢复补记，保留正常历史管理。

**架构：** adapter 拥有采集区间；PersistentClipboardHistory 保持唯一去重事实及持久化所有权。真实插件集成测试覆盖连接处。

**技术栈：** C++20、Fcitx5、既有 CMake/CTest，无新依赖。

**设计：** [剪贴板采集边界设计](../specs/2026-11-08-剪贴板采集边界设计.md)。

## 全局约束

- Ubuntu 24.04 + GNOME 为主平台；测试数据全隔离，不读取宿主剪贴板。
- 保留30条/每条1MiB剪贴板边界、200,000学习容量及原性能门限。
- 无新 schema、依赖、异步线程或隐藏学习入口；文件格式和外部清空合并保持。
- 新文档和提交用中文；沿用现有隔离 worktree；不部署或推送。

## 审查重点

快速失焦再聚焦、敏感再普通、输入法往返均可能发生在两次采样间；对应集成场景直接连续触发事件。读取异常后恢复值不得补记；集成故障注入覆盖。已有合法待写不能因建立基线而丢失；核心故障路径覆盖。外部清空后同值不可复活；核心和实际 V+2 共同覆盖。关闭功能及全局输入后恢复必须建立基线；集成测试通过实际配置热载覆盖。
