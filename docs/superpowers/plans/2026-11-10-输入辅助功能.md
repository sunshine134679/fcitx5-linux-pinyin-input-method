用户确认本轮继续临时英文、候选置顶、拆字查字、离线计算器。只修改后端、设置接口和输入接线，维持八个客户端模块。

- [x] 临时英文：空闲中文状态按 Ctrl+Shift+E，编辑单段 ASCII；Enter 提交、Space 提交并补空格，Esc 取消，自动回中文。保护原有组合、快捷键与敏感/失焦边界。
- [x] 候选置顶：在 SettingsStore 提供按方案/输入/候选身份保存的规则，Composer 统一应用；只置顶合法且已召回的完整中文候选，不绕过屏蔽、学习或消费范围。

- [ ] 离线计算器：提供独立纯解析接口，支持四则、括号、小数和一元正负；显式触发，错误不提交，生成结果不学习。
- [ ] 每项增量构建、相关用例通过后提交主目录 main；统一交接配置与接口，不推送/部署。
