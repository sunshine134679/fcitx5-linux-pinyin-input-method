# 剪贴板异步持久化实施计划（U10）

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:executing-plans 在当前会话逐项执行；用户已授权自主实施，沿用现有 worktree，不另设审批。

**Goal:** 将剪贴板全部文件I/O移出输入事件循环，同时保住观察基线、外部清空、合法待写与真实选词。

**Architecture:** 主线程过滤观察身份并构建有界批次；单worker独占持久历史和文件事务。批次先重载后解释，向主线程发布不可变快照；Fcitx安全端点处理完成通知。

**Tech Stack:** C++20、std::thread、现有ClipboardHistory/PersistentClipboardHistory、Fcitx5、CTest/GTest。

**Spec:** [剪贴板异步持久化设计](../specs/2026-11-08-剪贴板异步持久化设计.md)。实施起点 `36083be`，非部署计划。

## Global Constraints

- 主验收 Ubuntu 24.04 + GNOME；保留原八模块及功能，不部署、不推送。
- 历史/pending各30条，每条1MiB；每个未判定批次最多first+tail31项，不引入无界采样队列。
- 保持200,000条学习容量、原生1ms/5ms/30ms门限、持久格式、0600权限、稳定锁、U09资格与恢复基线。
- 核心不依赖Fcitx/GTK；无新外部库，Threads通过CMake声明；所有新文档/提交中文。
- 原同步断言不改；后台失败不伪装Ready，不丢合法待写；主线程不等I/O。
- 基准和任何完整CTest/嵌套构建串行；证据保存首次失败和退出码，隔离HOME/XDG与/tmp。

## Review Focus

1. 重载前历史顶部恰好等于新复制值、外部已清空：仍保留合法新复制，不能按旧视图过滤（任务1/2）。
2. baseline与失败批次交错、压缩后前驱消失：待写资格和次序不丢，基线不入库（任务1）。
3. 读失败后的同inode/stamp恢复及物理文件删除：下次可重试，不永久缓存错误（任务1/2）。
4. 退出时任务/通知在途且保存失败：停止UI回调，有限重试并报告，已接受批次不静默丢弃（任务2/3）。
5. Loading页关闭、失焦或新组合已开始，旧完成和旧选择到达：不重开/不误提交；正常剪贴板页面不被重排（任务3）。
