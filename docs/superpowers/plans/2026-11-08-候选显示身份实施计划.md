# 候选显示身份实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans 在当前隔离工作树逐项实施。

**Goal:** 拒绝与已绘制候选不一致的鼠标选择，正常选择保留身份和消费。

**Architecture:** UI 持有更新帧与已绘制帧；每帧绑定受跟踪的 InputContext、弱 CandidateList 和候选映射。提交仍由原选择端点负责。

**Tech Stack:** C++20、Fcitx5、GTK3、现有 CMake/CTest。

**Spec:** `docs/superpowers/specs/2026-11-08-候选显示身份设计.md`

## Global Constraints

- 保留排序、分页政策、学习资格、消费范围和 200,000 容量；不添加依赖。
- Ubuntu 24.04 + GNOME；X11 测试不冒充原生 Wayland。
- 中文维护文档/提交；不安装或重启日常输入法，不改变用户数据。

## Review Focus

- 同列表页码改变、条数相同，不能把旧下标映射到新词。
- 同文本而消费范围/读音不同，不能按文本放行替换列表。
- GTK 更新已经完成但还没有 draw，不能接受新布局的点击。
- 失焦后重新聚焦或销毁 owner，旧页面不能重新取得资格。
- 选择回调销毁上下文或刷新列表，后续 UI 请求不得访问过期对象。
