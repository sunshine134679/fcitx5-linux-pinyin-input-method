# 客户端动效实现计划

目标：按用户确认的六项设计实现原生 GTK3 动效，仅本地验证。

设计依据：[客户端动效设计与实现提示词](/home/wsl/.codex/worktrees/website-publish/ModernIME/docs/客户端动效设计与实现提示词-2026-11-09.md)。基线为客户端工作树 `6131b33`；保留此前更新流程及升级引导排版修复。

架构：复用 GTK 帧时钟、GtkStack、GtkRevealer 与现有 Cairo 绘制。动画只跟随业务状态；短暂快照按设备比例绘制，覆盖层穿透输入。主界面动效、候选预览、折叠动效按文件职责并行实施，最后统一增量构建和隔离实机验证。

执行使用 writing-plans、dispatching-parallel-agents 的任务划分；直接按已确认设计实现，不新增方案审批。用户要求的有限验证优先于技能中的全量测试和多轮审查。

## 全局边界

- 保留信息架构、布局、文案、配色及保存/放弃、异步任务生命周期。
- 不改变日常候选弹窗、排序、身份、消费或学习。
- 系统禁用动画、隐藏、关闭时结束动效；主题进出高对比直接切换。
- 不推送、发布、安装覆盖日常客户端，不修改网站。
- 仅增量构建客户端和直接相关验证，不运行全量回归或安装卸载。

## 任务

- [x] 主界面：`settings_shell.cpp` 接入局部 `settings_motion` 辅助。主题选择 440 ms 圆形揭幕，放弃 300 ms；旧快照与新内容完整配色；快速操作取消/衔接，缩放立即结束。导航背景 180 ms 移动，正文保留 160 ms 交叉淡入。搜索目标行 100/250/350 ms 单次提示，真实控件保持焦点。底部状态 150/180 ms，任务消息 120 ms，保持几何稳定与真实保存/应用状态。
- [x] 预览：仅修改 `pages/candidates_page.cpp` 及局部预览辅助，按颜色 180 ms、轮廓 220 ms、布局 180 ms 过渡；新字体立即清晰绘制，最终委托原绘制结果。主题选择接口保持不变。
- [x] 折叠：`settings_disclosure` 小型公共辅助及 input/clipboard/updates/diagnostics 页面，展开 220 ms、收起 170 ms，箭头随进度旋转，保持默认状态与搜索定位。
- [x] 验证：客户端增量编译；运行直接受影响 GTK 检查；在临时配置和数据目录中操作主题/放弃、预览、导航、展开、搜索、保存，检查快速切换、禁用动画与关闭清理。只为新引入的非平凡状态逻辑增加必要测试。
- [x] 交付：保存真实运行截图/短录屏和简短结果，中文本地提交，不推送。

## 重点检查

1. 主题快照不能残留菜单、低分辨率文字或夺取焦点。
2. 最新选择与真实草稿一致，取消动画不能回滚业务状态。
3. 预览过渡结束与原渲染一致，新字体不缩放旧截图。
4. 搜索折叠目标可立即聚焦，提示只作用于最后目标。
5. 保存落盘和运行时应用反馈保持区别；关闭窗口不留帧回调。
