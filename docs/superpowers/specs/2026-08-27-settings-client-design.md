# ModernIME 设置客户端设计规格

## 目标

新增一个面向 Ubuntu 桌面的 GTK3 原生设置客户端 `modernime-settings`，用于配置 ModernIME 的功能开关、候选操作、用户学习、用户词典和运行状态。客户端必须复用 ModernIME 的用户配置路径，不修改已经确认的候选框尺寸、位置、字体、圆角和间距。

## 范围

第一版包含以下能力：

1. 基本设置：读取和保存 ModernIME 的启用状态、默认中英文状态以及切换快捷键配置。
2. 候选设置：配置候选翻页和选择行为，包括数字键选择、上下方向键、`+`/`=` 翻页；不提供候选框几何尺寸编辑。
3. 智能学习：启用或停用用户习惯学习、上下文学习，显示学习数据库位置，并提供清空学习记录操作。
4. 用户词典：查看、添加、编辑、删除、导入和导出本地专业词条。
5. 输入法状态：显示 Fcitx5 是否运行、当前输入法、ModernIME 插件是否加载，并提供重新加载 ModernIME 的操作。
6. 恢复默认：只恢复 ModernIME 自己的配置和可选学习数据，不触碰系统其他输入法。

不包含云端候选、联网词库、远程模型、候选框视觉编辑、系统级 Fcitx5 全局设置以及管理员权限操作。

## 用户体验

- 客户端通过桌面菜单启动，窗口为单实例设置窗口。
- 左侧使用设置分类列表，右侧显示当前分类内容；窗口支持键盘导航。
- 修改配置后由用户点击“应用”或“保存”提交；保存失败时保留编辑内容并显示具体原因。
- 会影响运行中输入法的设置显示“需要重新加载”，客户端提供明确的“重新加载 ModernIME”按钮。
- 清空学习记录、删除词条和恢复默认属于破坏性操作，必须二次确认。
- 缺少配置文件、词典文件或学习数据库时按空数据处理，并显示可操作的创建或导入提示。
- 不使用 `sudo`，所有用户数据写入 `${XDG_CONFIG_HOME:-$HOME/.config}` 或 `${XDG_DATA_HOME:-$HOME/.local/share}`。

## 配置与数据边界

新增共享配置层，集中定义默认值、用户路径、格式和校验规则。建议配置文件为：

`${XDG_CONFIG_HOME:-$HOME/.config}/modernime/settings.conf`

配置采用稳定、可审计的键值格式，至少包含：

- `input.enabled`
- `input.default_mode`
- `input.toggle_key`
- `candidate.number_selection`
- `candidate.arrow_navigation`
- `candidate.page_navigation`
- `learning.enabled`
- `learning.context_enabled`

配置写入采用“临时文件写入、刷新、原子替换”的方式；损坏或未知值不能导致客户端崩溃，读取时回退到单项默认值并保留可诊断错误。

现有候选栏的几何参数继续由 UI 代码固定维护，设置客户端不得写入这些参数。用户词典继续使用现有 `UserDictionary` 数据格式；学习数据继续使用现有 SQLite 文件和 `LearningStore`，客户端通过独立服务接口执行清空，不直接拼接 SQL。

## 运行时通信

新增 `RuntimeController` 抽象，负责：

- 查询 `fcitx5-remote` 是否可用以及 Fcitx5 是否运行；
- 查询当前输入法名称和激活状态；
- 请求重新加载或重启 ModernIME 相关运行状态；
- 将命令不可用、超时、非零退出码转换为用户可读错误。

客户端默认使用当前用户环境中的 `DISPLAY`、`DBUS_SESSION_BUS_ADDRESS` 和 `XDG_RUNTIME_DIR`，不自行猜测显示服务器，也不以 root 身份启动 Fcitx5。

## 模块划分

- `config/`：默认值、路径解析、配置解析与原子保存。
- `core/`：可被客户端复用的配置模型和学习数据操作接口。
- `tools/settings/`：GTK3 应用入口、窗口和页面控制器。
- `algorithm/pinyin/`：复用现有用户词典接口，不在设置客户端复制词典解析逻辑。
- `tests/`：配置读写、校验、词典编辑、学习数据清空、运行时错误转换和 GTK 页面行为测试。

应用目标名为 `modernime-settings`，由 CMake 构建并由 `install.sh` 安装到用户前缀的 `bin/`；`uninstall.sh` 通过安装清单移除它。设置客户端自身不作为 Fcitx5 addon 加载。

## 错误处理与安全

- 所有文件操作使用显式路径，拒绝路径穿越和空路径覆盖。
- 配置保存失败不删除原文件。
- 用户词典导入采用临时解析结果，全部校验通过后才替换目标文件。
- 清空学习数据前创建同目录备份，备份失败则不执行清空。
- 外部命令通过参数数组执行，不拼接用户输入到 shell 命令。
- UI 线程不执行不可控的长时间阻塞操作；运行状态查询和词典大文件操作使用可取消的后台任务，完成后回到 GTK 主线程更新界面。

## 验收标准

1. 在没有用户配置文件的干净环境中启动客户端，所有页面可打开并显示默认值。
2. 修改一个设置、保存、重新启动客户端后，值保持不变；配置文件损坏时客户端仍能启动并只回退损坏项。
3. 添加、编辑、删除、导入、导出词条后，ModernIME 下一次重载能看到对应结果；非法 UTF-8 或非法拼音不会写入词典。
4. 清空学习记录必须经过确认，执行后学习数据库为空且已有备份；取消确认不改变数据。
5. Fcitx5 未运行或 `fcitx5-remote` 不可用时，客户端仍能使用本地设置和词典功能，并给出明确状态。
6. 设置客户端安装、卸载不影响系统其他 Fcitx5 文件；不需要 `sudo`。
7. 现有完整测试继续通过，新增功能每个独立提交，并补充 GTK/文件系统边界测试。

## 分阶段实施

实施顺序固定为：

1. 配置模型、路径和原子读写；
2. GTK3 应用骨架与基本设置页面；
3. 候选行为设置和运行时状态页面；
4. 学习开关、备份与清空；
5. 用户词典编辑、导入导出；
6. 安装、卸载、桌面入口与端到端验证。

每个阶段先写失败测试，再实现最小功能，完整验证通过后单独进行一次 Git commit。
