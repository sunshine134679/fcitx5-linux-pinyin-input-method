# 候选显示身份设计

状态：针对 U13 已复现缺陷的局部修复；总目标继续。基线 `8aaef338baab9b9b195c278f41598a56a7fef363`，Ubuntu 24.04 + GNOME 为主验收环境。

## 意图与证据

用户需要鼠标提交眼前的候选。真实 `ModernIMEUserInterface` 旧实现先命中缓存几何，再从当前 inputPanel 取词；相同五项列表替换但没有 UI 更新时，原“你好”位置提交了未显示的“新词”。失败证据在 `build/候选显示身份验证/旧列表点击复现.log`，退出 1；隔离配置及 DBus，未改宿主输入法。

## 方案与取舍

采用 UI 内聚的页面绑定：布局、上下文弱引用、候选列表弱引用及页内候选对象映射属于一次更新；绘制回调完成后撤销旧点击资格，使用 G_PRIORITY_DEFAULT_IDLE 等待优先级更高的 GDK 事件及 redraw/resume 阶段排空后才登记为可点击页面。点击只允许当前输入面板仍为该列表、页内映射仍一致且上下文仍有效并聚焦时发生。选择继续调用既有 CandidateWord / SelectionEndpoint，不另造提交或学习政策。

仅比较列表指针不足以拦截同一列表翻页；仅比较文本不足以区分同字不同读音/消费；每次点击强制重绘会把用户旧坐标解释为新内容。故不采用这些替代方案。原生 Wayland UI 路由和可用宽度分页是独立问题 U11/U12，本次不改路由或几何政策。

## 状态与生命周期

唯一写者为宿主/GTK 主线程。当前更新帧与已绘制帧各最多一份；候选列表以弱引用保存，不延长整份剪贴板列表寿命。ModernIME 已发布 CandidateWord 的身份不可变，保留原列表中的对象映射，不能将下标重新绑定到新对象。公开兼容列表的文字变更也须拒绝旧点击。字体热载、隐藏、suspend、上下文失焦/销毁清除点击资格；不使用 mostRecentInputContext 补齐丢失的 owner。执行 select 后再次用受跟踪的上下文引用检查寿命，再请求 UI 更新。

绘制完成只表示 GTK draw 回调完成，不等于合成器已经呈现。本地 GTK before-paint 排入的点击必须在新帧取得资格前处理，已由实际 frame clock 交错回归约束。服务器/合成器尚未送达本地的事件与实际屏幕呈现边界仍需协议证据，后续 U14 做呈现测量。

## 契约与验收

涉及 `CAND-SELECT/PAGES/VIEW`、`ALG-IDENTITY/FORM/GATE`。不改变语义顺序、消费规则、学习、持久格式、容量、依赖或安装路径。回退仅撤销程序改动，不恢复用户数据库。

先在旧实现运行：同数量列表替换、同列表翻页、更新但 draw 被阻止、失焦和销毁、隐藏后新上下文、同文本不同消费身份。正常重绘后的点击、键盘选择、部分候选消费与剩余输入必须保持；保留字号热载原断言。通过真实 GTK UI + Fcitx 选择端点/控制器验证，不仅测布局 helper。记录编译、专项 CTest、GTest 选择回归；按仓库既有门禁运行全套 CTest，GUI 使用隔离数据补测。没有原生 Wayland 证据时不得计为已完成。

用户已授权按阶段自主实施。本设计中的技术选择由执行者依据现有契约作出，不增加审批环节。
