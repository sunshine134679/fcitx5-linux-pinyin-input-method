# ModernIME 设置客户端优化设计规格

## 目标

在不改变 ModernIME 候选栏现有尺寸、位置、字体、圆角和间距的前提下，完善 GTK3 设置客户端 `modernime-settings` 的功能闭环、运行状态反馈、数据管理能力和界面层级，使用户可以清楚地修改、保存、应用、重载和管理 ModernIME 的所有客户端可配置功能。

## 已确认的技术方向

- 保留 GTK3，不迁移 GTK4/libadwaita。
- 保留现有 `SettingsStore`、`UserDictionary`、`LearningStore` 和持久化剪贴板文件格式。
- 设置客户端继续使用用户目录，不使用 `sudo`，不修改系统其他输入法的文件。
- 候选栏几何参数不加入设置客户端，也不在本次任务中调整。
- 每个独立功能完成后单独使用中文 Git 提交信息。
- 每个提交完成后都必须构建、测试并安装验证。

## 范围

### 1. 设置编辑生命周期

设置客户端需要明确区分以下状态：

- 已加载且未修改；
- 有未保存修改；
- 正在保存；
- 保存失败但保留编辑内容；
- 已保存但需要重新加载输入法；
- 正在重载运行中的输入法。

按钮语义统一为：

- `应用`：保存当前修改，窗口保持打开；
- `保存并关闭`：保存当前修改并关闭窗口；
- `恢复修改`：丢弃当前未保存修改，恢复最近一次保存内容；
- `恢复默认`：二次确认后将设置编辑为默认值，并通过正常保存流程提交；
- `重新加载 ModernIME`：在状态页或保存成功后的提示区域触发运行时重载。

关闭窗口或切换到会导致数据丢失的操作前，如果存在未保存修改，必须二次确认。保存失败时不得覆盖旧配置，也不得丢弃界面上的编辑值。

### 2. 统一校验和诊断

所有设置必须在保存前统一校验：

- `input.toggle_key` 必须是非空、长度不超过 64、只包含字母、数字、`+` 或 `-` 的快捷键描述；
- `clipboard.trigger` 必须符合 `Letter+Digit`，例如 `V+2`；
- 配置读取时单项错误回退到该项默认值，同时保留带行号的诊断信息；
- 客户端启动后显示配置警告，不能静默丢失诊断；
- 控件输入阶段提供即时错误提示，错误存在时禁用应用按钮。

### 3. 页面能力

#### 基本设置

包含启用状态、默认中文/英文状态和中英文切换快捷键。每项显示用途说明；快捷键错误在输入框附近显示，不等到点击保存才提示。

#### 候选设置

包含数字键选择候选、左右方向键切换候选、上下方向键以及 `+`/`=` 翻页。只配置行为，不配置候选栏几何参数。每个开关显示与候选操作的对应关系。

#### 剪贴板

包含 `V+2` 功能开关、触发键设置、当前历史数量、最大保存数量和持久化历史列表。进入页面自动刷新，也保留手动刷新。历史为空、文件不存在、读取失败都要有明确状态。

历史管理提供选择、复制到系统剪贴板、删除选中项和清空全部历史；清空属于破坏性操作，需要确认。所有修改使用原子保存，失败时保留原历史文件。

#### 智能学习

包含用户候选学习开关、上下文学习开关、学习数据库路径、当前学习记录数量和备份/清空操作。清空前自动备份并验证备份可读取，备份失败时不清空原数据。

#### 用户词典

包含拼音、词条、权重列表，支持添加、编辑、删除、导入、导出和搜索。未选择词条时编辑/删除按钮禁用；词条输入即时校验；导入先完整解析和校验，全部通过后才替换原文件；无词条时显示引导状态。

#### 输入法状态

分别显示 `fcitx5-remote` 是否可用、Fcitx5 是否运行、当前输入法、ModernIME 是否激活。状态查询、重载过程和最终结果使用不同视觉状态显示，并提供失败后的再次重试。

重载逻辑必须先探测运行状态：已运行时优先调用 `fcitx5-remote -r`，只有服务未运行时才启动 Fcitx5；不得每次无条件启动第二个 Fcitx5 进程。启动和重载均捕获标准错误，并转换成可理解的中文提示。

### 4. 界面系统

- 保留左侧分类导航和右侧内容区；
- 右侧页面统一使用标题、副标题、分组卡片和说明文字；
- 页面主体可滚动，窗口缩小时不裁剪控件；
- 底部固定操作栏显示修改状态、错误/成功信息和主要按钮；
- 主开关关闭时，相关从属控件正确禁用但保留已配置值；
- 所有操作支持 Tab、方向键和回车等键盘导航；
- 所有可交互控件有可读标签、提示文字和明确焦点；
- 使用 GTK3 样式类统一颜色、边框、内边距、圆角和按钮层级，不引入新的运行时依赖；
- 界面优化只作用于设置客户端，不触碰输入法候选栏的显示代码。

## 数据边界和安全要求

- 配置、用户词典、学习数据库和剪贴板历史继续写入 `SettingsPaths` 指定的用户目录；
- 配置、词典和剪贴板历史使用临时文件写入后原子替换；
- 文件操作失败必须保留原文件并在界面显示原因；
- 外部命令只能通过参数数组启动，不把用户输入拼接到 shell 命令；
- 长时间运行的 Fcitx5 查询、重载和大数据读取不阻塞 GTK 主线程；
- 不增加联网词库、云端候选、系统级 Fcitx5 全局设置或管理员权限操作。

## 验收标准

1. 在干净用户目录启动设置客户端时，所有页面都能显示默认值，不出现空白页面。
2. 修改任一设置后能看到未保存状态；非法快捷键会在保存前被阻止并给出具体提示。
3. `应用`、`保存并关闭`、`恢复修改`、`恢复默认` 和关闭确认行为彼此明确，保存失败不丢编辑内容。
4. Fcitx5 已运行时重载不会创建重复服务；未运行时能给出启动失败原因或成功激活 ModernIME。
5. 剪贴板历史能可靠读取、显示、选择、复制、删除、清空并持久化；学习清空始终先备份。
6. 用户词典的增删改、搜索、导入、导出和错误提示均可用，非法数据不会覆盖原文件。
7. 窗口缩放、键盘导航、禁用状态、空数据状态、失败状态和成功状态均有可理解的界面反馈。
8. 每个独立功能都有针对性测试，并在提交前完成完整构建、CTest 和用户前缀安装验证。
