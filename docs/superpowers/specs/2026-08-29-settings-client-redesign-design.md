# ModernIME 设置客户端重构设计规格

## 1. 背景与目标

ModernIME 当前包含独立的 GTK3 设置客户端，已经具备基本设置、候选设置、剪贴板、智能学习、用户词典和输入法状态等功能。本次只重做设置客户端，不改变 Fcitx5 候选栏的外观和交互，也不以重写输入引擎为目标。

本次重构需要同时实现以下目标：

- 建立简洁、高效但不过度简陋的统一界面体系；
- 面向普通用户提供清楚的默认路径，同时为高级用户保留完整的数据管理和诊断能力；
- 增加有实际用途、能够形成完整操作闭环的客户端功能，不保留占位按钮或不可用入口；
- 默认完全离线，任何联网能力都必须由用户明确启用；
- 保留 GTK3 和现有数据格式，采用增量重构降低回归风险；
- 所有保存、导入、删除、恢复和联网操作都提供可理解的状态、错误和恢复路径。

## 2. 已确认的产品原则

### 2.1 用户定位

客户端采用“普通用户优先、兼顾高级用户”的分层设计。常用设置直接展示，数据维护、诊断和联网控制放在清晰的独立页面，不以隐藏功能为代价追求表面简洁。

### 2.2 技术路线

采用增量重构方案：

- 保留 GTK3，不迁移 GTK4 或 libadwaita；
- 保留现有 `SettingsStore`、`UserDictionary`、`LearningStore`、剪贴板历史和运行时控制能力；
- 先拆分现有窗口结构并建立共享 UI 组件，再逐页接入现有能力和新增能力；
- 所有阶段均可独立构建、测试、安装和验收。

### 2.3 离线与联网边界

客户端默认完全离线。版本检查、词库更新和配置同步分别使用独立开关，不能因用户启用其中一项而隐式启用其他联网行为。

首次启用每项联网功能前，界面必须说明访问目标、发送数据、保存内容和关闭方式。联网总开关未授权时，不创建网络请求、不注册后台定时任务，也不因打开联网页面自动连接外部服务。

## 3. 范围与非目标

### 3.1 本次范围

- 设置客户端的窗口外壳、导航、页面布局和视觉体系；
- 设置搜索、状态反馈、表单校验和保存生命周期；
- 输入体验、个人词典、剪贴板、智能学习、本地备份与恢复；
- Fcitx5 与 ModernIME 运行状态、配置和数据诊断；
- 第三阶段中显式选择后才启用的版本检查、词库更新和配置同步；
- 对新增与既有功能补充自动化测试和人工验收流程。

### 3.2 非目标

- 不修改候选栏尺寸、位置、字体、圆角、配色和交互；
- 不迁移 UI 框架；
- 不增加云账号体系或默认后台服务；
- 不实现应用专属输入规则，因为该能力需要修改输入引擎与应用识别链路；
- 不增加复杂主题编辑器；
- 不使用管理员权限，不修改系统其他输入法的数据。

## 4. 信息架构与视觉设计

### 4.1 窗口结构

窗口默认尺寸为 860×620，并允许缩放。整体由左侧分组导航、右侧滚动内容区和底部固定操作栏组成。

左侧导航按用户心智而不是现有源代码模块划分：

1. 概览；
2. 输入体验；
3. 个人词典；
4. 剪贴板；
5. 智能学习；
6. 数据与备份；
7. 系统与诊断；
8. 联网与更新。

右侧页面统一使用标题、副标题、分组卡片、设置行、状态徽标、空状态和任务进度组件。页面过长时只滚动内容区，导航和底部操作栏保持可见。

### 4.2 概览页

概览页作为默认首页，展示：

- ModernIME 是否运行和激活；
- 当前默认输入状态与切换快捷键；
- 个人词典词条数、学习记录数和剪贴板记录数；
- 未保存设置、配置诊断和更新等需要处理的事项；
- 进入常用页面的快捷入口。

概览仅显示摘要，不复制其他页面的完整操作表单。点击摘要或警告进入对应页面。

### 4.3 视觉风格

- 使用系统主题提供的背景和文字颜色，支持跟随浅色或深色主题；
- 使用单一强调色标识选中导航、主要按钮和活动状态；
- 使用轻边框、适度圆角和明确留白建立层级，不使用大面积渐变、装饰插画或高饱和配色；
- 危险操作只使用红色，正常、警告和失败状态同时提供文字，不只依赖颜色；
- 控件密度以桌面设置工具为准，普通页面优先一列布局，列表和数据页使用更高信息密度。

### 4.4 底部操作栏

底部操作栏固定显示：

- 当前修改状态；
- 最近一次跨页面任务的结果；
- `恢复修改`；
- `应用`；
- `保存并关闭`。

`恢复默认`属于低频且有影响的操作，移动到输入体验页或窗口菜单中，并在执行前说明影响范围。

## 5. 功能设计

### 5.1 客户端基础体验

#### 设置搜索

搜索索引覆盖页面标题、设置名称、说明文字和常见别名。结果显示所属页面和简短说明，选择后跳转页面并聚焦对应控件。搜索在本地完成，不记录搜索内容。

#### 输入体验

集中管理：

- ModernIME 启用状态；
- 默认中文或英文状态；
- 中英文切换快捷键；
- 中文全角标点；
- 数字键选择候选；
- 方向键移动候选；
- 上下方向键和 `+`/`=` 翻页。

快捷键录入提供格式校验和客户端内重复检查。无法可靠探测的系统全局冲突显示提示，不做虚假的“无冲突”保证。

#### 设置生命周期

所有普通设置先写入内存草稿。统一校验通过后才允许保存。保存成功后更新已保存快照，并提示是否需要重载；保存失败时保留草稿和原文件。

关闭存在未保存修改的窗口时提供继续编辑、放弃修改和保存后关闭三种选择。

### 5.2 个人词典

个人词典支持：

- 按拼音、词条和分类搜索；
- 添加、编辑、删除和批量删除；
- 批量选择与分类管理；
- 导入前预览新增、更新、重复、冲突和无效条目；
- 对冲突选择保留现有、使用导入值或提高现有权重；
- 导出全部、筛选结果或选中词条；
- 自动去重和非法拼音、非法权重、非法 UTF-8 校验。

导入先完整解析到临时数据集，用户确认后原子替换。任一校验失败都不得覆盖现有词典。

### 5.3 剪贴板

剪贴板页面支持：

- 本地历史搜索和内容预览；
- 复制、删除、批量删除和清空；
- 固定常用条目，固定条目不受容量淘汰影响；
- 配置普通历史最大数量；
- 排除空白、过长内容和疑似敏感内容；
- 暂停记录和立即清理全部历史。

敏感内容排除使用本地规则，并允许用户查看规则说明。客户端不上传剪贴板内容，诊断报告也不得包含历史正文。

### 5.4 智能学习

智能学习页面支持：

- 用户学习和上下文学习独立开关；
- 学习记录总量、最近更新时间和数据库大小；
- 按词条搜索学习记录；
- 选择性删除异常记录；
- 暂停学习但保留已有数据；
- 清空前自动备份并验证备份可读取；
- 从有效备份恢复学习数据。

页面必须明确区分“暂停学习”“清空学习数据”和“恢复默认设置”，避免用户误认为三者效果相同。

### 5.5 数据与备份

数据与备份页面统一管理设置、词典、学习数据库和剪贴板历史。

备份文件包含版本化清单、每个数据文件的类型、大小和校验信息。恢复前显示备份版本、包含内容、目标位置和将被覆盖的数据，并允许按数据类别选择恢复。

恢复过程为：校验备份、创建当前数据安全副本、写入临时目标、原子替换、重新读取验证。任一步失败都恢复到操作前状态，并保留可用于人工恢复的安全副本。

### 5.6 系统与诊断

系统与诊断页面显示：

- `fcitx5-remote` 是否可用；
- Fcitx5 是否运行；
- 当前输入法；
- ModernIME 是否激活；
- 配置文件、词典、数据库和用户目录是否可读写；
- 配置语法、数据库完整性和必要依赖检查结果。

页面提供刷新状态、重新加载 ModernIME、复制诊断摘要和导出诊断报告。诊断结果按“正常、建议、需要处理”分组，每个问题给出具体下一步操作。

诊断报告默认移除用户主目录、剪贴板正文、词典正文和其他个人内容，只保留必要的版本、状态、计数和脱敏路径。

### 5.7 联网与更新

联网与更新页面的三项能力独立控制：

- 版本检查：只读取公开版本信息；
- 词库更新：显示来源、版本、大小、校验值和更新内容，下载后校验再安装；
- 配置同步：在明确选择同步目标和数据类别后执行，不默认包含剪贴板历史和学习正文。

三项功能默认关闭，界面不得通过预选复选框、模糊按钮或关闭困难等方式诱导启用。关闭后停止对应后台任务，并允许删除该功能产生的缓存或凭据。

具体远程服务、认证方式和协议不在第一阶段实现计划中确定；第三阶段开始前必须为选定服务补充独立设计和威胁审查。第一、二阶段不显示联网入口；第三阶段只有在对应联网能力实现并通过验收后才显示入口，不能先显示不可用页面。

## 6. 代码架构

### 6.1 UI 层

- `SettingsApplication`：启动、单实例和窗口生命周期；
- `SettingsShell`：导航、页面容器、搜索、底部操作栏和全局通知；
- 页面组件：每个一级页面使用独立类和源文件；
- 共享组件：设置行、状态徽标、空状态、确认对话框、任务进度和提示条；
- `PageRegistry`：登记页面元数据、搜索词条和页面跳转目标。

现有大型 `settings_window.cpp` 在重构后只保留窗口组合和少量全局协调，不继续承载各页面的数据操作实现。

### 6.2 服务层

- `SettingsService`：设置草稿、统一校验、保存快照和原子写入；
- `DictionaryService`：查询、批量编辑、导入预览和导出；
- `ClipboardService`：历史查询、固定、删除、容量和隐私规则；
- `LearningService`：统计、查询、选择性删除、备份与恢复；
- `BackupService`：备份清单、校验、恢复和回滚；
- `RuntimeController`：复用并扩展当前运行状态和重载能力；
- `DiagnosticsService`：本地检查、修复建议和脱敏报告；
- `NetworkConsentService`：联网授权状态和每项能力的独立门槛。

服务层通过明确的结果类型返回成功、用户可读摘要和可记录的技术详情，不直接操作 GTK 控件。

### 6.3 异步任务

词典导入、大数据读取、备份恢复、诊断和联网操作不得阻塞 GTK 主线程。任务在后台执行，通过 GTK 主循环提交进度和结果。窗口关闭或用户取消时设置取消标记；不可安全中断的原子替换阶段完成后再响应取消，避免生成半写入状态。

## 7. 错误处理与数据安全

### 7.1 反馈层级

- 控件级：就地显示输入错误并阻止无效提交；
- 页面级：展示数据为空、文件损坏、权限不足或功能未启用等状态；
- 全局级：展示保存、恢复、重载等跨页面任务结果，并允许展开和复制详情。

普通提示使用用户能够执行的语言。原始技术错误保留在可展开详情中，不替代用户说明。

### 7.2 写入与恢复

- 设置、词典和剪贴板文件使用临时文件加原子替换；
- SQLite 操作使用事务；
- 导入在替换前完成全部解析和校验；
- 清空学习数据前创建并验证备份；
- 恢复数据前保存当前状态，并在验证失败时自动回滚；
- 外部命令使用参数数组执行，不拼接用户输入到 shell；
- 所有数据只作用于 `SettingsPaths` 推导的当前用户目录。

## 8. 分阶段交付

### 阶段一：客户端基础体验

- 拆分窗口外壳和共享组件；
- 实现概览、导航、设置搜索和统一通知；
- 重组输入体验页；
- 完善快捷键校验、保存生命周期和自动重载提示；
- 完成主题、键盘导航、窗口缩放和基础无障碍验收。

### 阶段二：本地数据中心

- 完善个人词典批量操作、导入预览和冲突处理；
- 完善剪贴板搜索、固定、隐私规则和容量管理；
- 完善学习记录查询、选择性删除和恢复；
- 实现统一备份、恢复、校验和回滚。

### 阶段三：诊断与可选联网

- 实现本地诊断、修复建议和脱敏报告；
- 完善 Fcitx5/ModernIME 状态和重载流程；
- 建立联网授权与独立开关；
- 在选定远程服务并完成独立设计与威胁审查后，分别实现版本检查、词库更新和配置同步。

每个阶段必须形成完整可用的交付物。后续阶段未开始时，界面不显示不可用的占位入口。

## 9. 测试与验收

### 9.1 自动化测试

- 单元测试：设置校验、搜索索引、冲突处理、备份清单、隐私脱敏和联网授权门槛；
- 数据集成测试：词典、剪贴板、学习数据库的导入、编辑、备份、恢复和失败回滚；
- GTK 交互测试：导航、未保存状态、控件禁用关系、对话框、键盘焦点和窗口缩放；
- 运行时测试：Fcitx5 未运行、命令缺失、命令超时、重载失败和恢复路径；
- 安装测试：CMake 构建、CTest、用户前缀安装和桌面入口。

### 9.2 人工验收

- 浅色和深色系统主题；
- 默认窗口、最小支持窗口和较大窗口；
- 空数据、正常数据和大量数据；
- 完全离线、联网功能关闭和单项联网授权；
- 纯键盘完成页面切换、设置修改、保存和主要数据操作；
- 保存失败、导入失败、恢复失败、运行时不可用等错误路径。

### 9.3 完成定义

一个功能只有同时满足以下条件才算完成：

1. 正常路径可用；
2. 空状态、加载状态和失败状态均有明确反馈；
3. 破坏性操作有确认和恢复措施；
4. 自动化测试覆盖关键规则和失败边界；
5. 完整构建、CTest、安装验证和客户端启动冒烟测试通过；
6. 界面中没有占位按钮、虚假成功提示或默认联网行为。

## 10. 成功标准

- 新用户可以从概览页理解 ModernIME 当前状态，并在两次导航内找到常用设置；
- 高级用户可以完整管理词典、剪贴板、学习数据、备份和诊断，无需手动编辑内部文件；
- 客户端在大数据操作、运行时检查和网络操作期间保持响应；
- 任一保存或恢复失败都不会破坏原数据或丢失当前设置草稿；
- 未经明确授权，客户端不产生任何联网请求；
- 三个交付阶段均可独立构建、测试、安装和使用。
