# 拼音智能纠错与预编辑动态分词接口（客户端交接）

2026-11-20。后端及配置存储已接入「拼音智能纠错 / 漏键容错」与「预编辑（Preedit）音节分隔符 `'` 动态重排」配置接口，GTK 设置客户端尚未新增对应 UI 控件。客户端仍维持既有八个模块。

## 客户端建议入口与行为

- 建议放置在「输入与按键 → 拼音与状态 → 拼音方案」卡片内（位于「输入方案」下方或「模糊音」上方），跟随 `input.enabled`（`state.dependentControlsSensitive`）控制可交互状态，建议同时接入 `tools/settings/page_registry.cpp` 的搜索索引。
- 推荐文案（遵循一句话加示例规范）：
  1. **拼音智能纠错**：`允许自动纠正全拼漏键、换位及邻键误触，如 xanch→线程、jnch→进程、xina→xian。`
  2. **预编辑动态分词**：`跟随当前首选词动态调整音节分隔符 '（如 x'an→xan'ch），始终保留原始输入字母与手动输入的 '。`
- 注意：两项功能仅对「全拼 / 简拼」模式生效；双拼模式保持双拼自身解析与 preedit 规则。继续沿用 `SettingsWindowModel` 的读取、草稿修改、`dirty()/changes()`、`save()`（冲突检测及 `rawLines` 保留）与放弃流程，不在 GTK 回调中新增同步磁盘 I/O。

## 配置与存储接口

公共头文件：[settings.h](file:///home/wsl/ModernIME/core/include/modernime/core/settings.h)（`modernime::core::ModernIMESettings`、`SettingsStore`）。配置文件默认路径为 `SettingsPaths::fromEnvironment(...).settingsFile`（`~/.config/modernime/settings.conf`）。

| C++ 字段 | 配置键 | 类型 / 默认值 | 说明 |
|---|---|---|---|
| `ModernIMESettings::typoCorrectionEnabled` | `pinyin.typo_correction` | `bool`，默认 `true` | 开启/关闭全拼漏键容错（如 `xanch→线程`、`jnch→进程`）、音节内部换位（如 `xina→xian`）及邻键容错（如 `juncheng→进程`）。关闭后仅保留精确全拼、简拼与手动词典匹配。 |
| `ModernIMESettings::dynamicPreeditSeparator` | `pinyin.dynamic_preedit_separator` | `bool`，默认 `true` | 开启/关闭预编辑串 `'` 跟随 Top-1 候选音节边界的动态插入与合并重排（如 `x'an` → `xan'ch` → `xan'cheng`，退格恢复 `x'an`）。关闭后 `page().preedit` 原样展示 `rawInput`（用户手动输入的 `'` 仍保留），不影响候选与部分消费切分。 |

配置示例（`settings.conf`）：

```ini
pinyin.typo_correction=true
pinyin.dynamic_preedit_separator=true
```

客户端读取与保存示意：

```cpp
// 通过 SettingsWindowModel（tools/settings/include/modernime/settings/settings_model.h）
auto settings = model.settings();
settings.typoCorrectionEnabled = true;
settings.dynamicPreeditSeparator = true;
model.setSettings(std::move(settings));
// model.changes() 已接入：
//   group = "输入习惯", title = "拼音智能纠错"
//   group = "输入习惯", title = "预编辑自动分词"
// 最终由现有主窗口保存流程调用 model.save() 写盘，Fcitx5 引擎约 2 秒配置轮询热生效。
```

## 引擎与嵌入式 Provider 接口（供需要直连引擎的消费者）

公共头文件：[pinyin_candidate_provider.h](file:///home/wsl/ModernIME/algorithm/pinyin/include/modernime/pinyin/pinyin_candidate_provider.h)（Fcitx5 适配层 [inputmethod.cpp](file:///home/wsl/ModernIME/adapter/fcitx5/src/inputmethod.cpp) 已完成 `pinyinOptions(settings)` 接线，支持热载立即生效）。

1. **`PinyinProviderOptions` 字段**：
   - `bool typoCorrectionEnabled = true;`
   - `bool dynamicPreeditSeparator = true;`
2. **`PinyinCandidateProvider` 运行时切换接口**：
   - `void setTypoCorrectionEnabled(bool enabled);`（变更后自动刷新当前组合页与候选）
   - `void setDynamicPreeditSeparator(bool enabled);`（变更后自动刷新当前 `page().preedit`）
   - `void applyOptions(const PinyinProviderOptions &options);`（支持同时热更新两项开关并触发刷新）
3. **只读消费输出**：
   - `page().preedit`：直接读取已按 Top-1 raw span 重排（或原样保留）的预编辑串，客户端无需自行推断或改写分隔符。
   - `page().items[i].consumedInputBytes`：始终对应原始击键字节数（`rawInput` 消费跨度），选词与学习统计不因动态 `'` 或纠错而错位。
