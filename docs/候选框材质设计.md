# 候选框材质设计

2026-11-12。适用于原生 X11 自绘候选栏、剪贴板菜单及设置中的同源预览。

## 调研与取舍

- [OriginOS 官方设计介绍](https://www.vivo.com.cn/originos)：以自然光影、昼夜明暗关系和不同表面质感建立层次。借鉴统一的光照方向，以及浅色、深色分别处理材质的方式。
- [Apple 图标设计规范](https://developer.apple.com/design/human-interface-guidelines/app-icons)：简洁的核心形状、清楚的轮廓和有序的前后层次可以同时存在。简约应减少视觉元素，仍需把已有形状做精细；无需靠细碎装饰表达品质。
- [Apple 材质规范](https://developer.apple.com/design/human-interface-guidelines/materials)：材质应表达层级并保持内容可读，过多玻璃效果会干扰信息。候选文字是高频阅读内容，因此使用密实表面，不采集桌面背景制作透明或折射效果。
- [Fluent 材质](https://fluent2.microsoft.design/material)与[层次规范](https://fluent2.microsoft.design/elevation)：实色也是完整材质；一致的受光方向、明确边缘与柔化阴影共同表达表面间的距离。采用有界渐变阴影，替代重复叠加半透明矩形。

以下是对这些原则在输入法小尺寸浮层中的设计转译，不表示复刻厂商系统或实现其原生玻璃渲染技术。

## 三档共同品质与差异

| 风格 | 表面与选中态 | 视觉重点 |
|---|---|---|
| 简约 | 密实哑光、轻薄边缘、淡彩选中面与清楚的同色系文字 | 少量形状，靠比例、边缘精度和微弱明暗完成表面；取消下划线装饰 |
| 标准 | 稳定实色、明确选中块、柔化外阴影 | 阅读和操作状态直接清楚，延续原有色彩关系 |
| 质感 | 磨砂底面、左上宽域柔光、微光内缘、带接触阴影的选中面 | 光照方向一致，前后层次更明显，避免厚重高光条与噪点纹理 |

颜色全部由当前候选配色推导；深色表面与浅色选中块分别控制受光和暗部。九套候选配色、三种轮廓与三档材质相互独立，高对比配色始终保留实色边界。

材质不改字体、候选测量、分页、点击身份或排序；光影留在既定绘制范围内。设置预览共享生产渲染器，新增光照颜色接入已有可打断过渡与禁用动画偏好。阴影使用固定数量的渐变块，不在每次按键中创建模糊位图或启动常驻动画。
