## 设计与边界

- 六个可见入口：工作台、输入习惯、候选与外观、我的词语、剪贴板、维护。保留八个 SettingsPageId 和 CLI/DBus 别名，Learning 映射到词语内学习记录、Updates 映射到维护内更新。
- 输入习惯含拼音/按键/辅助/学习行为分区；我的词语含词条、短语、学习记录、词库包；维护含状态、应用诊断、备份、更新。
- 候选持续预览与调节区分离；实际大小/适应窗口、原效果比较、中文/长词/英文/读音样例共享生产渲染器，不改候选算法。
- 内容管理使用固定搜索操作区和列表详情联动；即时管理与独立草稿明确标注，保留原冲突/事务/生命周期。
- 默认主题采用石墨色导航、浅色工作面和蓝色强调；工作台突出试输入，内容入口显示数量，列表与详情分区。保留七套客户端主题、候选材质、平面选中与键盘焦点；支持 720×520 至宽窗口。
- 保存区说明设置变更范围与条数，显示独立短语草稿；错误可持续查看。全局恢复默认移到维护，完整搜索可访问全部匹配项。
- 不改输入算法、数据格式、学习库恢复契约、包管理安装协议。生产安装仅使用已验证客户端及所需匹配产物，保留回退与用户数据。

跨任务接口（不改变已有构造调用）：

- `LearningPage::takeBehaviorWidget()`：将学习开关分区从本页取出，返回持有一个引用的 GtkWidget，调用方装入输入页后释放此引用；`setEmbedded(bool)` 隐藏嵌入页的重复标题。
- `InputPage::setLearningControls(GtkWidget*)`：接收有外部引用的分区并纳入任务分类；`focusTarget` 支持 learning-enabled/context-learning。
- `DictionaryPage::setLearningPage(GtkWidget*, std::function<void()>, std::function<bool(std::string_view)>)`：增加学习记录页签，接收其刷新与定位回调；`showLearning()`；focusTarget 转交学习 target。
- `DictionaryPage::setStateChanged(std::function<void()>)`、`QuickPhraseEditor::setStateChanged(std::function<void()>)`：草稿或在途状态变化通知壳层，仅传播状态，不合并保存事务。
- `DiagnosticsPage::setUpdatesPage(GtkWidget*, std::function<void()>, std::function<bool(std::string_view)>)`、`showUpdates()`；`UpdatesPage::setEmbedded(bool)`。
- 共享页面 helper 支持通过 `g_object_set_data(page, "modernime-page-fixed-content", widget)` 指定页面需固定的顶部区域；`createScrollablePage` 仅滚动其余内容，兼容原 page target 与焦点定位。页面若自管滚动则设置 `modernime-page-self-scrolling`。
