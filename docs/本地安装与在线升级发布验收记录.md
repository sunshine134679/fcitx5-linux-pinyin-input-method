## 6. v0.1.14 线上构建阻断定位与 v0.1.15 修复事实

- **Run ID**：39223521919 (Release)
- **失败 Job**：
  - `Build Standalone Tarball (glibc 2.34+ Baseline)` (ID: 117964239915)
  - `Build Ubuntu DEB (ubuntu-22.04)` (ID: 117964239989)
- **根本原因**：
  Ubuntu 22.04 LTS 默认使用 GCC 11。`core/include/modernime/core/learning_writer.h` 中使用了 `std::optional<CommitEvent>`，但在该头文件中未直接 `#include <optional>`。在 Ubuntu 24.04 (GCC 13/14) 下该头文件被隐式传递包含，而在 GCC 11 下报错：
  `error: ‘optional’ in namespace ‘std’ does not name a template type`
- **合规处置**：
  按照规定“源码修复使用新提交/版本，不移动已发布标签或强推覆盖”，保留不可变标签 `v0.1.14`，在 `core/include/modernime/core/learning_writer.h` 中显式补齐 `#include <optional>`，并将版本递增为 `0.1.15`，以全新标签 `v0.1.15` 启动交付。
