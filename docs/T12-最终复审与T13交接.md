## 3. T13 不可放宽的契约

### 3.1 结果协议与期限

采用原计划的 `CommandSpec` / `CommandResult`、`CommandMode::{Query, PackageTransaction}`、`CommandState::{NotStarted, Exited, Continuing, Unknown}`，包含 operationId、argv、Environment、timeout、CaptureLimits、exitStatus、每流 truncated 和输出。

- 未启动、已退出、继续执行、未知必须可区分；已退出且非零不能被映射为成功。
- 更新查询默认 5 秒；包操作默认等待 300 秒，等待期结束只返回 Continuing，采集器继续拥有事务。
- 超时不强杀包操作，不重新分配 operationId，不自动重试，不因窗口/GUI 退出宣布完成。
- 未知身份或结果进入原操作的 Uncertain。信号中断维持 T12 既有保守语义；正常非零退出按已确认失败交付。
- collector 无法启动/握手失败时不得启动包命令；collector 异常后不能把“观察不到”当作“成功结束”。
- PID 存在或不存在都不是充分身份/结果证据；使用每操作唯一标识和可验证的进程身份，不读旧操作文件替代当前结果。具体编码和身份实现由执行方选择并测试。

### 3.2 资源预算

| 资源 | 上限与行为 |
|---|---|
| Query 返回的 stdout / stderr | 每流 ≤1 MiB；超出明确 truncated，不能用残缺输出宣称“已最新” |
| PackageTransaction 返回的 stdout / stderr | 每流 ≤64 KiB，保留尾部；超过仍持续排空并丢弃旧字节 |
| collector 捕获驻留 | 每流 ≤1 MiB；记录捕获缓冲峰值，辅以进程内存基线/增量，不要求整个含动态库进程 RSS ≤2 MiB |
| 临时诊断输出文件 | 每流 ≤1 MiB，不使用无限增长普通文件 |
| 控制状态文件 | ≤4 KiB，状态不携带无限日志 |
| T12 全局完成队列及 last output | 队列仍为 8 项，存储同样有界的输出；消费者不能通过全局 last stdout 错配旧 ID 的结果 |

不能只截断最终 600 字消息后宣称资源有界。输出字节增加时，缓冲、文件和最终结果均须保持预算。不得用 RLIMIT_FSIZE、停止读取管道或强杀命令限制包事务输出。

### 3.3 生命周期与安全执行

- collector 使用同一个安装的 `modernime-settings` 可执行文件，不引入额外常驻服务或未声明依赖。
- 每操作独立的私有目录、控制/结果文件 0600；避免符号链接、部分写入和旧文件造成身份混淆。状态发布需要可验证的完整性，读取大小有上限。
- 直接传 argv 和受控 Environment，不 shell 拼接/eval；不把认证信息或全套环境变量写入日志。
- GUI 退出后 collector 和假包命令继续运行，stdout/stderr 仍有读取者；collector 自身也不能因 GUI 关闭的日志通道而收到 SIGPIPE 退出。
- 查询的子孙继承输出 FD 不能让控制循环无限等待 EOF；查询取消只处理自己拥有的查询资源，不影响包事务。
- 清理只针对自己拥有且确认可清理的操作资源；不能删仍在运行/未知事务的控制文件以假装恢复 Idle。
- RuntimeController 不是本轮强制迁移对象。若共享执行机制，保留其现有 1500ms 查询、200ms 启动探测、启动时 stdout/stderr silence、启动后 daemon 可继续运行，以及无焦点时空 `fcitx5-remote -n` 的合法语义。
