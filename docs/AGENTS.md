# 文档命名与跨对话协作要求

本目录所有文档工作遵守用户 2026-10-18 起的中文命名要求。

1. 新建计划、审查、验收和交接文档使用中文文件名，保留 T19/R1/日期等稳定编号；Git 提交说明使用中文。
2. 开始或恢复任务前读取 `中文命名与协作约定.md`；完整旧名→中文名映射见 `文档名称映射.json`。本机跨工作树共享入口为 `/home/wsl/ModernIME/docs/中文命名与协作约定.md`。
3. 旧英文路径为兼容入口，禁止将中英文维护成两份正文。若当前冻结 worktree 仍保留英文实体和中文别名，应使用本工作树版本；由协调者在后续单独文档提交中迁移，不能复制主检出的旧正文覆盖本树新验收结果。
4. 不改写历史提交、冻结实现 SHA、测试报告、任务状态与判定；不修改程序固定入口或源码标识符。不替其他任务提交文件，不使用 git add . 把本机通知和其他人的工作一并提交。
5. 正在运行的对话可能尚未重新读取文件，不能声称落盘通知等于消息已送达或已确认。
