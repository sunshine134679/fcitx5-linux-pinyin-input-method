# 中文命名与协作约定

- 新建维护、交接、计划和说明文档使用中文文件名；Git 提交说明使用中文。保留稳定任务编号、代码标识符、API 及工具约定文件名。
- 中文文件是正文；仍保留的英文兼容入口使用相对符号链接，编辑同一份正文，避免重复事实来源。
- 修改前读取根目录与适用子目录的 `AGENTS.md`，维护底线见[项目基础与 AI 修改护栏](项目基础与AI修改护栏.md)及[检查清单](AI改动前后检查清单.md)。
- 不改写历史提交、冻结源码或原始验收结论；迁移文件不等于重新通过验收。
- 完成任务后优先更新现有维护文档。一次性日志、截图与构建结果存放于忽略的 `build/`，需要长期保留的本机资料归档到项目外。
