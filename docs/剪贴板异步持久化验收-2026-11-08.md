# 剪贴板异步持久化验收（U10）

状态：实现、full/core-only回归、图形补测与独立审查整改已完成；本批以本地分支交付，整体产品升级继续进行。实施基线 `36083be0d03365de51c4127c4d0d58df75bad766`，分支 `codex/input-correctness`，主平台 Ubuntu 24.04 + GNOME。未部署、推送或修改日常剪贴板历史。

## 实现与用户行为

历史的启动加载、重载、锁内读写、fsync及失败重试由单一worker负责。主线程负责采集资格、观察身份和有界观察批次；批次在后台重载后解释，避免按旧历史顶部错误丢弃清空后的新复制。每批至多first+tail 31项，历史和合法pending各30项，每项1MiB；沿用稳定文件锁、原子替换、0600权限和持久格式，无新外部依赖。

V+2初始加载显示不可提交的“正在读取剪贴板”，加载失败显示“剪贴板暂不可用”。完成只刷新仍打开且允许更新的占位页，并使旧选择代次失效；Esc取消后不会重开。已打开的正常列表保留原顺序，新历史在重新打开时采用。共享不可变快照避免每键复制完整历史；兼容原设置历史接口。保存为非阻塞请求，析构停用通知后等待在途工作并有限尝试保存，错误仍报告。内核I/O永久挂起时不保证强制无损退出。

文件身份缓存对应读取前状态，读取失败不接受身份；保存后使缓存失效，避免把旧内容与外部刚清空的新身份绑定。物理删除能重载为空。采集排除区间、恢复基线、原同步断言、200,000条学习容量、模型及排序保持。

## 范围与回退

真实桌面应用复制链、GNOME原生Wayland、跨DPI/副屏、托盘及长期耐久未由此证明。采样前正常复制可能被恢复基线保守跳过，未报告敏感状态、复制来源和采样间同文本复制仍受原API限制。慢盘期间合并有界批次，不保证无限历史或每次中间观察独立fsync。

独立审查另列范围边界：既有不可读文件按损坏文件隔离的分类、隔离时与外部写入的竞争，本批未修改或专项验证。新增文件身份和失败恢复测试不能证明该策略完整安全；作为后续维护缺口保留。

无数据迁移。回退只撤本批程序变更并完整重编译，不恢复旧文件覆盖用户新复制记录；原同步API与持久格式兼容。整体升级目标继续进行。
