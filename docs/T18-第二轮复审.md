## 2. S1 / P1：非法请求后的状态文件不是新观察，正式门禁接受真实 UI 副作用

位置：`settings_app.cpp::commandLine()` 的非法页提前返回、`dumpSettingsStateIfConfigured()`；脚本 Step 5。

结果：

- 独立从 mutant 的实际 GtkStack 读取并写下 `candidates`，证明最后的非法请求确实改变了 UI；
- 正式脚本仍读取旧文件中的 clipboard，未发现错误。

这是测试契约缺口，不是声称当前正常生产分支已存在该错误。
