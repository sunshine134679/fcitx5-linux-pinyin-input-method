## 二、第八轮缺陷物理根因修复详情

### R8-01 · P2：目录元数据操作吞错，可能将有效程序目录恢复成不可访问状态

#### 1. 缺陷现象与风险分析
在前版脚本 `scripts/modernime-migrate-channel` 中：
1. **准备阶段（冻结）**：元数据引用文件先通过 `touch -r` 创建，随后在调用 `chmod --reference ...` 时附加了 `2>/dev/null || true`。当权限冻结失败（例如权限受限或测试注入返回非零退出码）时，错误被无声忽略，函数返回成功，且残缺的引用文件被记录进元数据清单 `target-dir-mtime.txt` 中。这导致迁移流程继续进行，甚至执行卸载和包步骤。
2. **恢复阶段（回滚）**：回滚阶段从引用文件取权限还原到目标目录时，若引用文件此前未成功复制原目录权限（为普通创建文件的掩码默认权限，如 0664），或回滚过程中的 `chmod`/`touch -r` 失败，脚本同样忽略了错误，未标记 `rollback_failed` 或 `target_restore_failed`。系统不仅会误向用户输出 `Original installation restored`，更会进而执行清理步骤将 `$temp_work` 事务材料删除，导致原本可执行的程序目录因执行位丢失变质为无法访问（EACCES），且人工救援材料被销毁。

#### 2. 物理根因治理措施
在 `scripts/modernime-migrate-channel` 中实施彻底的错误感知、传播与事务阻断机制：

1. **`record_target_dir_metadata()` 严格检验并原子清理**：
   - 在采集引用文件属性时，彻底移除 `2>/dev/null || true` 吞错语句；
   - 严格检查 `touch -r` 和 `chmod --reference` 的执行状态；
   - 若任一指令执行失败，立即捕获实际退出码 `$?`，清理已创建的半成品引用文件，并不向清单记录该条目，直接返回非零退出码：
     ```bash
     record_target_dir_metadata() {
         local dir_path="$1"
         local rel_path="$2"
         if grep -q -E "^${rel_path}\t" "$target_dir_mtime_list" 2>/dev/null; then
             return 0
         fi
         dir_ref_idx=$((dir_ref_idx + 1))
         local ref_file="$target_mtime_refs/ref_$dir_ref_idx"
         local rc=0
         touch -r "$dir_path" "$ref_file" 2>/dev/null || {
             rc=$?
             rm -f -- "$ref_file" 2>/dev/null || true
             return "$rc"
         }
         chmod --reference="$dir_path" "$ref_file" 2>/dev/null || {
             rc=$?
             rm -f -- "$ref_file" 2>/dev/null || true
             return "$rc"
         }
         printf '%s\t%s\n' "$rel_path" "$ref_file" >> "$target_dir_mtime_list"
         return 0
     }
     ```
2. **准备阶段两处调用点故障阻断**：
   - 在主程序扫描和子目录扫描的两处 `record_target_dir_metadata` 调用点，均添加返回码检查：
     ```bash
     record_target_dir_metadata "$pre_file" "$rel" || {
         cp_ec=$?
         printf 'Error: Failed to record directory metadata for %s (exit %d)\n' "$pre_file" "$cp_ec" >&2
         printf 'Pre-migration backup incomplete; aborting migration to protect existing installation.\n' >&2
         printf 'Transaction materials and diagnostics preserved at: %s\n' "$temp_work" >&2
         exit "$cp_ec"
     }
     ```
   - 确保权限冻结失败时立即以底层错误码（如 74）退出，保留全部事务现场与诊断材料，**绝不调用后续的包安装或源卸载步骤**。
3. **恢复阶段（`restore_original_channel`）错误汇聚与状态保护**：
   - 在回滚应用引用文件属性时，移除对 `chmod` 和 `touch -r` 的错误抑制；
   - 捕获执行失败并将错误信息重定向至 `$temp_work/target_chmod.err` 与 `$temp_work/target_touch.err`；
   - 一旦失败，显式设置 `target_restore_failed=true` 及 `rollback_failed=true`，输出详细错误日志；
   - 在存在任何回滚失败时，阻止事务目录清理，向用户输出完整的现场位置与手动救援指南，**绝对不输出 `Original installation restored`**：
     ```bash
     if ! chmod --reference="$ref_file" "$target_dir" 2>"$temp_work/target_chmod.err"; then
         target_restore_failed=true
         rollback_failed=true
         printf '[ROLLBACK] Error: Failed to restore directory permissions for %s\n' "$target_dir" >&2
     fi
     if ! touch -r "$ref_file" "$target_dir" 2>"$temp_work/target_touch.err"; then
         target_restore_failed=true
         rollback_failed=true
         printf '[ROLLBACK] Error: Failed to restore directory timestamps for %s\n' "$target_dir" >&2
     fi
     ```
