# ModernIME v0.2.8

本版修复 openEuler 实机发现的会话恢复问题：异常退出后自动重启 Fcitx5，并恢复最近一次采样的输入法及激活状态，减少“进程恢复了却只能输入英文”的情况。

## 会话启动与异常恢复

- 会话自启和 `modernime-session-init` 使用 `modernime-session-runner` 管理自己启动的 Fcitx5 前台进程，不依赖 GNOME 或 systemd 的图形会话目标。
- 强杀、崩溃等异常退出后，按 1、2、4 秒间隔最多重启三次；稳定运行一分钟后重置次数，避免持续启动失败时无限重试。
- 支持 `fcitx5-remote --check` 时，每半秒采样有焦点时的输入法标识与激活状态，异常重启后恢复最近一次采样。原先使用中文时继续中文，原先切到英文时保留英文。
- 初始化状态查询使用 `--check` 避免经 D-Bus 抢先启动非受管实例。更旧版本没有此选项时保留原有激活方式，可通过登录自启获得受管启动。
- 正常退出、会话总线或原有 Xauthority 消失后停止恢复；重复启动不会创建第二个受管实例，也不替换其他入口已启动的 Fcitx5。

状态快照仅存在于内存，不保存输入文字，不修改个人设置、词典或学习数据。崩溃瞬间尚未采样的切换和未上屏内容无法恢复；此机制只监护它自己启动的 Fcitx5，不负责恢复监护程序自身被强杀的情况。

## 升级后启用

继续提供 Ubuntu 24.04 amd64 DEB、openEuler x86_64 RPM 和 Linux x86_64 便携归档，沿用现有签名公钥及 APT/DNF 软件源。请沿用当前安装渠道升级。

在普通用户的桌面终端中执行以下命令，正常退出已有实例并刷新自启入口、启动受管会话：

```bash
fcitx5-remote -e
modernime-session-init
```

自定义安装前缀、配置或数据目录时，初始化仍需沿用对应的 `MODERNIME_PREFIX`、`MODERNIME_CONFIG_HOME`、`MODERNIME_DATA_HOME`。下一次登录也会通过更新后的自启入口启动。

## 已验证范围

- openEuler 24.03 LTS-SP4、UKUI/X11 的真实 GTK3 输入框：中文输入、强杀后约 1.07 秒生成新进程、无需人工激活继续输入“中国”、英文模式保留、正常退出不再拉起。
- 核对实际运行父进程及插件映射 inode；设置、个人词典与学习库逻辑快照一致，数据库完整。剪贴板正常追加一条，原历史条目完整保留。
- 三项直接相关的启动、恢复及安装环境检查通过。发行流程继续执行完整回归、安装升级、包内容及生产签名门禁。

上述桌面实测不代表其他应用、桌面环境或 Wayland 场景已完成专项验收。
