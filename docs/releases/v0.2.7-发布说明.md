# ModernIME v0.2.7

本版改善设置客户端的更新说明阅读体验与概览交互，并整理项目中的过期过程资料。

## 更新说明与在线查询

- 更新说明按标题、段落、列表、代码和链接显示，正文可选择、复制，文档相对链接指向对应发行标签。
- 展开更新说明时读取正式发布正文；公共 API 限流或正文为空时，尝试从同一发行标签读取说明文件。
- 加入限高滚动阅读区，修复展开后正文开头被裁掉、短说明留下过多空白的问题。
- 明确加载中与读取失败状态，支持重试和浏览器查看；后续本地检查不再覆盖已加载的正式正文。
- 统一版本详情、更新说明与升级指南的分组、间距和键盘焦点顺序。

## 概览与项目整理

- 统一概览与侧栏的候选、学习等图标，完善本地内容入口的悬停、按下及键盘交互反馈。
- 移除过期过程文档和重复兼容入口，保留当前维护规范、接口与各版发布说明；旧资料通过历史索引追溯。
- 本机构建副产物已整理，需保留的历史证据移至项目外归档；产品源码、测试、离线数据与用户个人数据继续保留。

## 发行门禁修复

`v0.2.6` 的发行回归被进程回收测试的时序问题阻断，未完成发行；保留原标签，改用新标签 `v0.2.7`。测试现在等待已有后台回收完成后检查资源，仍要求 1 秒内零残留及零僵尸；同时不再把 1 MiB 模拟输出直接写进测试日志。生产事务行为和资源预算不变。

## 更新与验证范围

继续提供 Ubuntu 24.04 amd64 DEB、openEuler x86_64 RPM 和 Linux x86_64 便携归档，沿用已有签名公钥及 APT/DNF 软件源。请沿用当前安装渠道升级，保留设置、个人词典、学习记录与收藏数据。

本轮针对客户端进行增量构建及更新页相关验证；正常 CI 与 Release 门禁继续检查发行构建、完整测试、性能、安装升级和生产签名。无显示环境的 GUI 跳过不计为通过。
