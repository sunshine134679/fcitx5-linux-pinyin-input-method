# ModernIME v0.2.17

- 补充「合法音节介韵母漏键」与「漏键 + 前后鼻音模糊音」复合纠错支持：如 `luoyegugen` / `luo'ye'gu'gen` / `luoyegugeng` / `luo'ye'gu'geng` 均以“落叶归根”为首选并保留原拼写，`xihun` / `jisunji` 等亦可稳定纠错召回。
- 增加合法音节守门保护：正常已有正音词（如 `dubuqi`、`gushi`、`hujia`、`wode`）跳过多余漏键解码，确保首选稳定且常规输入零额外开销；同时支持跨音节分隔符 `'` 进行前后鼻音模糊尾部匹配，并严守绝不跨手动音节内 `'` 合并边界。
- 放宽持续集成回放测试超时阈值至 1200 秒并补充性能门禁失败摘要注释。

请沿用原安装渠道升级，设置、主题、个人词典和学习数据继续保留。
