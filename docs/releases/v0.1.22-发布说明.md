## 1. 版本概述

ModernIME v0.1.22 是 v0.1.20 功能集的正式发布版本：**高频易错音内联读音提示（卡qiǎ住）、简拼部分消费范围修复、读音提示跨 fcitx5 链路传递修复**。

v0.1.20 与 v0.1.21 的 Release CI 均因 Ubuntu 22.04（LibIME 1.0.11）门禁失败而未产出资产（v0.1.18/v0.1.19 亦受同一问题影响，`releases/latest` 此前停留在 v0.1.17）。本版定位到**真实算法缺陷**并修复后重新发布。

## 2. 核心修复：模糊音组间晋升误伤简拼（ALG-RANK）

- **现象**：Ubuntu 22.04 上 `nh` 简拼的首选不是 `你好`。
- **根因**：2026-10-24 引入的 F1 组间晋升允许“学习增益 ≥1.8 且候选音节数等于输入段数”的 `prio=0` 候选进入高优先级组。该门槛把**简拼输入的段数误当作音节数**：Jammy 模型下 `nh` 的原生候选包含单字「你」(ni)，前序学习使其增益达到 2.08，于是被晋升并越过 trusted 简拼候选「你好」(`prio=1`)。现代模型（Noble）的 `nh` 原生候选不含「你」，因此本地与 24.04 未暴露。
- **修复**：F1 组间晋升新增“输入必须为全拼（每个音节均为标准音节）”条件；简拼、混拼与含非法音节的输入不再借用该通道。全拼下模糊音学习上位（`zongwen→中文`、`lali→哪里`）与单音节（`shi`）行为完全不变。
- **修复验证**：新增长期回归 `CandidatePriorRegression.LearnedSingleCharCannotHijackAbbreviationInput`（ranker 层、模型无关，先红后绿）；在 **Ubuntu 22.04 官方容器**中以 Release 构建复现并验证修复后 `modernime_pinyin_daily_simulation` 全 9 节通过。

## 3. 发布门禁基线标定（Legacy LibIME 1.0.11）

- 旧版语言模型下单字原生位次更深：「试/键」实测索引 6（仍在首页）、「破折号」索引 16（仍在第 2 页）。沿用既有 `hasAuditedLegacyProfile()` 行为探测，仅旧模型采用实测基线并打印实际排位；**现代模型保持前 5 与索引 0 的严格门禁**。
- `ge` 次选断言在旧模型下要求“仍是中文且英文原文不插队”，现代模型仍与原生次选完全一致。

## 4. 功能内容（同 v0.1.20）

### 4.1 高频易错音内联读音提示（卡qiǎ住）

- 输入 `kazhu`（把「卡住」的「卡」记成 kǎ）时，首选显示 `卡qiǎ住`；规范读音依据《现代汉语词典》第七版（动词义 qiǎ）。
- 离线词表 32 词（卡住/卡在/卡顿/卡壳/关卡/发卡/卡脖子、角色 jué、睡觉 jiào、银行 háng、说服 shuō、血液 xuè、粗犷 guǎng 等），由 `scripts/生成易错音词表.py` 逐字对 Unicode Unihan 五读音字段（含繁简形关联）校验后生成，随仓库离线发布。
- 仅当输入的无声调节节与该字规范读音不一致时提示；正确读音（`qiazhu`）、简拼（`kzhu`）、错位拼与非词表词（`卡着`）不提示。提示只影响展示。

### 4.2 简拼部分消费范围修复

- `zmhuishi` 首选恢复为全消费整句「怎么回事」；高频学习的「怎么」以真实部分消费（`zm`）居次席，选中后 `hui'shi` 保留在组合中。
- 读音提示字段完整穿过 Provider→引擎→fcitx5 候选列表→UI 重建全链路。

### 4.3 容错与学习链路强化（承接 2026-10-24 专项）

- 近音变体召回（`baoyan→表演`、`lui→六`）、换位+简拼混合修复（`wiesm→为什么`）、模糊音学习上位（`zongwen`）、提交后空有效窗口不再误扣词频。
- 不变量矩阵新增 #47~#51。

## 5. 平台兼容性与升级指南

### 5.1 安装渠道支持矩阵

| 资产文件名 / 渠道 | 适配发行版与代号 | 架构 | 最低系统要求 |
|---|---|---|---|
| `modernime_0.1.22_amd64_ubuntu22.04.deb` | Ubuntu 22.04 LTS (`jammy`) / Debian 12 (`bookworm`) | `amd64` (`x86_64`) | glibc ≥ 2.35, Fcitx5 ≥ 5.0.14, LibIME ≥ 1.0.11 |
| `modernime_0.1.22_amd64_ubuntu24.04.deb` | Ubuntu 24.04 LTS (`noble`) | `amd64` (`x86_64`) | glibc ≥ 2.39, Fcitx5 ≥ 5.1.7, LibIME ≥ 1.1.5 |
| `modernime-0.1.22-1.oe24.x86_64.rpm` | openEuler 24.09 (`oe2409`) / 24.03 SP4 | `x86_64` | glibc ≥ 2.38, Fcitx5 ≥ 5.0.14, LibIME ≥ 1.0.11 |
| `modernime-0.1.22-linux-x86_64.tar.gz` | Linux 便携免编译包 | `x86_64` | glibc ≥ 2.34, libstdc++ ≥ 3.4.30, Fcitx5 |
| 源码构建 (`./install.sh`) | 任意 Linux (含 ARM64, RISC-V) | 全架构 | C++20, CMake ≥ 3.24, GCC ≥ 10, Fcitx5-devel |

### 5.2 升级方式

- **源码升级**：`git pull --ff-only && ./install.sh`
- **APT**：`sudo apt update && sudo apt install --only-upgrade modernime`
- **DNF**：`sudo dnf upgrade --refresh modernime`
- **设置客户端**：「检查与更新」页面一键升级。
- 升级前自动备份学习数据库（SQLite WAL Checkpoint + Backup API 完整性校验、LMDB 备份）。
