# ModernIME v0.1.25 发布说明

日期：2026-11-02。此版本的安装包、软件源与源码由不可变标签 `v0.1.25` 的同一提交构建。

## 输入体验

- 修复冷词“子代理”、AI 术语的召回与混拼匹配，补充九项离线术语；只对经过回放的“子代理”“多代理”采用独立词典代价，保留 `zdl` 默认“战斗力”。
- 部分候选携带原始拼音消费边界，选择“子”后保留 `daili`，避免按显示字数误吞拼音；含分隔符和纠错路径均有回归。
- 补充“那你”“你继续”“说吧”口语片段，覆盖“那你继续说吧”等 29 项词语、长句首选与真实空格提交回归；保留“纳尼”等正常词的可选性。
- 混拼匹配沿用有界状态、扫描和候选预算，不改变学习资格、清空世代或持久格式。

## 客户端与更新

- 修复旧用户应用项的 `input-keyboard` 通用图标和已失效 ModernIME 绝对图标路径；保留自定义图标、注释、其他入口和启动命令。
- 修复启用索引验签后普通用户检查更新误报缓存不可用的问题：只读查询仅查看系统本地缓存，不重复访问 root 的私有验签密钥目录；实际刷新和升级继续遵循仓库元数据及包体验签配置。
- DNF 刷新指令及升级参数加入 `--refresh`，避免缓存仍有效时继续使用旧元数据。
- 更新页的实际流程是“检查更新 → 复制升级命令 → 在终端执行”，升级后重启 Fcitx5 加载新输入法插件。

## 存储与性能

LMDB 提交序号查询改为读取环境已提交事务信息，不再为查询序号创建只读事务；读槽耗尽时也能正确观察已提交的外部写入。保留生命周期锁、RO/RW 升级、200,000 条容量及原有性能断言，测量继续包含快照释放。

## 安装与升级

- Ubuntu 24.04：`sudo apt update && sudo apt install --only-upgrade modernime`。
- openEuler（已配置签名软件源）：`sudo dnf makecache --refresh && sudo dnf upgrade modernime`。
- 源码用户：检出 `v0.1.25` 后执行 `./install.sh`；不同安装渠道请先按 README 迁移。

预编译资产包括 Ubuntu 24.04 amd64 DEB、openEuler x86_64 RPM、Linux x86_64 便携包及校验文件。其他架构按源码构建。

发布前验证与发布后的真实 openEuler 旧客户端升级、图标及运行插件核验，记录在[发布与 openEuler 在线升级验收记录](https://github.com/sunshine134679/fcitx5-linux-pinyin-input-method/blob/main/docs/v0.1.25-发布与openEuler在线升级验收记录.md)。该记录区分已执行结果与待验证项目；本发布说明不提前宣称远程实机升级成功。
