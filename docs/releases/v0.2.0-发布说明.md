# ModernIME v0.2.0 发布说明

日期：2026-11-09。主验证平台为 Ubuntu 24.04 / GNOME 46.2。[v0.2.0 已正式发布](https://github.com/sunshine134679/fcitx5-linux-pinyin-input-method/releases/tag/v0.2.0)，不可变标签绑定源码 `dfc96d4af4487ca96bfa89aa9a13849661d20267`，官网及签名 APT/DNF 软件源同步上线。本页补充了发布后真实旧版升级结果；标签中的说明保留发布时状态。

## 输入体验

- 新增小鹤、自然码双拼和六组可配置模糊音，设置保存后可热更新；保留全拼、简拼及原始输入消费范围。
- 支持内部拆音歧义及候选按需续取；`xian` 可直接选择“西安”，部分选词继续保留剩余输入。
- 静态语言模型参与前文语境评分；成熟的个人学习词，包括主词典已有词，参与整句解码。真实选择“充气”五次后，新会话输入 `qingbangwochongqi` 的首选从“请帮我重启”变为“请帮我充气”。
- 修复长拼音原文误学为英文、超范围金额转换、上下文时间衰减未接入及解码评分方向问题，保持 200,000 条学习容量、隐私和用户清空边界。

## 候选框与客户端

- 八个主要模块保持原结构，改为中性浅色界面；补齐搜索无结果、加载和错误反馈、首次启用引导及软件源缓存状态。
- 自绘候选框提供字体、字号、间距和配色设置；GNOME 原生面板独立支持跟随桌面、浅色、深色、经典蓝与三档间距，设置即时生效。
- GNOME 面板使用独立标识 `modernime-panel@sunshine134679.github.io`，避免上游 Kimpanel 自动更新覆盖。保留未修改受管副本的升级路径、用户禁用偏好和修改过的副本。
- 系统诊断可区分面板未安装、待重新登录、未启用、运行中和加载失败，并提供已发现面板的启用入口。
- 修复 GNOME 46 新输入连接对已有窗口的焦点恢复；概览搜索复用原生异步输入。剪贴板持久化移至后台，敏感输入与失焦采集遵循统一边界。

## 已执行验证与限制

- 正式发行 Release/full 检查 89 项中 82 项通过、7 项图形检查因无图形环境合法跳过，0 失败；包含 Benchmark，必需项注册及执行核对通过。发布前 core-only 34 项全部通过，openEuler 原生 RPM/DNF 和生产签名门禁通过。首次集成及后续 CI 的失败与修正历史保留在升级路线图，不把图形跳过项写成已执行通过。
- 隔离 GNOME 46.2 中实际验证 GTK、Qt 5.15 Wayland、Chrome 157 和概览搜索的输入；覆盖 100% / 150% 双屏定位及原生面板外观切换和鼠标选词。
- 5 分钟连续输入累计 7,585 键、555 次真实提交，内容正确。虚拟按键至首个候选接收 P95 为 10.433ms；这不是物理按键到屏幕像素延迟。RSS 从 78.49MiB 达到 79.53MiB，60 秒后至结束保持；不能据此宣称长期稳定性已验收。
- 干净源码快照实际构建、安装、元数据发现及卸载通过，用户学习数据保留；未为此重复通用算法测试。各批证据和运行身份见[升级路线图](../全面升级审计与路线图-2026-11-08.md)。
- 版本化质量样本 20 项中 18 项达标；“气球”后输入 `chongqi` 的“充气”和“他的”后输入 `shenqing` 的“神情”仍为第 2。直接模型探针确认前一组缺少区分性的语境增益，后一组模型仍略偏“深情”；不使用单词硬编码或修改验收目标掩盖结果。
- 正式 Ubuntu 0.1.25 客户端实际发现 0.2.0，通过原有公钥与 APT 源升级成功，正式包摘要匹配，配置、个人词典与 SQLite/LMDB 学习数据保留。长期日用和其他桌面/应用版本尚未完成本版验收；当前说明不代表商业输入法水平或总体准确率。

## 安装与回退

正式 Ubuntu 24.04 amd64 DEB、openEuler RPM 和便携包见发布页。此前本地体验包与正式包分别保留构建身份，日常安装仍沿用原有渠道。源码及便携用户继续使用原渠道安装方式；不要直接用 DEB 覆盖其他渠道。

升级不会自动回滚或清空用户词典与学习数据。回退程序时保留用户数据；新 GNOME 扩展需重新登录确认加载。官网、正式标签、线上资产和签名软件源均已发布，继续使用原有发布公钥。
