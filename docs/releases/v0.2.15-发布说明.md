# ModernIME v0.2.15

- 修复含大写字母输入时的候选混入问题：优先保持纯英文/原样大小写候选，过滤“了/你/来”等纯汉字噪点及伪拼接项（如 `GitHub` 下的“给itHub”），仅保留真正的中英混排词条（如 `Docker容器`）。
- 修复大写入串处理、无上下文部分删词与负反馈愈合后的单字优先级恢复，并提升长句及真实常用搭配的首位命中率。
- 修复左右方向键选词交互，以及无上下文场景下的中文配对标点输入行为。
- 持续稳定支持 Ubuntu 24.04、Debian 12/13、Fedora 41/42、openEuler 24.09、Arch / Manjaro（`x86_64` / `aarch64`）与便携压缩包分发。

请沿用原安装渠道升级，设置、主题、个人词典和学习数据继续保留。
