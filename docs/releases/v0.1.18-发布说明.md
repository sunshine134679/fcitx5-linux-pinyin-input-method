## 1. 版本概述

ModernIME v0.1.18 是在 v0.1.17 架构整改与并发安全基线之上的**重大算法精进、候选体验优化与打字质感提升正式版本**。

结合对 17,476 次真实输入会话日志、底层候选决策链路与排版几何的深度审计，本版本针对实际打字过程中高频出现的英文补全截断、声母简拼中英冲突、词典路径回退、多页指示缺乏与外部导入频次冲击等 6 个核心体验与算法问题进行了彻底重构与解决。同时，完善了系统托盘指示器动态探测与实时状态刷新，全平台构建、安装脚本及在线一键更新功能经过严密验证，保持开箱即用。

## 2. 六大核心体验与算法优化

### 2.1 消除英文静态前缀补全 128 条字典序截断缺陷
- **问题定位**：`core/src/english_dictionary.cpp` 历史实现中，静态词表按字母字典序遍历时采用硬编码 `matches.size() >= 128` 早期跳出，导致前缀较长或词汇量庞大的前缀（如 `con-`、`trans-`、`pro-` 等）的高频实用词（如 `configuration`、`translation`、`protocol`）被较前字母序的冷门词直接挤占淘汰。
- **重构实现**：引入 Top-K 优先队列评分机制，扩大候选收集窗口（扩展上限至 512 项），综合考虑词频、词长、音节结构及自然构词权重进行全局打分，彻底解决高频英文长词不可达痛点。

### 2.2 放宽 3 字母前缀英文单词补全门槛与输入预测
- **重构实现**：在 `algorithm/pinyin/src/pinyin_candidate_provider.cpp` 中放宽英文候选提取门槛，允许如 `app`、`con`、`pro`、`dev` 等 3 字母有效前缀正常触发长词英文补全与候选派生，减少用户频繁切换中英文输入模式的打字中断。

### 2.3 拼音词典路径自愈机制
- **重构实现**：在 `algorithm/pinyin/src/pinyin_shared_resources.cpp` 中建立健全的词典路径多层回退与自愈检测机制。当默认路径未找到内置词典时，自动依次检索 `/usr/share/modernime/pinyin/`、`~/.local/share/modernime/pinyin/` 及相对构建路径，杜绝在非标安装或便携迁移环境下的词库静默降级。

### 2.4 候选条多页状态直观提示
- **重构实现**：在 `ui/fcitx5/src/candidate_bar_layout.cpp`、`candidate_bar_renderer.cpp` 与 `candidate_bar_layout.h` 中引入优雅的水平分页提示符（例如 `1/2 ►`）。在候选词多于单页容量时，右侧直观呈现当前页码与总页数，大幅提升候选框排版质感与浏览可预期性。

### 2.5 纯声母简拼技术词中英跨维度智能仲裁
- **问题定位**：程序员在输入类似 `pyt` 时，旧策略存在纯技术英文词直接冲上第 1 位抢占中文、或完全无法获得英文技术词的两个极端。
- **重构实现**：在 `algorithm/pinyin/src/candidate_composition.cpp` 建立声母缩写跨维度仲裁：第 1 位严格保留高质量中文候选（如「普通话/拼音/平台」），第 2 位智能安插首选高频英文技术词（如 `python`），在保护中文母语输入流畅度的同时，兼顾现代技术人员编码输入体验。

### 2.6 外部词频对数平滑与导入保护
- **重构实现**：在 `tools/settings/data_controller.cpp` 引入 `normalizeImportedWeight` 对数平滑归一化函数：
  $$\text{weight} = \min(50.0, \operatorname{round}(10.0 \times \ln(1.0 + \text{rawWeight})))$$
  对第三方导入的大词库原始频次进行科学平滑，防止数万量级外部词频直接冲垮本地个性化学习的权重梯度与艾宾浩斯遗忘模型。

## 3. 界面与托盘指示器完善

- **运行时动态绑定**：`ui/fcitx5/src/ui_addon.cpp` 采用运行时动态探测（`dlopen`/`dlsym`）绑定 `libayatana-appindicator3.so.1`，摆脱对编译期 `-dev` 依赖的硬性绑定。
- **实时状态刷新**：在输入法激活与 Shift 单键中英切换时，通过 Session DBus 广播 `PropertiesChanged` 信号，驱动 GNOME Shell 顶栏与各类桌面托盘实时更新中英文指示状态。

**Ubuntu / Debian (APT)**:
```bash
sudo apt update && sudo apt install --only-upgrade modernime
```

**openEuler / Fedora (DNF)**:
```bash
sudo dnf upgrade --refresh modernime
```

**源码安装或便携用户**:
```bash
cd ModernIME
git pull --ff-only
./install.sh
```
