# ModernIME v0.2.3

本版完善设置客户端的动效、主题与更新流程，修复透明动效层导致鼠标无法点击的问题。输入法排序、个人学习及用户数据格式沿用 v0.2.1。

## 客户端界面与交互

- 增加主题揭幕、候选预览过渡、导航选中背景移动、折叠展开、搜索定位提示与保存反馈。快速切换采用最新选择；关闭窗口会清理动画回调，系统禁用动画及高对比主题切换遵循相应偏好。
- 分别协调晴空蓝、青竹绿、暖砂橙、玫瑰粉、雾紫、深海夜与高对比的表面、文字、边界及焦点。九套候选栏配色保持独立，新增动效读取当前界面主题颜色。
- 统一启用类开关、控件高度与文字层级，明确界面主题和候选配色入口，收紧预览空间并区分即时操作与设置草稿。
- 修复绘制层挡住鼠标输入，导航、菜单、放弃和保存均通过实际鼠标事件验证。
- 将按钮、字体选择和开关的焦点提示收进控件边界，消除外侧双层边框及局部重绘时的残留，保留键盘导航定位。

## 下载与安装更新

- 检查版本不再要求输入管理员密码；发现新版后主按钮切换为下载操作，支持客户端内下载、校验及按原安装渠道更新。
- 修正脚本安装被误判为未知渠道导致下载失败的问题，以及升级后仍显示软件源刷新失败的问题。
- 下载失败给出简短状态和可查看的详情，避免原始错误长时间撑大底栏；修复升级引导说明被挤成竖列。
- 系统包安装阶段仍遵循系统授权和包管理器事务规则；源码/便携安装保持脚本渠道，不自动跨渠道覆盖。

## 构建兼容

- 补齐 CI 与发行构建显式安装的 Python 和 CA 证书依赖，修正 Ubuntu 22.04 证书目录延迟加载被误判为证书缺失的问题，恢复便携包构建；HTTPS 证书校验继续启用。

## 验证与安装说明

本地已完成相关 GTK 检查、七套界面主题与九套候选配色的独立组合检查，并使用 X11 真实鼠标事件验证点击链路。已安装客户端的导航点击也已核对；这些结果不代表所有桌面环境都已人工验收。

发行资产由绑定本版本标签的工作流构建，完整正确性、性能、安装升级和仓库签名由既有 CI 与 Release 门禁验证。无显示环境中的 GTK 检查会明确标记跳过，不计为通过。

提供 Ubuntu 24.04 amd64 DEB、openEuler x86_64 RPM 和 Linux x86_64 便携归档，沿用现有签名公钥及 APT/DNF 软件源。升级保留设置、个人词典、学习与剪贴板数据，继续使用原安装渠道。
