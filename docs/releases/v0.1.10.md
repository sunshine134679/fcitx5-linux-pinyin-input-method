# ModernIME v0.1.10

本次更新改善设置客户端的可读性、候选预览一致性，以及启动恢复、安装和在线更新的可靠性。

## 客户端与输入体验

- 候选栏按固定宽度展示，设置含义改为可容纳的单字候选数量；预览共用实际输入法的布局和绘制，支持单字、双字和混合词组示例。
- 中英文切换增加 Shift 预设，保留已有组合快捷键与按键录制。
- 侧栏选中项使用蓝色文字和浅蓝背景，改善焦点、悬停和切换动画。
- 更新页的长软件源路径、说明和终端命令支持换行、选择与复制。

## 稳定性与在线更新

- 完善 Fcitx5 会话启动与恢复、设置保存和安装事务失败回滚；受控卸载保留用户修改过的配置。
- DEB / RPM 安装按渠道选择 APT / DNF；版本检查只读取本地缓存，避免检查操作暗中触发联网刷新。
- DNF 检查查询可用版本，缓存缺失时引导用户手动刷新。
- 发布重试不会重复加入当前版本，签名软件源继续保留 0.1.9 及后续历史包用于回退。

## 升级

已配置官方签名软件源的用户，可在客户端刷新缓存后升级，或运行：

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install --only-upgrade modernime
# openEuler
sudo dnf makecache --refresh
sudo dnf upgrade modernime
```

源码用户运行 `git pull --ff-only && ./install.sh`；便携包用户下载适合系统的新版包并运行其安装脚本。源码或便携包用户若要改用包管理器升级，应先配置软件源，再执行 `modernime-migrate-channel`。升级后重新打开设置客户端。

在线源首发版本为 0.1.9；0.1.8 及更早版本需通过历史 Release 离线包回退。各平台兼容范围、软件源签名配置和回退命令见 README。
