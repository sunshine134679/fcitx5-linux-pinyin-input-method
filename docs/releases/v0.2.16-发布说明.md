# ModernIME v0.2.16

- 新增「拼音智能纠错」（`pinyin.typo_correction`）：支持全拼漏键容错（如 `xanch→线程`、`jnch→进程`）、音节内部换位（如 `xina→xian`）及邻键误触纠正（如 `juncheng→进程`），保持原生全拼/简拼锚点显著度与手动词典兼容。
- 新增「预编辑自动分词」（`pinyin.dynamic_preedit_separator`）：预编辑区分隔符 `'` 跟随首选候选音节边界动态插入与合并重排（如 `x'an→xan'ch→xan'cheng`，退格恢复 `x'an`），始终保留原始输入字母及用户手动输入的 `'` 分隔点。
- 设置客户端「输入习惯 → 拼音与状态」新增“拼音智能纠错”与“预编辑自动分词”两个独立开关，支持搜索定位、保存热生效与 `input.enabled` 联动（仅限全拼/简拼方案）。
- 继续覆盖 Ubuntu 24.04、Debian 12/13、Fedora 41/42、openEuler 24.09、Arch / Manjaro（`x86_64` / `aarch64`）与便携压缩包分发。

请沿用原安装渠道升级，设置、主题、个人词典和学习数据继续保留。
