# ModernIME v0.2.18

- 拼音匹配与纠错精细化：保留 `daan`、`hunan`、`jinan`、`zheg`、`yig` 等合法音节边界，关闭纠错时严格隔离近音变体与 `lue/nue`；用 $O(\log N)$ 前缀探测优化查词热路径，修复中英混输后标点判断、`Ctrl+[` / `Ctrl+]` 不漏发标点及首页单字同音词保护。
- 双拼、Shift 切换与辅助工具增强：修复双拼模糊音回退与候选消费字节对齐，关闭与双拼冲突的全拼宏及 `v2` 触发（保留 `v123` 大写数字宏）；收敛 Shift 400ms 单次短按判定并过滤长按连发误触；支持计算器左右方向键移动光标及极端指数溢出防护。
- 候选栏、Kimpanel 与设置客户端改进：X11 候选栏新增鼠标滚轮翻页，修复选中胶囊边缘点击命中、剪贴板选中行与图标间距及零宽/零高光标坐标跟随；GNOME Kimpanel 扩展兼容至 45–49；设置客户端支持 `pacman` 渠道升级、保存生效有界自动复查与 `SharedLifetime` / `GTask` 异步生命周期加固。
- 隐私与长期存储稳定性：焦点位于 KeePass / Bitwarden / 1Password / Enpass / Passbolt / Seahorse / KWallet 等密码管理器窗口时自动暂停剪贴板监听并重置基线；为 SQLite 学习库配置 4MB WAL 上限与部分索引并自动清理 LMDB 过期读锁；升级备份切回回滚日志模式且自动保留最近 5 份时间戳备份。

请沿用原安装渠道升级，设置、主题、个人词典和学习数据继续保留。
