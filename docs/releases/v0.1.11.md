# ModernIME v0.1.11

本次更新简化个人词典使用，改善客户端展示、官网清晰度，并修复安装版本记录与临时目录防护。

## 候选排序与智能学习

- **解除高频单字锁定**：引入休眠衰减机制，解决高频单字在短期密集选词后权重过度膨胀、长期锁定首选位而抑制多字词组优先召回的体验问题。
- **前后鼻音容错个性化学习**：支持前后鼻音容错（如 `en/eng`、`in/ing`、`an/ang`）模式下的用户习惯自适应学习与拼音键前缀召回。
- **退格删除负反馈闭环**：当用户选词上屏后立即按 Backspace 删除该词时，自动触发负反馈衰减，闭环抑制错误选词的频次积累。
- **中英仲裁与前缀召回优化**：解耦仲裁标识与拼音键规范化，优先保证拼音前缀的高精度召回。

## 客户端

- 添加词条时只需先输入词语，客户端从本地词库建议拼音；可按实际读音修正，无需手动填写排序权重。
- 剪贴板使用紧凑列表，长记录按需展开；窗口底部圆角与顶部统一。
- 更新页显示包管理器与系统授权失败的具体诊断，并保留终端刷新入口；修复 DNF 当前已安装最新版时误报离线的问题。

## 安装与升级

- 便携包安装脚本内置准确版本，不再依赖包内不存在的源码或外部 CMake 缓存。
- 临时目录中的安装器未指定前缀时立即拒绝，不会先触发用户数据备份；普通 CLI 开关不能绕过保护。
- 源码与便携安装保持离线流程；升级前仍校验并备份 SQLite / LMDB，保留个人词典和配置。系统包安装与升级继续通过 APT / DNF 执行。
- 沿用官方签名公钥环，在线软件源保留 0.1.9 起的历史版本，支持查询与回退。
- 规范化旧插件迁移路径比对（采用规范真实路径），避免清理时因软链接误删运行目标文件。

## 官方网站

官方网站提供下载安装与文档入口。客户端图片由真实界面以 3× 分辨率重新绘制，图库支持连续切换、加载失败重试，脚本与样式使用内容版本号避免缓存混用；排版统一字号层级与字重。统一矢标图标与动作间距，优化候选词横向边距与选中反馈。

## 更新方法

已配置官方签名软件源的系统包用户：

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install --only-upgrade modernime

# openEuler 24.09
sudo dnf makecache --refresh
sudo dnf upgrade modernime
```

源码用户运行 `git pull --ff-only && ./install.sh`；便携包用户下载对应系统的新归档，解压后运行其中的 `./install.sh`。在临时目录使用便携包时请明确设置 `MODERNIME_PREFIX`，并按 README 配置隔离路径。源码/便携安装改用系统包时，应先配置签名软件源，再使用 `modernime-migrate-channel` 迁移，避免直接覆盖不同渠道的文件。

完成升级后关闭并重新打开设置客户端；如需要立即使用新的输入法插件，在当前桌面会话执行 `fcitx5-remote -r`。发行包平台兼容范围与依赖见 README。
