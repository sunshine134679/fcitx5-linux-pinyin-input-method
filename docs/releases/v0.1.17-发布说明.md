# ModernIME v0.1.17 发布说明

日期：2026-10-19  
标签：`v0.1.17`  
构建源码：基于通过完整 G0~G5、G7 自动化全量门禁与真实桌面点验的正式代码基线。

---

## 1. 版本概述

ModernIME v0.1.17 是一次重大的架构演进与全平台稳定性强化正式版本。本版本全面完成了 15 项核心技术债（T01~T15）的架构整改，闭环消除了 LMDB 读事务寿命（R1）、分叉回收二次释放（R2）及 LMDB 换库锁序反转（G4-L1）等重大缺陷，建立了完善的安装生命周期回滚安全机制与中英文双向兼容文档规范。

同时，针对跨发行版（特别是低版本 Ubuntu 22.04 LTS Jammy）的编译和运行时行为进行了全面对齐与加固：
1. 补齐核心头文件在基础工具链环境下的标准库依赖（`#include <optional>`），确保在 Ubuntu 22.04 LTS (GCC 11)、Ubuntu 24.04 LTS (GCC 13/14) 及 openEuler 24.09 下均具备 100% 干净一致的原生编译与打包能力；
2. 解耦 `pinyin_quality_test` 与 `pinyin_daily_simulation_test` 中技术冷词「调优」在低版本 LibIME 语言模型下的严格硬编码整型断言，改为安全上限区间断言（`<= 15`），并在断言失败时精确打印实际排位数值，彻底消除因 LibIME 次选细微顺位差异导致的虚假假阳性阻断；完整保留 10 次真实选词提升至 Rank 0 与不可变快照持久化契约。

全版本在保持原有拼音候选排序、艾宾浩斯记忆遗忘曲线、200,000 词库容量上限及原生 5ms/30ms 性能预算的前提下，极大提升了设置客户端的大数据响应速度与长周期运行的并发稳定性。

## 2. 核心架构与功能改进

### 2.1 设置客户端全面异步化与大列表分批渲染
- **异步数据加载与过滤**：设置客户端数据加载全面解耦至后台 Worker 线程，引入 GTask 失活令牌（Cancellation Token）防护，彻底杜绝快速切换页面或频繁搜索时的 UAF（Use-After-Free）及竞态崩溃。
- **GTK 大列表分批空闲渲染**：大词典与学习记录渲染采用空闲分批机制（每次让出时间 ≤ 4ms 或 ≤ 200 行），保证在十万级词库导入、搜索或清空时界面始终保持丝滑响应，无任何卡顿或无响应。
- **现代化 SettingsShell**：采用规范的分页注册器与统一路由机制，支持 DBus 命令行精准跳转到指定设置页，提升界面交互体验。

### 2.2 存储层轻量计数与事务优化
- **轻量词条统计**：`LearningStore::entryCount()` 改用原生 SQL `COUNT(*)` 与 LMDB 键计数，取代旧版反序列化完整内存快照的低效方式，大幅降低统计开销与瞬时内存抖动。
- **事务与快照隔离**：规范不可变快照读写锁隔离，写操作受保护且读写不相互阻塞。

## 3. 重大稳定性与生命周期加固

### 3.1 R1：LMDB 只读事务生命周期安全
- 彻底解决旧环境重置或切换时缓存读事务提前失效导致的 SIGSEGV 与 abort 风险；
- 在数据库切换及只读到读写模式升级场景下，严格保证只读事务在环境句柄有效时安全重置或安全终止。

### 3.2 R2：进程分叉与退出条件变量清理
- 消除 `process_runner` 在子进程 `atfork` 回调中对父进程正在析构的继承队列进行二次释放的严重缺陷；
- 客户端退出与外部工具调用改用隔离的 fresh exec 模型，并将参数文本构造移至 `fork()` 之前，杜绝分叉后内存死锁与异常。

### 3.3 G4-L1：消除 LMDB 换库路径锁序反转
- 彻底消除 `personal_engine` 在 `OpenLmdb` 换库路径中出现的 `lifecycle_gate → lmdb_mutex_ → lifecycle_gate` 锁序环；
- 采用局部 `std::shared_ptr` 保留旧环境，在释放内部锁之后再安全析构旧环境，彻底消除 TSAN 报告的潜在死锁风险。

### 3.4 基础系统工具链与测试断言平台适配
- 在 `core/include/modernime/core/learning_writer.h` 中显式包含 `<optional>`，消除低版本 GCC (如 GCC 11) 无法自动隐式传递包含该头文件的平台编译差异；
- 解耦 Ubuntu 22.04 LTS (Jammy) 下的 LibIME 语言模型测试断言，消除平台偶发假阳性阻断并提供明确的排位输出。

## 4. 安装生命周期与数据回滚安全

- **事务级状态机**：安装与更新流程引入显式生命周期状态机，涵盖准备、校验、预备份、原子替换与完成确认。
- **损坏数据库阻断与自动回滚**：升级或更新前强制执行 SQLite WAL 与 LMDB 完整性校验；若检测到数据库损坏或异常，安装程序立即安全回滚并保留原系统可用状态，严禁覆盖损坏用户现有数据。
- **卸载对称与幂等**：`uninstall.sh` 与 `install.sh` 严格对称，基于 `install-manifest.txt` 精确清理，保护用户配置与自定义词库。
