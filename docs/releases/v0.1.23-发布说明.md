# ModernIME v0.1.23 发布说明

日期：2026-10-25  
标签：`v0.1.23`  
构建源码：停止 Ubuntu 22.04 支持、修复简拼晋升缺陷后的正式发布基线。

---

## 1. 版本概述

ModernIME v0.1.23 是 **卡qiǎ住 读音提示** 功能集的正式发布版本，同时按维护者决定**停止 Ubuntu 22.04（LibIME 1.0.11）支持**，发布门禁只保留 Ubuntu 24.04、openEuler RPM 与便携归档。

此前 v0.1.18 ~ v0.1.22 的 Release 均因 Ubuntu 22.04 作业失败而未产出资产（`releases/latest` 长期停留在 v0.1.17）。本版删除 22.04 构建与旧模型基线适配，并从源头修复了暴露出的简拼晋升缺陷。

---

## 2. 支持矩阵变更：停止 Ubuntu 22.04 / Debian 12

- 移除 `ubuntu-22.04` DEB 构建作业；发布门禁只跑 Ubuntu 24.04。
- APT 软件源只保留 `noble`（Ubuntu 24.04）套件；`jammy`、`bookworm` 套件与对应的旧包保留历史但不再更新。
- 官网下载区移除 Ubuntu 22.04 / Debian 12 选项；README 兼容矩阵与安装说明同步。
- 源码构建与便携归档仍支持其它发行版（便携包 glibc ≥ 2.34 基线不变）。

## 3. 修复：模糊音组间晋升误伤简拼（ALG-RANK）

- **根因**：组间晋升把“简拼段数”当作音节数。Jammy 模型下 `nh` 的原生候选包含单字「你」(ni)，学习增益达到 2.08 后被抬入高优先级组，越过 trusted 简拼「你好」。
- **修复**：晋升仅对全拼输入生效（每个音节均为标准音节）；简拼/混拼/含非法音节输入不再借用该通道。全拼模糊音学习上位（`zongwen→中文`）与单音节行为不变。
- **验证**：模型无关回归 `LearnedSingleCharCannotHijackAbbreviationInput`（先红后绿）；Ubuntu 22.04 容器内 `daily_simulation` 全 9 节通过（修复验证完成后才移除 22.04 支持）。

## 4. 功能内容（同 v0.1.20）

### 4.1 高频易错音内联读音提示（卡qiǎ住）

- 输入 `kazhu`（把「卡住」的「卡」记成 kǎ）时，首选显示 `卡qiǎ住`；规范读音依据《现代汉语词典》第七版（动词义 qiǎ）。
- 离线词表 32 词（卡住/卡在/卡顿/卡壳/关卡/发卡/卡脖子、角色 jué、睡觉 jiào、银行 háng、说服 shuō、血液 xuè、粗犷 guǎng 等），由 `scripts/生成易错音词表.py` 逐字对 Unicode Unihan 五读音字段（含繁简形关联）校验后生成。
- 仅当输入的无声调节节与该字规范读音不一致时提示；正确读音（`qiazhu`）、简拼（`kzhu`）、错位拼与非词表词（`卡着`）不提示。

### 4.2 简拼部分消费范围修复

- `zmhuishi` 首选恢复为全消费整句「怎么回事」；高频学习的「怎么」以真实部分消费（`zm`）居次席，选中后 `hui'shi` 保留在组合中。
- 读音提示字段完整穿过 Provider→引擎→fcitx5 候选列表→UI 重建全链路。

### 4.3 容错与学习链路强化（承接 2026-10-24 专项）

- 近音变体召回（`baoyan→表演`、`lui→六`）、换位+简拼混合修复（`wiesm→为什么`）、模糊音学习上位（`zongwen`）、提交后空有效窗口不再误扣词频。
- 不变量矩阵新增 #47~#51。

## 5. 安装渠道与升级

| 资产文件名 / 渠道 | 适配发行版与代号 | 架构 | 最低系统要求 |
|---|---|---|---|
| `modernime_0.1.23_amd64_ubuntu24.04.deb` | Ubuntu 24.04 LTS (`noble`) | `amd64` (`x86_64`) | glibc ≥ 2.39, Fcitx5 ≥ 5.1.7, LibIME ≥ 1.1.5 |
| `modernime-0.1.23-1.oe24.x86_64.rpm` | openEuler 24.09 (`oe2409`) / 24.03 SP4 | `x86_64` | glibc ≥ 2.38, Fcitx5 ≥ 5.0.14, LibIME ≥ 1.0.11 |
| `modernime-0.1.23-linux-x86_64.tar.gz` | Linux 便携免编译包 | `x86_64` | glibc ≥ 2.34, libstdc++ ≥ 3.4.30, Fcitx5 |
| 源码构建 (`./install.sh`) | 任意 Linux (含 ARM64, RISC-V) | 全架构 | C++20, CMake ≥ 3.24, GCC ≥ 10, Fcitx5-devel |

- **源码升级**：`git pull --ff-only && ./install.sh`
- **APT（Ubuntu 24.04）**：`sudo apt update && sudo apt install --only-upgrade modernime`
- **DNF（openEuler）**：`sudo dnf upgrade --refresh modernime`
- **设置客户端**：「检查与更新」页面一键升级。
- 升级前自动备份学习数据库（SQLite WAL Checkpoint + Backup API 完整性校验、LMDB 备份）。
