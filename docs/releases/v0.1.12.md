# ModernIME v0.1.12

本次更新重点是个性化与候选排序的结构优化，修复重复选词仍难以提权的问题，并建立可持续增删算法特性的边界。

## 候选排序与模块边界

- 中文候选分别经过召回、统一特征计算、前缀派生与混排；会话选择窗口独立管理，分页只负责显示几何和选择映射。
- 约束静态先验，保留匹配资格、可信简拼、整句与消费范围规则。重复明确选择 `shi→试`、`jian→见/键` 可以提升最终候选位置。
- 派生前缀使用自身学习证据，避免父词权重覆盖；负反馈不会被零值合并吞掉。
- 新增架构、变更指南及候选子契约，记录扩展入口、状态权限、依赖和退役规则。全局 Composer、完整排序 trace 与统一策略版本仍为后续迁移设计。

## 个性化可靠性与性能

- 修复敏感输入和关闭学习时的状态边界、光标移动误触删字学习、英语词条身份及旧记录兼容。
- 持久屏蔽跨重启和输入上下文生效；关闭学习仍读取既有屏蔽规则，首次关闭学习不会创建学习数据库。
- 修复 SQLite/LMDB 写入事务、失败重试与清空一致性，保留不可变快照、艾宾浩斯时间遗忘和 200,000 词容量。
- 学习快照由 256 改为 512 分片，减少局部索引重建；本地最终基准中 200,000 词新词学习加召回 P99 为 2.72 ms，门限仍为 5 ms。
- 会话选择窗口仅存在内存，重启后不会保留临时加分；持久词频仍保留。首次选择也不会无条件置顶。

## 安装与在线更新

- 发行版本统一为 0.1.12，README、官网静态下载和 API 失败时的后备链接同步更新。
- Benchmark 命令使用跨版本兼容的秒数参数，支持 Ubuntu 22.04 的较旧 Google Benchmark。
- Ubuntu 发行构建在打包前检查 GTest、Benchmark、安装测试已注册并实际运行；缺少必需测试将阻止发布。
- 延用标签绑定源码、签名 APT/DNF 仓库、历史版本保留、SHA256 校验及升级数据保护流程。发行包与软件源由同一 Release 工作流发布。
- APT/DNF 安装可在设置客户端刷新对应软件源后更新；源码安装仍使用 `git pull --ff-only && ./install.sh`，便携安装下载新归档后执行其安装器。跨渠道迁移使用 `modernime-migrate-channel`。

## 验证与限制

- 本地完整回归：63 项 CTest 通过、3 项 GTK 图形测试跳过、0 失败；GTest 内部 64/64 通过，Benchmark 实际执行。
- 隔离全新克隆、离线构建、安装产物与元数据发现、卸载闭环通过。
- 模拟输入引擎完成 300 次选词训练，验证学习后的全局位置、物理分页和剩余拼音；另覆盖 36 组字号/栏宽的分页及数字键、点击映射。
- 当前验证不包含真实桌面打字、Pango 实际字体测量或跨 DPI/Wayland/X11 交互，不把跳过的图形测试计为通过。
