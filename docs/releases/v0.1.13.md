# ModernIME v0.1.13

本次更新重点是个性化与候选排序的结构优化，修复重复选词仍难以提权的问题，并建立可持续增删算法特性的边界。

## 候选排序与模块边界

- 中文候选分别经过召回、统一特征计算、前缀派生与混排；会话选择窗口独立管理，分页只负责显示几何和选择映射。
- 约束静态先验，保留匹配资格、可信简拼、整句与消费范围规则。重复明确选择 `shi→试`、`jian→见/键` 可以提升最终候选位置。
- 派生前缀使用自身学习证据，避免父词权重覆盖；负反馈不会被零值合并吞掉。
- 新增架构、变更指南及候选子契约，记录扩展入口、状态权限、依赖和退役规则。全局 Composer、完整排序 trace 与统一策略版本仍为后续迁移设计。

## 个性化可靠性与性能

- 修复敏感输入和关闭学习时的状态边界、光标移动误触删字学习、英语词条身份及旧记录兼容。
- 持久屏蔽跨重启和输入上下文生效；关闭学习仍读取既有屏蔽规则，首次关闭学习不会创建学习数据库。
- 修复 SQLite/LMDB 写入事务、失败重试与清空一致性，保留不可变快照、艾宾浩斯时间遗忘和 200,000 词容量。
- 学习快照由 256 改为 512 分片，减少局部索引重建；本地最终基准中 200,000 词新词学习加召回 P99 为 2.72 ms，门限仍为 5 ms。
- 会话选择窗口仅存在内存，重启后不会保留临时加分；持久词频仍保留。首次选择也不会无条件置顶。

## 跨版本发布修复

v0.1.12 标签的首次发行门禁发现 Ubuntu 22.04 兼容性问题，因此没有发布正式产物。保留失败标签与证据，本版使用新标签交付原算法优化与兼容修复。

- 剪贴板文件状态同时检查设备、inode、大小、mtime 和 ctime，识别同时间戳、同尺寸的原子替换，避免清空后恢复旧记录。
- Fcitx 输入面板测试按实际客户端文本及光标验证清空，兼容旧版空 segment 表示；多 Instance 夹具重置选项解析状态。
- CI 保留 Debug 正确性回归，性能预算改由独立 Release 构建验证，阈值保持不变。
- 旧 LibIME 的 `ga'r'a` 含内部不完整音节，不再作为“完整精确拼音”禁止英文预测；`gara→garage` 恢复召回、选择、学习与持久屏蔽。
- 系统语言模型存在可复现的单字顺序差异：旧/新模型分别为 `yi→一/以`、`zi→子/自`、`ge→个/各`、`jia→加/家`，`ni` 的次选为 `尼/拟`。对应测试使用独立原生 LibIME 模型基线，继续验证首选、同音项位置与前缀消费；生产冷启动排序保持尊重原生模型。

旧模型另外三个词的既有冷启动全局位置是 `调优=7`、`死锁=3`、`破折号=15`（从零计数），用 `d1c3195` 独立构建确认修复前后相同。测试仅在上述五组独立原生行为同时匹配时使用旧模型精确位置基线；这是一组行为基线，不是版本判断或安全指纹。新模型和未知模型保留原排名要求；两组均校验完整拼音、消费范围及十次选择后的最终全局第一和重开结果，不将旧模型冷启动位置宣称为新版金样通过。

首次失败记录：[v0.1.12 Release](https://github.com/sunshine134679/fcitx5-linux-pinyin-input-method/actions/runs/38732883798)、[Debug 性能 CI](https://github.com/sunshine134679/fcitx5-linux-pinyin-input-method/actions/runs/38732850801)。模型 SHA256：旧 `c14b734950c8bb27ac2813d07fc30b011c94a93d0ba02865bd663a13f2081d86`；新 `c5b939318bd7705f8ddcd0ba98229dd1ddf5f3ea34135056f2090b7f3513e086`。

## 安装与在线更新

- 发行版本统一为 0.1.13，README、官网静态下载和 API 失败时的后备链接同步更新。
- Benchmark 命令使用跨版本兼容的秒数参数，支持 Ubuntu 22.04 的较旧 Google Benchmark。
- Ubuntu 发行构建在打包前检查 GTest、Benchmark、安装测试已注册并实际运行；缺少必需测试将阻止发布。
- 延用标签绑定源码、签名 APT/DNF 仓库、历史版本保留、SHA256 校验及升级数据保护流程。发行包与软件源由同一 Release 工作流发布。
- APT/DNF 安装可在设置客户端刷新对应软件源后更新；源码安装仍使用 `git pull --ff-only && ./install.sh`，便携安装下载新归档后执行其安装器。跨渠道迁移使用 `modernime-migrate-channel`。

## 算法变更影响记录

- 类型：调整；契约 `ALG-PINYIN/ZHEN/IDENTITY/SUPPRESS`、`CAND-ELIGIBILITY/FALLBACK/IDENTITY`。入口为 Provider 的英文准入判断；读取当前候选完整拼音与已有音节合法性策略，不新增可写状态、持久字段、开关或候选来源。
- 触发：旧 LibIME 将 `gara` 解码为 `ga'r'a`。变化：内部不完整音节不能提前否决英文预测，`garage` 按既有英文混排、消费 4 字节、全词身份学习和屏蔽规则进入候选。
- 保持：有效完整拼音、可信简拼、`de/shi/qu` 中文保护、隐私禁学、清空、持久屏蔽、容量及时间遗忘。模型差异验收由独立 LibIME 夹具提供基线，不在生产代码硬编码“以/自/各/家”高位。
- 数据与回退：无 schema 或词条身份变更；旧版本仍可读取学习数据。代码回退只恢复旧英文资格判断，无数据删除或迁移。消费和学习回归由 Provider、GTest 与输入引擎覆盖。

## 验证与限制

- 本地完整回归：63 项 CTest 通过、3 项 GTK 图形测试跳过、0 失败；GTest 内部 64/64 通过，Benchmark 实际执行。
- 隔离全新克隆、离线构建、安装产物与元数据发现、卸载闭环通过。
- 模拟输入引擎完成 300 次选词训练，验证学习后的全局位置、物理分页和剩余拼音；另覆盖 36 组字号/栏宽的分页及数字键、点击映射。
- 当前验证不包含真实桌面打字、Pango 实际字体测量或跨 DPI/Wayland/X11 交互，不把跳过的图形测试计为通过。
