# ModernIME v0.2.4

本版增加日常输入辅助、快捷短语和收藏管理，并修复实际桌面体验中发现的标点、撤销及焦点问题。设置客户端继续保持八个主要模块，沿用现有设置、个人词典和学习数据。

## 输入辅助与个人词典

- 个人词典模块新增快捷短语管理：缩写对应单行固定文本，可新增、编辑、删除和搜索；输入时复用 Fcitx Quick Phrase 的明确触发和候选选择，不将缩写强行插入普通拼音候选。
- `Ctrl+Shift+E` 开始临时英文，回车提交原文后恢复中文，Esc 取消；空格提交片段并保留空格。
- 支持按输入方案及原始输入置顶候选、取消置顶；管理入口位于既有个人词典模块。
- `u+` 进入离线拆字查字，如 `u+mumu` 查“林”；`v=` 进入离线计算器，如 `v=2+3*4` 得到 `14`，也可从 `v` 菜单进入。
- 二进制安装包随附拆字索引及上游许可，整包许可证声明增加拆字数据的 `CC-BY-3.0`；输入法自身代码仍为 `LGPL-2.1-or-later`。

## 标点、输入状态与撤销

- 补全 `（）`、`【】`、`《》`、`“”`、`‘’` 并将光标放在中间；支持嵌套、空对删除和越过本次补出的闭符号。需要应用提供有效周边文本、无选区且当前有焦点；终端不自动补对。
- 默认智能模式下，尚未选词时按 `_` 保留原始拼写，`foo_bar` 和 `inter_name` 不被中文候选或英文补全改写；先选词确认中文后再按 `_`，以及独立输入时，仍输出 `——`。显式下划线样式和逐键映射继续优先。
- 可设置应用默认中英模式，或在当前进程内按应用记住模式；不改变其他应用的规则。
- 在支持周边文本的应用内，`Ctrl+Shift+BackSpace` 可在 15 秒内撤销最近一次普通候选提交并恢复拼音，支持部分选词；移动光标、外部编辑、失焦等使其失效。`Ctrl+BackSpace` 继续由应用处理。

## 简繁、符号与剪贴板

- 复用 Fcitx `chttrans` 的简繁转换、原生动作和用户配置，默认快捷键 `Ctrl+Shift+F`，以用户在 Fcitx 中的实际设置为准。候选学习身份保持简体；缺失或禁用转换模块不影响普通输入。
- `v;` 搜索离线符号，支持中文名称、拼音和英文别名；目录含常用标点、数学符号、单位、箭头和表情，设置端可分类浏览及收藏。
- 既有 `V+2` 剪贴板入口增加 `Ctrl+F` 搜索、`Ctrl+D` 收藏或取消收藏；设置端提供中文关键词搜索及收藏管理。
- 收藏独立保存：清空历史、删除历史条目均保留收藏；取消或清空收藏不删除历史。继续使用异步存储，生成结果不作为普通选词学习。

## 桌面问题修复

- 将可选简繁模块加载延后到引擎激活，避免 Fcitx 加载器重入导致 ModernIME 无法启动。
- 下划线原文提交不再依赖当前首选候选是否英文，修复 `foo_bar` 变成“佛——bar”。
- 区分 GTK 的预编辑重置与完整会话重置，修复括号内选词后重复插入闭括号；闭合前仍检查实际周边文本。
- 实体 Ctrl、Shift 按下不再提前清空撤销记录，修复撤销快捷键落入 GTK 删除操作、丢失前文且无法恢复候选的问题。
- 显示用预编辑禁止自动提交，失焦按现有策略清理未确认组合，不再将 `ming'tian` 等格式化拼音写入正文；明确按回车仍提交原始击键。
- 明确语境中的正音候选不再被普通模糊词频压过，保留标准模糊音的明确选择学习，不采用词语硬编码。
- 卸载时清理新增拆字组件的空目录；只删除受管文件并移除空目录，保留非空目录中的用户内容。

## 更新与验证范围

提供 Ubuntu 24.04 amd64 DEB、openEuler x86_64 RPM 和 Linux x86_64 便携归档，继续使用已有签名公钥和 APT/DNF 软件源。请沿用当前安装渠道升级；升级保留设置、个人词典、学习记录及剪贴板数据，加载新插件需要重启 Fcitx5。

新增功能已做相应增量构建和直接相关验证；上述撤销、失焦、下划线及括号问题均有隔离 GTK/X11 桌面复现与修复后验证。代理体验记录不能替代真人反馈，也不代表全部功能、所有应用或原生 Wayland 场景均已验收。发行构建、完整测试、性能、安装升级和生产签名继续由正常 CI 与 Release 门禁检查，无显示环境的 GUI 跳过不计为通过。

详细配置及兼容边界见[输入编辑功能接口](../输入编辑功能接口.md)、[输入扩展功能接口](../输入扩展功能接口.md)。
