## 1. 版本概述

ModernIME v0.1.19 是专注于**GNOME 桌面深度集成、GNOME Shell Overview (Super 键概览搜索栏) 体验修复与全生命周期交付安全**的正式维护版本。

本版本彻底解决了 GNOME 40~46+ 环境下按下 `Super` 键进入概览搜索栏时中文输入法候选框无法渲染失效的经典系统级交互难题。通过内置原生 Clutter 扩展资产及开箱即用自动化会话配置，实现 Overview 模式下拼音实时选词与光标跟随；同时完善了安装生命周期清单与对称卸载机制，确保系统包管理器与一键更新渠道顺畅可靠。

## 2. 核心改进与技术实现

### 2.1 GNOME Shell Overview (Super 键搜索栏) 候选框深度支持
- **问题定位**：GNOME Shell 概览搜索栏属于 GNOME Shell 内部 Clutter 舞台参与者（`StEntry` -> `ClutterText`），其输入法事件由内部 `inputMethod.js` 经 DBus 桥接至 Fcitx5 ibusfrontend。在 Overview 概览模式下，由于 Clutter 独占合成舞台，外部 X11/Wayland 独立候选窗口（如 `modernime-ui` 或经典 X11 悬浮窗口）无法置顶呈现在 Clutter 舞台之上，导致用户按下 Super 键后只能盲打英文字母而无法看到中文候选框。
- **重构实现**：系统在 `data/extensions/kimpanel@kde.org` 内置集成了经过 GNOME 46 适配验证的原生 Clutter 扩展。该扩展直接在 GNOME Shell 内部实现 `/org/kde/impanel` DBus 协议，由 GNOME Shell 自身在舞台内部实时绘制紧随搜索栏光标的现代候选框，彻底打通 Overview 模式下的中文输入链路。

### 2.2 开箱即用会话自动化集成与激活
- **实现方案**：在 `scripts/modernime-session-init` 与 `install.sh` 中增加智能桌面环境感知。若检测到当前会话属于 GNOME 环境（`XDG_CURRENT_DESKTOP` 或 `gnome-shell`），安装部署程序将自动完成：
  1. 将内置的 `kimpanel@kde.org` 扩展部署至用户扩展目录 `~/.local/share/gnome-shell/extensions/kimpanel@kde.org`；
  2. 自动调用 `glib-compile-schemas` 编译扩展 GSettings 配置模式；
  3. 通过 `gnome-extensions enable` 与 `gsettings` 自动激活扩展；
  无需用户手动在 extensions.gnome.org 搜寻、排查或通过浏览器插件配置，安装即生效。

### 2.3 严格对称的安装生命周期与卸载保护
- **清单管理**：在 `scripts/install_lifecycle.sh` 的 `modernime_integrate` 阶段，将所有扩展资产完整纳入 `$PREFIX/share/modernime/install-manifest.txt` 清单追踪，杜绝未托管文件。
- **对称清理**：升级 `uninstall.sh`，在清单校验白名单中增加 `"$prefix/share/modernime/extensions/"*)`，并在卸载时自动递归收敛扩展目录结构，确保与 `install.sh` 严格对称且零文件残留；同时绝不误触用户词库与个性化学习数据库。

### 2.4 打包流水线与门禁测试适配
- **门禁校验**：更新 RPM 与 DEB 包结构验证门禁 `tests/verify_package_repo_gate.sh`，将扩展资产纳入包体常规文件与权限审查，保持所有可执行代码 0755、数据资源 0644 的严格安全基线。
- **回退与升级保障**：通过全量 78 项自动化测试（覆盖安装事务、多版本升降级隔离、并发学习数据保护与配置契约），保障现有在线更新与各渠道包管理器升级体验平滑稳定。

### 3.2 升级方式

- **源码升级**：
  ```bash
  git pull --ff-only
  ./install.sh
  ```
- **APT 仓库升级（Ubuntu / Debian）**：
  ```bash
  sudo apt update
  sudo apt install --only-upgrade modernime
  ```
- **DNF 仓库升级（openEuler）**：
  ```bash
  sudo dnf upgrade --refresh modernime
  ```
- **设置客户端**：打开「ModernIME 设置」客户端 -> 切换至「检查与更新」页面 -> 点击「检查更新」并一键升级。
