# ModernIME v0.2.9

本版集中完善原生 GTK3 客户端的界面和交互，并为实际打字时的自绘候选框增加简约、标准、质感三档风格。沿用现有八个主要模块、配置和个人数据。

## 客户端界面与流畅度

- 精修蓝、绿、橙、粉、紫、深海夜与高对比七套主题的明暗层次、边缘和控件状态，统一文字对齐、页面留白、列表及操作区的排版。
- 修复鼠标点击后选中框长期残留的问题，键盘导航继续保留清晰的焦点提示。
- 协调确认窗口和规则窗口的标题栏、内容与底部操作区，消除标题栏下方不协调的缝隙和重复圆角。
- 统一页面切换、折叠展开和菜单弹出的节奏；外观菜单采用固定位置的轻量淡入，减少重复布局，快速操作可以打断过渡。
- 候选预览复用静止画面，减少菜单展开期间的重复绘制；尊重系统禁用动画偏好。
- 运行详情不再重复显示已有状态已经表达的正常提示，异常反馈继续保留。

## 三档候选风格

在「候选与外观」的实际预览下方选择：

- **简约**：细腻哑光、轻薄边缘和淡彩选中，以完整选中面与清楚文字表达状态。
- **标准**：清晰边界、实色选中与柔和阴影，延续日常清晰易读的观感。
- **质感**：磨砂底面、统一从左上入光的柔光、微光内缘和带接触阴影的选中层次。

三档与九套候选配色、三种轮廓、字体和间距独立搭配。浅色、深色分别调整受光，高对比配色始终保留实色与清楚边界。旧配置默认标准；风格保存在 `candidate.style`，预览后点击「保存设置」应用，也可放弃草稿恢复原外观。

此项作用于原生 X11 自绘候选栏及剪贴板菜单，共享同一生产渲染器；GNOME Wayland 原生候选面板继续通过「打开 GNOME 面板设置」配置。磨砂与光照由本地绘制实现，不采集桌面背景，不模拟实际背景折射。材质不改变候选内容、排序、分页、点击身份或学习规则。[材质调研与设计依据](../候选框材质设计.md)保留官方资料和具体取舍。

## 升级与数据

继续提供 Ubuntu 24.04 amd64 DEB、openEuler x86_64 RPM 与 Linux x86_64 便携包，沿用现有签名公钥及 APT/DNF 软件源。请使用当前安装渠道升级，保留设置、个人词典、快捷短语、学习记录及剪贴板历史。

本轮在 Ubuntu/X11 的完整 Release 回归通过，包含 GTK3 桌面检查、GTest、原生 Benchmark 及安装升级保护；另完成窄窗口、材质绘制、实际选词和九套候选配色文字对比度检查。发行包继续受本标签的回归、安装升级及生产签名门禁约束；不将本机体验等同于其他桌面和应用的完整专项验收。
