# ModernIME v0.2.1 发布说明

状态：发布准备中，本地 DEB 已生成，尚未创建正式标签、发布发行资产或更新线上软件源。主验证平台为 Ubuntu 24.04 / GNOME。

## 输入体验

- 增加随源码提供、离线构建的独立语境模型。主模型继续负责简拼、整句解码与个人学习，新模型评价前文与候选首词的衔接；缺失时回退原路径。
- 未经过个人训练时，“气球”后输入 `chongqi` 首选“充气”，“他的”后输入 `shenqing` 首选“神情”；明确语境也参与单字排序，“我们去公”后输入 `yuan` 首选“园”。没有词语专用置顶规则。
- 修复退格留字学习结算后丢失当前前文的问题；在 Qt6 编辑器中删除“公园”的“园”再输入 `yuan`，可空格正确补回。
- 修复普通词频跨拼音抢首选：正常输入“设置”不会让 `shuzi` 首选也变成“设置”；同一输入下反复明确选择的纠错偏好仍可生效。
- 保留学习与语境开关、敏感输入、屏蔽、候选身份、消费范围及用户数据格式；诊断增加首字额外先验，便于区分排序原因。

## 客户端与候选外观

- 保持概览等八个主要模块，精简运行状态、试输入与常用设置入口；词典、剪贴板、学习内容集中呈现。
- 统一选择浮层、展开详情、字体选择、焦点与保存反馈；提供晴空蓝、青竹绿、暖砂橙、玫瑰粉、雾紫、深海夜及高对比客户端主题。
- 扩展候选配色与圆润、方正、胶囊轮廓；预览和自绘候选框共用样式，外观不改变候选身份、分页或排序。GNOME 面板保留独立设置和旧偏好编号。
- 更新页由用户点击“检查更新”后授权刷新 APT/DNF 缓存，再查询版本；自动查询不弹授权，刷新中、取消、失败及完成状态有反馈。

## 已验证范围与代价

- Provider、Controller 直接回归通过，既有 20 项功能质量目标全部达标；这不是整体中文输入准确率。
- Qt 6.4.2 / GNOME X11 真实窗口中验证候选显示、数字选词、空格上屏、连续输入及退格补字。客户端 GTK 交互与主题沿用本次改动的直接检查和原生截图；新 GNOME 主题尚未完成 Shell 实机界面验收。
- 独立模型文件约 39MiB，诊断进程峰值内存约增加 36MiB；模型接入的四组采样中位耗时增加约 0.07–0.14ms。单字语境场景另测得约 0.12ms 成本，测量含诊断采集，不能当作按键到屏幕延迟或提速结论。
- 本版集中 CI、发行包生命周期和正式软件源验证尚待完成，不复用 v0.2.0 的通过结果冒充本版。Qt6 原生 Wayland、更多应用及长期日用仍需后续观察。

## 安装与回退

计划提供 Ubuntu 24.04 amd64 DEB、openEuler RPM 和便携归档，继续沿用原有发布公钥及渠道。新增模型源码、构建参数、摘要和 LGPL-2.1-or-later 许可随仓库提供；构建不额外下载模型。

升级不清空或迁移个人词典与学习数据。程序回退保留最新用户数据；GNOME 扩展更新后需重新登录加载。源码、便携、APT 与 DNF 用户保持各自安装渠道，避免直接覆盖其他渠道的文件。
