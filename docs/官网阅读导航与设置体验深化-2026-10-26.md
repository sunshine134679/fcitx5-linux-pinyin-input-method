# 官网阅读导航与设置体验深化（2026-10-26）

## 基线与设计决定

继续用户授权的现代 UI / UX 及交互动效优化，基线为 `66fc767b1391d2f35b0aa00afd050741832a898f`。仅官网、网站测试与说明；原有引擎／GTK 修改不纳入本轮。

本轮 Chrome 观察：场景导航卡片被等高撑开，四卡之间留出大块空白；浮动主导航不显示当前章节；设置预览可调字号与容量，但没有候选间距。

选择三个有直接用途的改进：

1. 主导航随当前阅读章节显示活动状态与连续背景标记，手机菜单同步当前项；滚动只更新导航，不改写体验输入、不改 URL、不强制滚动。
2. 桌面场景卡片紧凑排列；足够高的桌面视口中侧栏吸附，手机仍为紧凑横向四按钮。场景／领域切换保持按钮焦点，不自动弹出手机键盘或把标题滚出视口；选词后的连续输入焦点保持。
3. 设置增加 0–12 px 候选间距，立即改变实际候选栏与物理分页。字号／容量／间距拖动即时更新几何，不等待位置动画；主题反馈和显式场景／选词过渡保留。

沿用前轮 GitHub 参考的共同状态标记与可中断过渡，不套用无关的 Tilt、磁吸或视差。保留蓝白品牌、真实图库、签名源配置、有限本地示例、动态偏好和无 JavaScript 阅读能力。
