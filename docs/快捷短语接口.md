# 快捷短语接口

本轮交付后端接口，客户端页面由独立客户端工作接入。复用 Fcitx5 QuickPhrase 的匹配、候选选择和上屏，不修改普通拼音排序、模糊音或学习策略。

入口：`tools/settings/include/modernime/settings/quick_phrase_store.h`；链接 `modernime_settings_logic`。公共头文件不依赖 GTK 类型。

| 接口 | 用途 |
|---|---|
| `quickPhrasePath()` | 当前 HOME/XDG 下的默认文件位置 |
| `quickPhraseValidation(entry)` | 字段校验；空错误字符串表示有效 |
| `loadQuickPhrases(path)` | 读取条目与同次文件内容基线；先检查 `error` |
| `filterQuickPhrases(entries, query)` | 内存搜索缩写或文本，忽略英文大小写；空查询返回全部；结果为原列表下标 |
| `saveQuickPhrases(path, baseline, entries)` | 修改条目副本后整体保存，完成新增、编辑、删除 |
| `reloadQuickPhrases()` | 经 DBus 仅重载 QuickPhrase，不重启 Fcitx5、不改写触发键 |

## 客户端接线

1. 在已有 Worker 中读取，成功后保留返回的 `QuickPhraseSnapshot`，界面编辑其 `entries` 副本。不要改写快照中的 `content`、`exists` 或把草稿当作文件基线。
2. 新增向副本追加；编辑替换对应原列表项；删除移除对应原列表项。搜索结果下标映射回原列表后再编辑/删除，不能把过滤后的展示序号当作原始下标。
3. 在 Worker 中调用保存。`QuickPhraseSaveStatus` 区分 `Saved`、`Invalid`、`Conflict`、`IoError`，附有错误文本。`Conflict` 时文件未覆盖，应保留草稿、重新读取并让用户确认合并。读取失败/格式不支持时禁止覆盖。
4. 保存成功后重新读取快照，再调用重载。`QuickPhraseReloadResult.applied` 与保存状态独立：未应用不代表未保存，不能因此重复新增。`error` 包含未应用原因；可稍后重试重载。
5. Worker 结果由客户端现有生命周期/代次机制投递；过期回调不能覆盖新列表或访问已销毁窗口。除纯校验、路径与内存搜索外，接口包含阻塞文件或 DBus I/O，不在 GTK 回调中直接调用。

## 数据和输入约定

- 缩写：1–30 个小写英文字母；固定文本：非空 UTF-8 单行，禁止换行、制表符和控制字符。同一缩写可对应不同文本；完全重复的缩写/文本保存时返回 `Invalid`。
- 默认文件：`$XDG_DATA_HOME/fcitx5/data/quickphrase.d/modernime.mb`，未设 XDG 时使用 `~/.local/share/…`。只管理该独立文件，不修改已有 `QuickPhrase.mb`、其他短语文件、个人词典或学习库。清空学习/个人词典不清除快捷短语。
- 文件采用 Fcitx5 原生文本转义，保留空格、引号和反斜杠；锁内核对原内容后原子写入。所有客户端写者应通过同一接口；不声称能阻止忽略锁协议的外部编辑器竞争写入。
- 默认触发键为 `Super+;` 或 Super 加反引号键；触发后输入缩写，空格选择当前项、数字键选择候选，`Esc` 取消。已有 Fcitx5 自定义触发键和选词修饰键以用户配置为准。
- 重载针对运行中 Fcitx5 自己的 HOME/XDG 数据目录。生产接入使用 `quickPhrasePath()` 并与 Fcitx5 保持同一用户环境；显式其他路径用于隔离验证，不会被运行中的日常输入法自动加载。
- 需要启用 Fcitx5「快速输入 / Quick Phrase」插件。可靠引号解析需要 Fcitx5 ≥ 5.0.16；旧构建返回明确不可用信息，保留原有个人词典功能。

官方能力依据：[QuickPhrase 文件说明](https://fcitx-im.org/wiki/QuickPhrase)、[Fcitx5 5.1.7 原生 Provider](https://github.com/fcitx/fcitx5/blob/5.1.7/src/modules/quickphrase/quickphraseprovider.cpp)。

验证范围：仅增量构建、存储/搜索与真实 QuickPhrase 触发选词用例，以及隔离 DBus 重载；未进行全量回归、安装卸载或发布。客户端界面与本机部署不在本次最终交付范围。
