# ModernIME 后端扩展接口

本文描述 2026-11-13 新增的后端接口，适用于当前源码构建。六项能力已实现；本轮不新增 GTK 设置页面，不代表已发布新版本。客户端可以通过会话 DBus 调用管理能力，嵌入式消费者可以使用相应 C++ 接口。

## 1. 会话服务与调用约定

- 服务名、接口名：`org.modernime.Backend1`
- 对象路径：`/org/modernime/Backend1`
- 方法：`Execute(s action, as args) → s json`
- 服务随真实 Fcitx5 ModernIME 插件及拼音资源初始化启动，不是单独的常驻进程。客户端应等待名称出现，并在输入法重启后重新连接。
- 管理操作在独立工作线程串行执行；客户端使用异步 DBus 调用，避免阻塞自身界面。磁盘操作可能超过普通 DBus 默认超时，建议明确设置 30 秒超时。超时不等于服务端取消操作，修改操作超时后先查询状态。
- 所有方法返回 JSON。成功包含 `"ok":true`；失败为 `{"ok":false,"error":"错误码","message":"中文原因"}`。传输错误另按 DBus 错误处理。
- `action` 最长64字节，最多8个参数，每个参数最长4096字节；布尔参数为小写 `true/false`，数值使用十进制非负整数字符串；文件参数必须为绝对路径。
- `capabilities` 的 `version` 当前为1；客户端应按 `actions` 与 `selectionComponents` 探测能力，不依赖显示名称。

```bash
gdbus call --session \
  --dest org.modernime.Backend1 \
  --object-path /org/modernime/Backend1 \
  --method org.modernime.Backend1.Execute \
  capabilities '[]'

gdbus call --session \
  --dest org.modernime.Backend1 \
  --object-path /org/modernime/Backend1 \
  --method org.modernime.Backend1.Execute \
  learning.search "['nihao', '0', '100', 'false']"
```

`gdbus` 输出的是包含 JSON 字符串的 DBus 元组；客户端应先解包返回字符串，再解析 JSON。

## 2. 学习精细管理

| action | args | 成功字段 / 行为 |
|---|---|---|
| `learning.list` | `[]` 或 `[offset, limit, suppressedOnly]` | `total`、`records` |
| `learning.search` | `[query]` 或 `[query, offset, limit, suppressedOnly]` | `total`、`records` |
| `learning.forget` | `[phrase, pinyin]` | 忘记该文本与拼音身份的全部上下文偏好及屏蔽记录 |
| `learning.unsuppress` | `[phrase, pinyin]` | 仅解除该身份屏蔽，保留频次、时间及负反馈 |

默认 `offset=0, limit=100`；`limit` 范围1–200，`offset` 最大200000。`suppressedOnly=true` 只列出屏蔽身份，`false` 表示全部记录；没有“只列未屏蔽”的 DBus 参数。C++ 查询的 `optional<bool> suppressed=false` 支持只列未屏蔽。

`query` 对文本做子串匹配，并对规范化后的拼音做子串匹配。拼音忽略大小写及兼容分隔符；显示文本大小写保持原身份。结果按规范拼音、文本稳定排序，同一身份的上下文记录聚合：

```json
{"ok":true,"total":1,"records":[{
  "phrase":"你好","pinyin":"nihao","frequency":5,
  "lastSelectedMs":1000,"negativeFeedback":0,"suppressed":false,"contextCount":2
}]}
```

`frequency`、`negativeFeedback` 为各上下文非负计数的饱和求和，`lastSelectedMs` 为最大选用时间（Unix毫秒），`contextCount` 为底层记录数。分页基于一次不可变快照；两次请求之间输入继续产生学习时，客户端应允许列表变化。

忘记不会删除系统词库、词库包或个人词典中的词，因此该词仍可能按基础排序出现。操作沿用正在工作的同一个 `LearningWriter`，返回成功前执行 `flush()`；`persistence_failed` 表示尚未持久化，后台保留重试状态，不可当作成功。候选在后续编辑/重新生成时采用新快照。手动管理是用户明确的数据操作，不会启用自动学习；密码/禁学输入仍不产生学习事件。

C++ 入口：

- `core/include/modernime/core/learning_snapshot.h`：`LearningQuery`、`LearningRecord`、`LearningQueryPage`、`LearningSnapshot::queryLearningEntries(query)`。
- `core/include/modernime/core/learning_writer.h`：`enqueueForget(phrase,pinyin)`、`enqueueUnsuppression(phrase,pinyin)`、`flush()`、`snapshot()`。
- 所有写入经过 Writer 和 SQLite/LMDB 事务；不要在活动数据库上另建第二个 Writer。

## 3. 离线词库包

| action | args | 行为 |
|---|---|---|
| `pack.list` | `[]` | 返回 `packs`，按 ID 排序 |
| `pack.inspect` | `[directory]` | 校验并返回 `pack`，不导入 |
| `pack.import` | `[directory]` | 导入新 ID；已存在返回 `pack_exists` |
| `pack.update` | `[directory]` | 替换已存在 ID，保留本地启停状态 |
| `pack.enable` / `pack.disable` | `[id]` | 调整用户副本；内置包首次操作先复制到用户目录 |
| `pack.remove` | `[id]` | 移除受管用户副本；若同 ID 有内置包，则回退内置包 |

每项元数据为 `id/name/source/license/version/entryCount/enabled/bundled`。同 ID 用户包覆盖内置包。若要关闭内置包，使用 `pack.disable`；`pack.remove` 不删除程序安装的内置数据。包删除、关闭不会删除该词已有的个人学习，词也可能由其他词库来源继续召回。

默认用户目录为 `$XDG_DATA_HOME/modernime/dictionary-packs/user`，未设置 XDG 时使用 `~/.local/share/modernime/dictionary-packs/user`。内置包安装到 `<prefix>/share/modernime/dictionary-packs`。与个人词典、学习数据库分别管理。

包是一个目录，包含：

```ini
# manifest.ini
id=my-domain
name=我的领域词
source=自编词表
license=CC0-1.0
version=1.0.0
entry_count=1
```

```text
# entries.tsv，实际使用 TAB 分隔；三列为完整读音、文本、权重
rong'qi'jing'xiang	容器镜像	0
```

上例的 `\t` 表示实际制表符。ID 限小写字母、数字及连字符，1–80字节；名称、来源、许可和版本必填；词条数1–200000且须与解析后的去重词条数一致。两个文件分别不超过32MiB；词条键最多128字节、文本最多512字节，权重沿用个人词典语义且不得超过50。普通中文须为有效完整拼音；混合词的 ASCII 部分可以作为完整键的一部分。目录和这两个叶文件不接受符号链接。

三个领域包 `computing/medicine/law` 默认关闭，各3词；`mixed-common` 默认开启，包含3个混合词。这些是可验证的小型示例，不是完整行业词库。

服务成功表示包文件操作完成；引擎每2秒轮询并在后台准备新资源，随后在主线程交换，新页代次撤销旧选择。完成加载通常还需要一个轮询周期及后台加载时间，API 没有“引擎加载完成”信号。调用方可重新输入核对实际候选。校验/加载失败不发布半成品，输入继续使用已有资源。

C++ 入口 `modernime/pinyin/dictionary_pack.h`：`DictionaryPackStore(root)` 的 `validate/list/loadEnabled/importPack/setEnabled/remove`。这些是阻塞管理接口，应在工作线程调用。`PinyinSharedResources` 的同步管理接口供其所有者线程使用；生产插件使用 `requestDictionaryPackRefresh()/consumeDictionaryPackRefresh()` 准备与发布，Provider 只读已发布资源。

## 4. 中英混合词

完整键 `agu → A股`、`txu → T恤`、`dockerrongqi → Docker容器` 已接入统一候选链。可通过个人词典或词库包扩展；最多补充16项匹配证据，保留输出大小写。词典词证据只授予已登记或已经学习的混合词，不能把原生“是i”等任意 ASCII+汉字组合视为合法词典词。

Provider 的 `replaceInput()` 接受大小写等价完整键；实际键盘入口沿用小写录入，大写键仍遵守原有英文直通行为。本轮混合词不支持简拼/双拼别名。候选使用中文提交角色、规范完整键及实际输入字节消费；选择沿既有学习资格，屏蔽对静态和学习来源均有效。重复选择能参与统一排序，不单独固定插入高位。

入口：`modernime/pinyin/mixed_word_index.h`、`PinyinCandidateProvider`；客户端直接消费已有 `CandidateItem`，没有新增候选 UI ABI。

## 5. 用户数据包

| action | args | 行为 |
|---|---|---|
| `bundle.export` | `[newDirectory]` 或 `[newDirectory, selectionCSV]` | 导出到不存在的新目录 |
| `bundle.preview` | `[directory]` | 返回 `token/fingerprint/differences` |
| `bundle.restore` | `[directory, token, selectionCSV]` | 根据预览恢复显式选择的组件 |

组件名：`settings,dictionary,quick-phrases,learning,clipboard-history,clipboard-favorites`。CSV 不允许空项、重复项或未知组件。默认导出前四项，剪贴板历史与收藏均默认排除。恢复必须显式提供非空选择，不能省略。

`differences` 每个组件包含 `component/included/present/currentPresent/changed/bundleEntries/currentEntries`。`included=false` 表示导出时未选择；`present=false` 表示没有源文件/状态。不存在的源组件恢复时跳过，不隐式删除当前数据。计数用于提示，不替代内容指纹校验。

令牌绑定规范路径与当次预览，最多保留8个，10分钟失效；输入法重启后失效。进入维护后的每次恢复尝试都会消费令牌，失败须重新预览。预览后备份包或所选当前数据改变则拒绝覆盖，应让用户重新查看差异。

学习以逻辑条目导出，包含上下文、频次、时间、负反馈及屏蔽，支持 SQLite WAL 和 LMDB；恢复递增当前清空世代，不导入旧世代。进入恢复前暂停文件重载和剪贴板写入，排空已接受任务；恢复后重新加载，剪贴板恢复观察先建立基线。恢复过程中之后接受的新学习保留，不被旧备份覆盖。

文件组件按固定顺序持有现有写锁，暂存并 fsync 原文件，原子替换；学习最后通过同一 Writer 的事务提交。普通错误回滚文件，回滚失败会报告保留路径。进程崩溃不具备跨文件总事务保证，遗留 `*.rollback` 文件为原数据恢复线索。

格式版本1，目录清单 `manifest.txt`，数据文件为 `settings.conf/dictionary.txt/quick-phrases.mb/learning.bin/clipboard-history.bin/clipboard-favorites.bin`。目录0700、数据0600；单文件及累计内容最多256MiB。FNV-1a64 仅检测损坏，不提供来源认证或加密。用于用户信任的本地备份；不要把陌生来源数据包当外部词库导入，外部词库频次平滑限制仍由原导入通道执行。

C++ 入口 `modernime/core/user_data_bundle.h`：

```cpp
UserDataBundle data(paths, existingWriter);
data.exportTo(directory, selection, &error);
auto preview = data.preview(directory, &error);
if (preview) data.restore(directory, selected, *preview, &error);
```

调用必须在工作线程，使用活动数据库的共享 Writer；宿主负责维护栅栏。独立消费者可使用 `AsyncClipboardHistory::pauseForMaintenance()` 非阻塞请求暂停，重复轮询直至 true，完成后 `resumeAfterMaintenance()`，并重设采集基线。不可在输入主线程等待暂停或执行备份。

设置主题随原设置文件一起备份；本轮不打包程序、内置模型、内置主题资源或词库包目录。

## 6. 拼音候选笔画/部件筛选

实际入口：有拼音组合时按反引号键 `` ` ``，继续输入笔画或部件拼音；Esc 退出筛选并保留原拼音，Backspace 删除筛选串，空串时再退格退出。空格/回车/数字键仍选择候选。敏感输入不可进入，切换敏感状态清除筛选。

- 笔画：`h/s/p/n/z` 对应横/竖/撇/点捺/折；C++ 表达式也支持 `1/2/3/4/5`。`s:nzhh` 显式指定笔画前缀，键盘可直接输入 `nzhh`。
- 部件：`c:mumu` 按部件拼音前缀筛选；用 `c:` 消除与笔画字母的歧义。
- 例如 `shi` 后进入筛选输入 `nzhh`，可选“试”，原始输入仍为 `shi`，选择只消费对应原始拼音。
- 默认检查候选第一个 Unicode 字符；C++ `characterOffset` 支持0–31。查询最长64字节。数据不覆盖的字不会匹配；组件前缀与独立拆字查询的精确匹配语义不同。

C++：

```cpp
CandidateFilterIndex index(componentPath, strokePath); // 资源预热阶段构造
if (auto predicate = index.predicate("c:mumu", 0)) {
    provider.setCandidateFilter(*predicate);
}
provider.clearCandidateFilter();
// Controller 入口：setCandidateFilter(expression)、clearCandidateFilter()、candidateFiltering()
```

谓词拥有不可变证据，只筛统一排序后的列表，保留相对顺序、完整身份和消费；设置/清除会更换页代次。显式筛选无结果时最多追加16批原生冷候选，仍不能承诺遍历全部同音字。普通输入保持原128项首批预算，不读笔画文件。筛选没有 DBus 命令，前端集成使用 Controller/Provider 接口及现有候选页。

数据离线随仓库/安装携带；笔画表70,196行，来源许可见 `data/components/数据来源与许可.md`。

## 7. 应用兼容诊断

| action | args | 成功字段 |
|---|---|---|
| `applications` | `[]` | `applications`：最多32个实际观察过的应用身份 |
| `diagnostics` | `[]` 或 `[application]` | 最近应用或精确身份的报告 |

报告字段：`observed/application/frontend/display/transport/toolkit/sandbox/focused/sensitive/surroundingText/clientPreedit/cursorRectangle/modernimeSelected/observedAtMs/handledKeys/maximumDispatchUs/suggestions`。

事实来自 Fcitx 输入上下文；未观察应用 `observed=false`，不能据此判定该应用已配置或未配置成功。`transport` 根据实际上下文显示身份识别 `x11/wayland/unknown`；toolkit 与 sandbox 没有可靠宿主证据时为 `unknown`，不按全局环境猜测。`observedAtMs` 为进程单调时钟毫秒，供同会话新旧比较，不是 Unix 时间。

`maximumDispatchUs` 是本次进程观察期间按键的引擎事件派发最大耗时（微秒），不包括应用绘制和端到端显示延迟，不可当作输入到像素延迟。敏感上下文不记录输入文本、周边文本内容和按键计数；整个诊断均不保存正文或上屏内容，数据仅在内存保留。建议为能力缺失的排查提示，不会自动修改环境或应用配置。

C++ 入口 `modernime/core/input_compatibility.h`：适配层调用 `InputCompatibilityTracker::observe/recordKey`，客户端读 `report/applications` 快照。

## 8. 错误与集成边界

常见错误：`unknown_action/invalid_arguments`、`learning_unavailable/learning_reloading/persistence_failed`、`invalid_pack/pack_exists/pack_missing/pack_write_failed/pack_remove_failed`、`bundle_export_failed/bundle_preview_failed/invalid_preview/maintenance_unavailable/bundle_restore_failed`、`diagnostics_unavailable`、`operation_failed/internal_error/stopping`。应显示服务返回的中文原因；不要在失败时假装删除、导入或恢复成功。

保持八个现有主要模块。core 拥有数据与不可变快照，pinyin 拥有召回/共享资源，adapter 拥有宿主事件和 DBus 调度，UI 继续只展示候选。没有新增系统依赖、动态算法插件或数据库 schema。停止使用新能力不删除旧学习与用户文件。

本轮必要验证覆盖新增后端用例、双后端学习管理、事务冲突/失败回滚、剪贴板维护、原 Writer/存储/快照契约、日常输入模拟、原 Provider/英文仲裁及实际 Xvfb+Fcitx5+GTK 跨进程输入。全量 CTest、全量 Benchmark、跨发行版和全新克隆安装矩阵留在集成发布阶段；本轮没有据局部结果宣称这些矩阵通过。

本机 Release 局部量测（预热后各100样本，5组完整输入轮换，禁学空库）：`replaceInput+最终候选页` P99约5.54ms、最大5.56ms；显式笔画谓词构造P99约3.42ms、最大4.16ms。这是局部观测，不替代200000条完整Benchmark门禁，也不代表跨设备或端到端延迟保证。
