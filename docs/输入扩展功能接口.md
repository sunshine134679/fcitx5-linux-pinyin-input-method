# 输入扩展功能接口（第 9–11 项）

仅后端/引擎接口，客户端继续现有八个模块。保留用户已有配置、主题、词典和学习数据。每项必要验证通过后在主目录 main 提交，不推送或发布。

## 9. 简繁切换：复用 Fcitx

ModernIME 激活时加入 Fcitx `chttrans` 原生状态动作。默认快捷键 `Ctrl+Shift+F`，用户已在 Fcitx 修改快捷键时以其配置为准；原生菜单动作同样可切换。`chttrans` 是可选模块，缺失或禁用时普通输入保持可用；Ubuntu 对应 `fcitx5-chinese-addons` 包。复用原生或 OpenCC 引擎及其用户配置，不另设 ModernIME 简繁开关覆盖它。

客户端通过会话 DBus：服务 `org.fcitx.Fcitx5`，对象 `/controller`，接口 `org.fcitx.Fcitx.Controller1`。

- `GetConfig(s uri)`，uri 为 `fcitx://config/addon/chttrans`，返回当前配置 Variant 与配置描述。
- `SetConfig(s uri, v config)` 提交修改后的配置，即时应用并由 Fcitx 保存。需提交最新读取的配置，保留其他输入法及转换引擎/配置档；不要用默认配置覆盖读取失败。
- C++ 可用 `fcitx::variantToRawConfig()` / `rawConfigToVariant()` 转换。新增头文件 `modernime/fcitx5/script_conversion.h` 提供 `traditionalOutput(const RawConfig&)` 与 `setTraditionalOutput(RawConfig&, bool)`，只调整 `EnabledIM` 中的 `modernime`，不修改其他字段；`kChineseScriptConfigUri` 提供 URI。

状态唯一归 Fcitx，原生快捷键切换后客户端应重新查询，不将镜像值写进 `ModernIMESettings`。原始候选文本/拼音/学习身份仍为简体，输出由 Fcitx 转换；不要修改 `CandidateSelectionRequest.expected`。Fcitx 的转换过滤覆盖其提交输出，包括中文短语/剪贴板文本，ASCII 不变。撤销仍需实际周边文本精确匹配，转换后与原身份文本不一致时不执行删除。

显示接入：Fcitx 原生面板沿其 `Instance::outputFilter(ic, Text)`；ModernIME 自绘候选栏由客户端 AI 在显示投影时复用同一接口，保留原始身份。此处不修改 GTK 绘制代码。官方依据：[chttrans 实现](https://github.com/fcitx/fcitx5-chinese-addons/blob/master/modules/chttrans/chttrans.cpp)、[Fcitx DBus 配置接口](https://github.com/fcitx/fcitx5/blob/master/src/modules/dbus/dbusmodule.cpp)。

验证：`modernime_script_conversion` 在独立 XDG 环境加载本次真实 ModernIME 插件与系统 chttrans，覆盖原生动作、快捷键、繁体显示过滤、实际选词上屏、恢复简体、ASCII 以及保留其他输入法配置，已通过。未修改日常简繁配置，未重启日常输入法。

## 10. 离线符号搜索、分类与收藏

设置新增 `bool ModernIMESettings::symbolSearchEnabled=true`（键 `symbols.enabled`）及 `std::set<std::string> symbolFavorites`（默认空、最多128项）。收藏 ID 是目录条目的完整 UTF-8 `text`，包含 emoji 变体选择符及成对标点；新增用 `insert(id)`，取消用 `erase(id)`，通过原 SettingsStore 冲突保存接口提交并传入 `loaded.rawLines`，不手写配置编码。存储键为 `symbols.favorite.<UTF-8字节小写hex>=true`，如 `symbols.favorite.e28692=true` 表示 `→`，删除不会因保留原始行而恢复。未知条目拒绝保存。

`modernime/core/symbol_catalog.h` 供客户端离线只读调用，无磁盘/网络访问：

```cpp
SymbolCatalog::entries(); // const vector<SymbolEntry>&，170项
SymbolCatalog::find(id);  // const SymbolEntry*，不存在为nullptr
SymbolCatalog::search(query, category, favoriteIds, favoritesOnly, limit);
// 返回 vector<const SymbolEntry*>；条目指针在进程内稳定
// SymbolEntry { id, text, name, category, vector<string> aliases }
```

分类键：空串=全部，`punctuation` 常用标点、`math` 数学、`units` 单位、`arrows` 箭头、`emoji` 表情、`other` 其他。支持中文名称、拼音别名、英文别名和原符号子串；ASCII 不分大小写、忽略空白。`favoriteIds` 为 vector，可由 Settings 集合构造；收藏优先，或只看收藏；默认最多60项，客户端可传200获取完整目录。

引擎中文输入 `v;` 进入，如 `v;jiantou` 搜箭头；全拼 `v` 菜单追加「符号搜索」「收藏符号」。数字、Space/Enter 或点击上屏，方向及翻页键沿用，Esc 取消；无匹配/空收藏提示不可提交。内部入口 `KeyKind::OpenSymbols/OpenFavoriteSymbols`，状态 `AuxiliaryInputMode::Symbols`，分类切换调用 `ModernIMEController::setSymbolFilter(category, favoritesOnly)`；客户端可在面板上接分类/收藏按钮，不改变查询原文和候选身份。结果为 Generated，不学习。收藏管理使用 SettingsStore，本轮不在按键线程写配置。

现有160个符号宏的全部值与顺序保留，共用目录事实源 `symbolMacroValues(key)`；rq/sj/xq/数字动态宏保持原入口，普通拼音排序政策不变。增量插件构建、`modernime_symbol_catalog/settings/typing_features` 通过，覆盖搜索/分类/收藏、配置往返及删除、旧宏保留、原计算器位置、实际查选、过期选择拒绝和提示不提交。

## 11. 剪贴板搜索与收藏

继续由 `clipboard.enabled` 控制整个剪贴板能力，无新主模块。`SettingsPaths::clipboardFavorites` 为新增路径，通常是 `~/.local/share/modernime/clipboard-favorites.bin`；历史仍用 `clipboard-history.bin`。文件与历史格式一致，采用独立锁、0600原子保存。收藏最多30条，每条最多1MiB，满额拒绝新项，不淘汰已有收藏。

**数据关系**：清空历史保留收藏；删除历史条目保留其收藏；取消收藏不删除历史；清空收藏是独立动作。收藏按完整文本去重，无自动学习或词典写入。需要“全部清空”时，客户端必须清楚展示两项作用，并分别调用两份存储，不能将“清空历史”隐式扩大到收藏。

核心接口 `modernime/core/clipboard_queries.h`：

```cpp
ClipboardFavorites favorites(paths.clipboardFavorites); // 同步接口，放既有Worker
favorites.load(&error);
favorites.add(text, &error);       // 重复添加幂等，不重排
favorites.remove(expectedText, &error); // 完整文本身份，失效时失败
favorites.clear(&error);          // 只清收藏
favorites.entries();             // const vector<string>&
auto matches = searchClipboard(history, favorites.entries(), query, favoritesOnly, 60);
// ClipboardSearchMatch { string_view text; bool favorite; optional<size_t> historyIndex; }
```

搜索为空时列出全部，收藏优先、与历史按完整文本去重；ASCII 不分大小写，中文按字串匹配，不提供拼音匹配。结果借用输入 vector 的字符串，消费期间必须保持两份不可变快照存活；客户端在既有 Worker 搜索大条目，不能让 `string_view` 跨快照失效。删除历史可沿现有 `ClipboardHistoryModel::remove(index, expectedText)`，不要直接用过滤后的显示下标操作原历史。同步读写失败保留旧可见收藏，读取失败时不得拿空默认覆盖文件。

引擎复用 `AsyncClipboardHistory(historyPath, notify, favoritesPath)`，第三参为空时兼容旧实例且不启用收藏；后台线程同时持有两份独立存储。`setFavorite(text, bool)` 只非阻塞排队，返回 true 表示已接受，**不代表已保存**；`lastAcceptedFavoriteOperationId()` 给出本次接受ID。最多30个已接受未消费完成的操作，关闭/无路径/非法长度/队列满返回false；失败操作报告后不自动重放。`takeSnapshot()` 消费结果并推进等待批次，`shutdown()` 排空已接受操作。

`ClipboardSnapshot` 保留旧4字段，追加 `favorites`（`shared_ptr<const vector<string>>`）、`favoritesAvailability`、`favoritesError`，以及 `lastFavoriteOperationId/lastFavoriteOperationSucceeded/lastFavoriteOperationError`。前三个历史字段及 `error` 仍只说明历史；收藏错误单独报告。操作字段描述最后完成操作，`favoritesError` 还可包含同批较早失败；客户端建议串行操作并等待接受ID对应的确认，不将批次最后一次成功当成全部成功。收藏文件外部变化在既有刷新任务中读取，无变化复用快照，失败下次继续重试；不在按键线程读写文件。

输入 `V+2` 打开合并历史，收藏标注“收藏”。面板中 `Ctrl+F` 进入搜索，输入ASCII关键词（含数字和空格），Enter/点击提交完整匹配条目；方向键编辑查询/移动选择，Esc先退出搜索，再按关闭历史。`Ctrl+D` 对当前条目收藏/取消，等待保存确认期间不重复排队，不将操作提示上屏。中文查询由客户端搜索框或 `ModernIMEController::setClipboardQuery(std::string query, bool favoritesOnly=false)` 接入，查询最多128字节。

内部接口还包括 `clipboardSearching()`、`favoriteCurrentClipboard()`、`clipboardFavoritePending()`、`setClipboardSnapshot(const ClipboardSnapshot&)`。过滤/收藏结果变化更新展示代次，旧点击拒绝；普通历史新增继续保留既有导航行为。进入敏感状态清掉查询并拒绝新的搜索/收藏请求，已接受任务仍按协议完成；重置同样清掉查询。异步错误通过快照及引擎提示可见，不隐藏失败。

必要验证：查询/收藏纯接口、同一worker的真实慢写非阻塞与关闭排空、Controller过滤/选择/旧代次、既有引擎状态与异步历史，以及真实共享插件的 `V+2 → Ctrl+F → Ctrl+D → Enter`、历史清空保留收藏和独立取消收藏。仅运行这些直接受影响项目。
