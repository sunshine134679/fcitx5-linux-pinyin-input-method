# ModernIME 官方网站

公开地址：<https://sunshine134679.github.io/fcitx5-linux-pinyin-input-method/>

网站使用原生 HTML、CSS、JavaScript，没有 npm 构建步骤、外部字体或新增输入法运行依赖。

## 本地预览与验证

```bash
python3 -m http.server 4173 --directory website
python3 tests/website/website_test.py
node tests/website/app_test.js
node tests/website/motion_test.js
node tests/website/install_test.js
```

访问 `http://localhost:4173`。下载区从 GitHub Releases 只读查询最新正式发布；断网、超时或限流时，回退到已核验的资产版本。新增发行版或变更资产命名时，应同步调整 `app.js` 的兼容规则和页面说明。复制按钮在成功复制后通过 `data-copied="true"` 给出绿色确认态反馈，权限不足时会选中命令供手动复制。

## 发布与软件源共存

`website.yml` 在官网相关代码推送到 `main` 时运行：读取既有 `gh-pages` 分支，通过 `scripts/prepare_website.py` 覆盖首页文件和 `assets/`，完整保留 `/apt`、`/rpm` 的路径和内容，再部署并保存回 `gh-pages`。脚本校验覆盖前后全部软件源文件的 SHA256，不会重新签名或生成软件源。

`release.yml` 也会取 `main` 上的官网覆盖到发布产物，因此重新发布旧产品标签也会保留官网。两个发布任务共用 `modernime-pages-sync` 串行组，避免并发覆盖软件源历史。

客户端截图是当前源码的界面示例，不承诺已发布的安装包包含源码之后的所有界面更新。网页候选栏是明确标注的交互示意，不收集键盘输入，不模拟真实输入法转换。

## 视觉与动效维护

首屏采用大字排版与流线图形，三种输入场景每隔 6.5 秒轮播并演示拼音输入，支持暂停／继续与重播当前场景。鼠标悬停或键盘焦点进入演示区时暂停自动切换；离开视口或切到后台时清除打字和轮播计时器，返回后恢复。系统减少动态效果偏好关闭自动轮播、入场、打字和截图切换动效，手动选择场景仍即时可用，偏好恢复时动效也能重新启用。

独立 `motion.js` 不依赖下载查询和图库脚本，观察器不可用时首屏仍能运行。滚动入场只给已进入视口的元素添加动画，默认内容始终可见，避免初始化故障导致整段空白。阅读进度通过被动 scroll 监听与单帧合并更新，并在布局尺寸变化后重新计算。

ChatGPT Sites 地址为 <https://modernime-official.bubblyfig129.chatgpt.site/>，它使用独立的 Sites 源码仓库，GitHub Pages 发布不会自动更新这个地址。修复或更新两处官网时需要同步同一份 `website/` 文件，通过 `prepare_website.py` 生成带内容哈希的脚本和样式引用，再用 Sites 的源码同步及部署流程更新原 project_id，保持公开访问范围。Sites 导出版本将 canonical、分享图片和 sitemap 指向对应托管地址；APT/RPM 安装命令继续指向 GitHub Pages 的签名软件源。

客户端展示源于真实 GTK3 客户端的 3× PNG（2940 × 2160 px），配合 GTK 设备缩放导出字体与图标；素材来自隔离的示例数据目录，不读取个人词典和剪贴板内容。同一份高清 PNG 导出 1×（980 × 720）与 3× 无损 WebP，使用 `srcset` / `sizes` 让浏览器选择合适分辨率；三张 1× 图合计约 306 KB，3× WebP 合计约 631 KB。不要把内容不同的旧版 1× PNG 混入这组响应式图片。展示宽度最多 980 CSS px，点击图片仍查看 3× PNG 原图。替换时同步图片尺寸、`data-src`、`data-srcset`、`data-original` 与首张图的 `srcset`；测试检查尺寸、候选源、原图和内容差异。

图库由独立的 `gallery.js` 初始化，不依赖下载查询或首屏动画。距视口 400 px 内提前加载并解码三张图，悬停与键盘聚焦也会预加载；节省流量模式关闭自动预加载。解码结果按路径、显示宽度和设备像素比缓存，切回已准备的图片无需再创建加载请求。图片解码成功后同步当前图、原图链接、说明和选中标签，前后两层以 240 ms 交叉淡入；减少动态效果时立即切换。准备阶段标签显示进度，失败或 12 秒超时保留原图并支持重试。快速连续选择时只接受最后一次请求的结果。

下载卡片采用原生单选框平铺系统版本，支持键盘方向键切换，避免原生下拉弹层遮挡下载操作。自 v0.1.23 起，DEB 与 APT 仅支持 Ubuntu 24.04 LTS（Noble）/ amd64；Ubuntu 22.04 / Debian 12 已停止预编译支持，页面明确提示升级系统或按源码说明自行验证。`install.js` 仅接受 Noble 套件，避免生成已停止支持的软件源命令。openEuler 与其他 Linux 卡片中间区域采用三项 `.compat-item` 规格条，主次操作按钮通过卡片弹性布局在桌面端保持基线对齐。软件源入口优先，直接安装包入口保留为次按钮。`install.js` 独立负责系统源配置、分步命令复制和导航折叠；JS 失效时仍可手动展开原生 details 并复制默认系统命令。复制失败会选中完整命令。软件源客户端配置沿用 `/apt/client/*.sources` 与 `/rpm/client/*.repo`，不绕过 Signed-By、gpgcheck 或 repo_gpgcheck。

紧凑场景模块并入“输入体验”，提供聊天、写作、剪贴板三种可切换的静态网页示意，以及六类常用场景的词汇展示。场景最小高度由 530 px 降至 330 px，去掉与前面候选演示重复的候选栏，背景大字水印置于右下角以避免与剪贴板卡片右上角快捷键角标冲突。示意无需网络请求，三个场景共用一个网格位置，隐藏场景保留尺寸，以最高内容确定高度，避免切换及文字缩放导致跳动；不读取用户剪贴板、不收集键盘输入。网站仍为无构建依赖的原生页面，发布时保持签名软件源不变。

发布脚本自动在脚本与样式 URL 中加入文件内容 SHA256 的前 12 位。内容更新会改变 URL，防止旧缓存脚本与新 HTML 混用；本地预览仍直接使用源码文件。新增脚本时同时维护发布脚本 FILES 与 website.yml 的持久化清单。

排版使用宋体展示标题与无衬线正文形成变化：首屏标题 36–58 px、章节标题 29–38 px、正文 15–16 px，辅助信息至少 13 px。正文默认 500 字重，标题与关键操作加强粗细，字体采用系统字体，无远程字体请求。候选栏示意采用容器查询与弹性间距分配，使 9 个单字候选和 7 个双字候选在桌面及 390 px / 360 px 窄屏上均完整单行显示、不溢出截断。

## 导航、搜索与分享

手机顶部使用原生 `details` 四项菜单（体验／设置／安装／GitHub），采用纯白实底浮层与多层投影以防背景文字透出，选择后收起，Escape 收起并返回菜单焦点。安装区旁保留三步启用提示与完整运行配置链接。页面提供 canonical、Open Graph 图片、Twitter Card 与 SoftwareApplication JSON-LD；更新产品版本时同步结构化数据和静态下载回退。`sitemap.xml` 列出官网首页，`robots.txt` 随站发布；GitHub Pages 项目子路径下的 robots 文件不会替代域名根路径的爬虫规则。

CSS 按 tokens → base → components → sections → responsive → motion 组织，通过 `--in-oklab` 渐进增强插值令牌与分层阴影令牌统一卡片层次，响应式规则集中在五个断点，避免在尾部追加整套覆盖样式。清理前后已做静态级联对照，再按当前新组件维护。

实机输入视频尚未提供，不用网页动画代替录屏。后续录制 10–20 秒实际桌面操作后，再添加视频，并标注发行版、显示协议和实际软件版本。2026-10-15 及 2026-10-19 已通过浏览器检查桌面与手机首屏、候选栏单双字切换、日常场景切换、截图切换、安装抽屉和手机导航；系统动态效果偏好及后台计时由自动化生命周期测试覆盖。

## 图标与窄屏交互

官网导航和 favicon 使用 `config/icons/` 中同源的用户 MI 图标，分别为 128 px 和 32 px PNG；不下载完整源图作为小图标。桌面按钮的布局规则只处理箭头，不覆盖移动文案的隐藏状态。

手机首屏只显示一句定位、三个核心能力和主要下载安装按钮，保留输入演示，并将 `.demo-index` 题注与上方主按钮留出充足间距；桌面首屏上下 80 px，演示卡偏移 24 px。≤360 px 顶栏保留品牌文字、图形菜单和安装入口；菜单摘要保持可访问名称、44 px 操作尺寸，并支持点外部关闭。手机图库标签保持单行，必要时横向滚动；完整截图可点击查看高清原图。

图库切换为 240 ms。正常状态使用视觉隐藏的 aria-live 通知；加载时图片区显示当前目标及“加载中”，失败提示可见，成功或返回当前截图后收起。预加载、解码缓存、双图叠层和最后请求优先保持不变。终端命令采用横向滚动，保留命令的原始换行和完整 URL；复制继续读取原始 textContent。
