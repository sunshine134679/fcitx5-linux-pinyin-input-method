# ModernIME 官方网站

公开地址：<https://sunshine134679.github.io/fcitx5-linux-pinyin-input-method/>

网站使用原生 HTML、CSS、JavaScript，没有 npm 构建步骤、外部字体或新增输入法运行依赖。

## 本地预览与验证

```bash
python3 -m http.server 4173 --directory website
python3 tests/website/website_test.py
node tests/website/app_test.js
```

访问 `http://localhost:4173`。下载区从 GitHub Releases 只读查询最新正式发布；断网、超时或限流时，回退到已核验的 v0.1.11 资产。新增发行版或变更资产命名时，应同步调整 `app.js` 的兼容规则和页面说明。复制按钮在权限不足时会选中命令，供手动复制。

## 发布与软件源共存

`website.yml` 在官网相关代码推送到 `main` 时运行：读取既有 `gh-pages` 分支，通过 `scripts/prepare_website.py` 覆盖首页文件和 `assets/`，完整保留 `/apt`、`/rpm` 的路径和内容，再部署并保存回 `gh-pages`。脚本校验覆盖前后全部软件源文件的 SHA256，不会重新签名或生成软件源。

`release.yml` 也会取 `main` 上的官网覆盖到发布产物，因此重新发布旧产品标签也会保留官网。两个发布任务共用 `modernime-github-pages` 串行组，避免并发覆盖软件源历史。

客户端截图是当前源码的界面示例，不承诺已发布的安装包包含源码之后的所有界面更新。网页候选栏是明确标注的交互示意，不收集键盘输入，不模拟真实输入法转换。

## 视觉与动效维护

首屏采用大字排版与流线图形，三种输入场景支持一次性打字演示。滚动入场使用 IntersectionObserver，元素出现后取消观察；阅读进度通过被动 scroll 监听与单帧合并更新，页面没有持续运行的动画循环。系统减少动态效果偏好会关闭入场、打字、截图切换动效，偏好在页面打开后改变也会生效；浏览器不支持观察器时保持全文可见。

客户端展示源于真实 GTK3 客户端的 3× PNG（2940 × 2160 px），配合 GTK 设备缩放导出字体与图标；素材来自隔离的示例数据目录，不读取个人词典和剪贴板内容。同一份高清 PNG 导出 1×（980 × 720）与 3× 无损 WebP，使用 `srcset` / `sizes` 让浏览器选择合适分辨率；三张 1× 图合计约 306 KB，3× WebP 合计约 631 KB。不要把内容不同的旧版 1× PNG 混入这组响应式图片。展示宽度最多 980 CSS px，点击图片仍查看 3× PNG 原图。替换时同步图片尺寸、`data-src`、`data-srcset`、`data-original` 与首张图的 `srcset`；测试检查尺寸、候选源、原图和内容差异。

图库由独立的 `gallery.js` 初始化，不依赖下载查询或首屏动画。距视口 400 px 内提前加载并解码三张图，悬停与键盘聚焦也会预加载；节省流量模式关闭自动预加载。解码结果按路径、显示宽度和设备像素比缓存，切回已准备的图片无需再创建加载请求。图片解码成功后同步当前图、原图链接、说明和选中标签，前后两层以 240 ms 交叉淡入；减少动态效果时立即切换。准备阶段标签显示进度，失败或 12 秒超时保留原图并支持重试。快速连续选择时只接受最后一次请求的结果。

下载卡片采用原生单选框平铺系统版本，支持键盘方向键切换，避免原生下拉弹层遮挡下载操作。Ubuntu 24.04 使用 Noble 包，Ubuntu 22.04 / Debian 12 使用 Jammy 包；对应 APT 软件源分别为 Noble、Jammy、Bookworm。选项和下载链接继续与正式发布同步。软件源入口优先，直接安装包入口保留为次按钮。`install.js` 独立负责系统源配置、分步命令复制和导航折叠；JS 失效时仍可手动展开原生 details 并复制默认系统命令。复制失败会选中完整命令。软件源客户端配置沿用 `/apt/client/*.sources` 与 `/rpm/client/*.repo`，不绕过 Signed-By、gpgcheck 或 repo_gpgcheck。

紧凑场景模块并入“输入体验”，提供聊天、写作、剪贴板三种可切换的静态网页示意，以及六类常用场景的词汇展示。场景最小高度由 530 px 降至 330 px，去掉与前面候选演示重复的候选栏。示意无需网络请求，三个场景共用一个网格位置，隐藏场景保留尺寸，以最高内容确定高度，避免切换及文字缩放导致跳动；不读取用户剪贴板、不收集键盘输入。网站仍为无构建依赖的原生页面，发布时保持签名软件源不变。

发布脚本自动在脚本与样式 URL 中加入文件内容 SHA256 的前 12 位。内容更新会改变 URL，防止旧缓存脚本与新 HTML 混用；本地预览仍直接使用源码文件。新增脚本时同时维护发布脚本 FILES 与 website.yml 的持久化清单。

排版使用宋体展示标题与无衬线正文形成变化：首屏标题 36–58 px、章节标题 29–38 px、正文 15–16 px，辅助信息至少 13 px。正文默认 500 字重，标题与关键操作加强粗细，字体采用系统字体，无远程字体请求。候选栏示意的数字标记单独按栏宽缩放。

## 导航、搜索与分享

手机顶部使用原生 `details` 四项菜单（体验／设置／安装／GitHub），选择后收起，Escape 收起并返回菜单焦点。安装区旁保留三步启用提示与完整运行配置链接。页面提供 canonical、Open Graph 图片、Twitter Card 与 SoftwareApplication JSON-LD；更新产品版本时同步结构化数据和静态下载回退。`sitemap.xml` 列出官网首页，`robots.txt` 随站发布；GitHub Pages 项目子路径下的 robots 文件不会替代域名根路径的爬虫规则。

CSS 按 tokens → base → components → sections → responsive → motion 组织，响应式规则集中在五个断点，避免在尾部追加整套覆盖样式。清理前后已做静态级联对照，再按当前新组件维护。

实机输入视频尚未提供，不用网页动画代替录屏。后续录制 10–20 秒实际桌面操作后，再添加视频，并标注发行版、显示协议和实际软件版本。当前会话没有可连接浏览器，不能宣称已完成逐屏视觉验收；代码及安装验证与该限制分别记录。

## 图标与窄屏交互

官网导航和 favicon 使用 `config/icons/` 中同源的用户 MI 图标，分别为 128 px 和 32 px PNG；不下载完整源图作为小图标。桌面按钮的布局规则只处理箭头，不覆盖移动文案的隐藏状态。

手机首屏只显示一句定位、三个核心能力和主要下载安装按钮，保留输入演示；桌面首屏上下 80 px，演示卡偏移 24 px。≤360 px 顶栏保留品牌文字、图形菜单和安装入口；菜单摘要保持可访问名称、44 px 操作尺寸，并支持点外部关闭。手机图库标签保持单行，必要时横向滚动；完整截图可点击查看高清原图。

图库切换为 240 ms。正常状态使用视觉隐藏的 aria-live 通知；加载时图片区显示当前目标及“加载中”，失败提示可见，成功或返回当前截图后收起。预加载、解码缓存、双图叠层和最后请求优先保持不变。终端命令采用横向滚动，保留命令的原始换行和完整 URL；复制继续读取原始 textContent。
