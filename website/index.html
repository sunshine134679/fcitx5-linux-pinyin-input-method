Ubuntu 24.04 LTS

Noble · amd64 / x86_64 · 签名 APT 软件源

下载 .deb ↓

首次安装可按下方三步配置软件源，后续直接通过 APT 更新。

首次安装：配置 APT 软件源按顺序完成三步，后续由系统管理更新＋
01

准备独立签名密钥

sudo apt update && sudo apt install -y curl ca-certificates &&
curl -fsSL https://sunshine134679.github.io/fcitx5-linux-pinyin-input-method/apt/modernime-archive-keyring.gpg -o modernime-archive-keyring.gpg &&
sudo install -D -m 0644 modernime-archive-keyring.gpg /usr/share/keyrings/modernime-archive-keyring.gpg
02

添加 Noble 软件源

curl -fsSL https://sunshine134679.github.io/fcitx5-linux-pinyin-input-method/apt/client/modernime-noble.sources -o modernime.sources &&
sudo install -D -m 0644 modernime.sources /etc/apt/sources.list.d/modernime.sources
03

刷新软件源并安装

sudo apt update && sudo apt install modernime

已下载安装包？sudo apt install ./modernime*.deb

更新：sudo apt update && sudo apt install --only-upgrade modernime

openEuler 24.09

x86_64 · 需 EPOL 扩展源与 Fcitx5 ≥ 5.0.14

下载 .rpm ↓

使用 DNF 管理安装与更新。24.03 SP4 请先查看依赖源兼容说明。

首次安装：配置 DNF 软件源启用 EPOL，保留包体与仓库索引签名校验＋
01

准备工具并启用 EPOL

sudo dnf install -y curl dnf-plugins-core &&
sudo dnf config-manager --set-enabled EPOL
02

添加签名软件源

curl -fsSL https://sunshine134679.github.io/fcitx5-linux-pinyin-input-method/rpm/client/modernime-openeuler-24.09.repo -o modernime.repo &&
sudo install -D -m 0644 modernime.repo /etc/yum.repos.d/modernime-openeuler-24.09.repo
03

刷新软件源并安装

sudo dnf makecache && sudo dnf install modernime

更新：sudo dnf upgrade modernime

还有几个小问题。

词典和学习数据保存在哪里？＋

保存在本机，可在设置客户端管理。更新和迁移会备份校验学习数据；操作前仍建议保留重要数据。

其他发行版和 ARM64 能用吗？＋

预编译包面向上方列出的 x86_64 系统。ARM64、Fedora 等环境请按文档准备依赖，从源码构建，并以目标环境的构建结果为准。
