安装与启用

我的 Linux 系统可以用吗？

签名 APT 源面向 Ubuntu 24.04 LTS amd64；DNF 源面向 openEuler 24.09 x86_64。其他系统或 ARM64 等架构，请先按文档准备依赖并从源码构建，不代表所有发行版都已完成验证。

openEuler 24.03 LTS-SP4 需额外配置限定范围的 24.09 EPOL 依赖源。Ubuntu 22.04 与 Debian 12 已停止提供预编译包。

选择安装方式兼容范围与 EPOL 配置
已经装好，怎样开始输入中文？

ModernIME 是 Fcitx5 的输入法组件。打开 Fcitx5 配置，添加 ModernIME，再切换到它；然后在输入框中输入 nihao，用空格选词。

在应用菜单搜索「ModernIME」可打开独立设置客户端。若输入法尚未出现，在当前用户的桌面终端执行：

modernime-session-init

若提示文件已安装但初始化未完成，先修复提示中的问题，再运行这条命令；无需重复安装。自定义安装路径时沿用原来的环境设置。

启动与会话检查
已经在用了，怎样更新？

在设置客户端搜索「检查更新」。发现新版后按提示下载，校验完成后点击「重启并更新」；有未保存设置时，先处理草稿。

更新沿用当前安装渠道。APT 和 DNF 用户也可通过原软件源更新；源码用户在原仓库更新后重新安装，便携用户使用新版归档。系统包安装阶段仍可能需要系统授权。

查看更新命令更新说明
原来用源码安装，可以改用 APT 或 DNF 吗？

可以，但需要先迁移渠道，不能直接跨渠道覆盖。在终端执行 modernime-migrate-channel --check 检查当前来源，再按文档配置软件源并迁移。

迁移会先备份并校验数据。失败时回退程序，保留期间的新学习、词典和设置，不自动恢复旧数据。

日常输入

支持全拼、双拼和模糊音吗？

支持全拼、简拼、小鹤双拼与自然码双拼。在客户端搜索「拼音方案」选择习惯的方式，个人词典和完整拼音学习记录可继续使用。

模糊音可单独调整 z/zh、c/ch、s/sh、l/n、en/eng、in/ing 六组。选好后点击「保存设置」。

输入辅助说明
只有某个应用不能输入，先检查哪里？

先确认已切换到 ModernIME，并把光标放入可编辑的输入框。再打开设置客户端的「维护」，查看运行状态和应用兼容诊断；旧版客户端对应「系统与诊断」。

Wayland 下的应用、桌面面板和 X11 使用不同链路，浏览器或 Qt 应用可能还需要相应配置。按当前应用与桌面类型查看文档中的步骤。

候选与外观

怎样调整字号、颜色和候选栏？

进入客户端「候选与外观」，边看预览边选择配色、轮廓、字号和间距，最后点击「保存设置」。自绘候选栏会自动应用，无需为了改颜色重启输入法。

设置窗口的「界面主题」与「候选栏配色」相互独立。网站预览便于挑选搭配，实际效果还会受到字体与桌面环境影响。

试试外观搭配
为什么 Wayland 中的候选栏和网站预览不同？

X11 使用 ModernIME 自绘候选栏；Wayland 由 Fcitx5 连接应用或桌面提供的候选面板，因此外观会随桌面与应用而不同。

GNOME 原生面板需要项目提供的 ModernIME Input Panel 扩展。在客户端「候选与外观」打开 GNOME 面板设置，可调整该面板的字体、配色、轮廓和间距。

首次安装或更新扩展后可能需要重新登录，再运行 modernime-session-init。若仍未出现，在「维护」或旧版「系统与诊断」查看面板状态；请勿在 Wayland 下强制使用 X11 自绘面板。

Wayland 与会话说明
网站选好的外观，怎样带回客户端？

最简单的方式是在「候选与外观」选择相同的配色、轮廓和间距，再保存。

也可从外观体验页复制或下载配置片段，只将片段中的设置合并到现有 settings.conf；不要用片段替换整个配置文件，以免丢失其他设置。

学习与数据

输入的文字会发送到云端吗？

拼音解码、个人词典和用户学习在本地完成，不依赖云端输入服务。上下文学习可以关闭，敏感输入场景会停用相关学习。

安装、检查更新和升级会连接相应软件源，与日常输入和学习分开。设置客户端可管理学习开关和本地记录。

功能与数据说明
怎样添加常用词、人名或快捷短语？

在客户端「我的词语」中打开个人词典，添加词条并确认拼音。人名或多音字可以手动修改读音；保存后，运行中的输入法会自动读取。

常用的整段文字可以保存为快捷短语，用缩写调出。默认按 Super + ; 进入快速输入，再输入缩写；需要启用 Fcitx5 的 Quick Phrase 插件，自定义快捷键以你的配置为准。

个人词典与快捷短语
选错过的词，可以让输入法忘记吗？

在客户端搜索「学习记录」，按词语或拼音找到记录后管理偏好。当前客户端可逐词忘记或解除屏蔽，也可以在「我的词语」中维护自己的词条。

想重新开始时可清空学习记录。清空前会自动备份并校验；备份失败会保留原记录。页面会显示结果与备份位置。

学习记录与词典管理
剪贴板历史怎样搜索、收藏和清理？

打开客户端「剪贴板」，搜索需要的文字或只查看收藏。输入时也可用默认的 v 后按 2 打开剪贴板菜单，按 Ctrl + F 搜索。

复制会保留完整内容；删除与清空前会要求确认。历史和收藏分开管理，清空历史不会清空收藏；数据备份默认不包含剪贴板。

剪贴板与收藏说明
换电脑或整理数据前，怎样备份？

在当前客户端搜索「创建数据备份」，选择设置、词典和学习数据，保存到本地文件夹。恢复前可以比较差异并选择要恢复的内容；先处理尚未保存的草稿。

备份默认不含剪贴板。剪贴板历史与收藏独立保存，清空历史会保留收藏。需要迁移或清理时，请分别检查它们。

旧版客户端没有这个入口时，可先使用个人词典的导出功能，并按文档中的安装与数据说明处理。
