# ModernIME 官网开发说明

## 本地运行

在仓库根目录执行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory website
```

打开 <http://localhost:4173>，实时外观体验位于 <http://localhost:4173/#experience>。这是无需安装依赖、无需构建的 HTML / CSS / JavaScript 静态站点。直接打开 `index.html` 也可浏览；HTTP 预览更适合验证资源与复制功能。

## 设计与文件

本轮从零设计，以「让表达，自然发生」为主线：输入纸面 → 实时外观体验 → 本地词典与学习 → 真实客户端 → 平台安装 → 常见问题。

- 色彩：纸白与墨蓝作为页面底色；雾紫作为默认体验配色与客户端展示主题。体验区随所选配色切换。
- 字体：界面采用系统 Noto Sans CJK SC / 苹方 / 微软雅黑，纸面用 Noto Serif CJK SC / 宋体；无需外部字体请求。
- 排版：桌面首屏左侧文案、右侧输入纸面，手机纵向排列。体验区在桌面并排展示试写与设置，手机上下排列。
- 动画：首屏按标题、拼音、候选、落字编排开场；选词移入纸面，换色整套揭开，候选翻页、截图切换、弹窗与折叠内容连续过渡。滚动时首屏纸面与键帽以不同速度移动，体验区逐渐就位，客户端截图从轻微倾斜过渡到原始比例和角度，顶部细线显示阅读进度。手机降低运动幅度，交互区域获得焦点后保持稳定；首屏纸面在鼠标操作时轻微倾斜。保留浏览器原生滚动，无无限循环或强制滚屏；尊重 `prefers-reduced-motion`，设置在页面打开期间改变也会停止动画。
- `index.html`：语义结构、产品说明与外链。
- `styles.css`：响应式布局、视觉、焦点及减少动画模式。
- `app.js`：首屏选词示意、键盘标签页、高清截图弹窗、导航与安装命令复制。
- `studio.js`：九套候选配色、三种轮廓、字号、间距、栏宽、样例分页、试写与配置导出。
- `interactions.js`：原生 Web Animations 动效层与原生滚动驱动的景深控制，按滚动事件更新，不延迟输入和配置生效；主题过渡用不可交互的临时视图保留原配色，结束后移除，不保存试写内容。
- `assets/`：产品原有图标、雾紫主题的真实客户端截图。

## 产品依据与交互边界

产品核对基线为 `bcfea9f`，本机 `/home/wsl/.local/bin/modernime-settings --version` 输出 `0.2.0`。文案依据当前 `README.md`、`tools/settings/page_registry.cpp` 及实际客户端。截图版本仅代表所展示的本机版本，不声称为远程最新版本。

外观体验的九套候选配色取自 `ui/fcitx5/src/candidate_bar_renderer.cpp`，单字、双字与混合词组样例取自 `tools/settings/pages/candidates_page.cpp`。网页通过 DOM 实时绘制和测量候选，按可用空间分页；浏览器排版是外观示意，不承诺与原生绘制的像素和分页容量完全一致。

试写区使用访问者的系统输入法。样例候选可用鼠标、方向键、数字键或空格插入，支持前后翻页；这些操作只在样例候选区生效。网页没有加载原生拼音引擎，也不执行在线学习。试写文字只保存在当前页面内存，不上传、不持久保存；浏览器 `localStorage` 仅记住外观选项。重置外观保留试写文字。

复制与下载输出实际 `candidate.*` 配置片段，不自动修改本机配置。页面说明可在客户端手动选择同样设置，或仅将片段中的键合并到既有 `settings.conf`，不可覆盖整个文件。

安装入口保持现有 APT / DNF 地址、签名校验与平台范围，下载链接指向 GitHub Releases。源码安装要求先准备文档中列出的系统依赖。网站不自动下载、安装或执行命令。

官网重建阶段仅修改网站及说明，未改动客户端、算法、安装器和软件源内容。2026-11-09 用户随后授权推送并上线；发布整合以最新 main 为基线，保留其他任务的未提交修改。

## 高清截图维护

三张截图在 2026-11-09 使用本机已安装客户端、独立 DBus 会话和临时 XDG 目录采集，未使用日常词库或剪贴板。设置窗口和候选配色均为雾紫。

采集时使用临时 Xephyr 显示和 `GDK_SCALE=3`，让客户端原生渲染出 **2940×2160** 像素；没有把低分辨率图片放大。保留原始 PNG，页面采用像素一致的无损 WebP。截图弹窗提供原始 PNG 链接，方便查看细节。页面按布局缩小显示，图片文件仍保留完整分辨率。

## 官网发布

官网沿用 GitHub Pages 地址。`.github/workflows/website.yml` 在 main 更新时检查部署归属，与软件发行共用 `modernime-pages-sync` 并发锁；`scripts/prepare_website.py` 仅覆盖官网资源，并逐文件核对 APT / RPM 软件源摘要不变。CSS 与 JavaScript 链接附加内容摘要，避免更新时混用旧脚本。软件发行工作流仍从 main 获取当前官网，避免后续发版覆盖首页。

部署前运行 `python3 tests/website/website_test.py` 和三个 JavaScript 文件的 `node --check`；部署后核对公网页面、关键交互、下载入口和软件源元数据。不因纯官网上线重建或重发客户端安装包。
