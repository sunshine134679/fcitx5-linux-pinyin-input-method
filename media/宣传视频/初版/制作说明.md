# ModernIME 宣传片：下一句，由你开始

## 设计与交付

用户已选择「代码动画结合真实客户端素材」方向，并要求高画质、高流畅度、动画富有创意。成片 40 秒，16:9，原生 3840×2160、60 fps；另导出便于分享的 1080p 版本。音乐、按键与转场声音均程序合成，不依赖外部音乐素材。

核心视觉是有生命感的输入光标：聚拢拼音、选中汉字、拉开客户端，最后收束到品牌。主题切换用圆形揭示和空间衔接，候选栏配色形成独立的文字色带。动画采用不同的加减速、轻微超调和错峰，不把每幕做成统一的淡入幻灯片。

底色为纸白 `#FAF9FE`、雾紫白 `#F0EBFA`，正文墨紫 `#29223B`，主强调雾紫 `#7854B4`；品牌蓝沿用现有图标。字体为 Noto Sans CJK SC 与 Noto Sans，候选字采用真实客户端字号比例。所有图形与字幕按 4K 渲染，截图为 2940×2160 原生采集，主体展示不超过其原始像素宽度。

## 重现

`film.cjs` 是逐帧确定性绘图和编码入口，`soundtrack.py` 合成 48 kHz 立体声配乐，`render.sh` 顺序执行。依赖 Node.js、skia-canvas 3.0.8、Python + NumPy、FFmpeg（libx264/AAC）。这些仅用于媒体制作，不属于客户端运行或安装依赖。

通过 `SKIA_CANVAS_MODULE`、`FILM_PYTHON`、`FFMPEG` 指定本机工具位置；默认渲染 4K 60 帧。`node film.cjs --stills` 导出分镜；`node film.cjs --width 1920 --fps 30 --draft` 可生成快速预览。完整运行命令见 `render.sh`。输出放在 `output/`，未自动推送大型视频到 Git。

打开 `预览.html` 可播放成片、切换 4K / 1080p 画质和跳转六个章节。图标使用仓库现有 512px 源文件；九张原生界面截图及二维码已保存在 `assets/`，重渲染不需要重新采集客户端。素材来源和哈希见 `assets/素材来源.json`。

一般环境安装本目录的 Node 依赖、NumPy 和带 libx264 的 FFmpeg 后执行 `npm run render`。本机已有工具可直接复用：

```bash
SKIA_CANVAS_MODULE=/home/wsl/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/@oai/artifact-tool/node_modules/skia-canvas \
FILM_PYTHON=/home/wsl/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python \
FFMPEG=/tmp/modernime-video-deps/imageio_ffmpeg/binaries/ffmpeg-linux-x86_64-v7.0.2 \
bash render.sh
```

临时目录中的 FFmpeg 可在目录清理后以系统 FFmpeg 替换。影片采用逐帧绘图；60 fps 时间轴不依赖桌面录屏速度或补帧。
