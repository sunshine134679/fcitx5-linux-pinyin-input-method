# ModernIME 宣传片：下一句，更像你

当前交付为第五版「灵动版」：65.15 秒，3909 帧，原生 3840×2160 / 60 fps，另提供 1080p / 60 fps 分享版。按用户要求，工作区的各版导出、临时音轨、分镜图片和渲染日志已清理；最终 4K 成片保存在 `/home/wsl/Videos/ModernIME-灵动版-4K-60fps.mp4`。制作源码与原始素材保留。此次只修改宣传视频制作工程，未修改客户端、官网或软件源，未推送或发布。

## 设计与节奏

- 开头移除大输入面板，拼音、紧凑候选栏与逐字上屏直接发生在画面上。汉字重排为手写标题，沿弧线衔接下一镜头。键盘保持水平，敲击、空格与标点有轻微同步音效。
- 学习段以两句常用表达和紧凑候选行表现重复选择，替换四张巨大字卡。通过文字路径引出上下文，演示「我们去公 + yuan → 园」及「气球 + chongqi → 充气」。
- 原有七套主题、外观设置、个人词典、学习开关、英文补全、金额转换和双拼界面镜头保持节奏。
- 片尾使用紫色底与浅色书写字，只保留一个 GitHub 地址；主信息展开约 1.45 秒后稳定，1.9 秒后开始绘制环线，随后出现游动标点与小光点，地址始终静止。
- 主色雾紫 `#7451AE`、纸白 `#F4EFFB`、墨紫 `#29233B`；上下文青竹绿 `#087F63`，片尾紫 `#68469C`。Noto Serif CJK SC 承担放大的输入文字，AR PL UKai CN 用于手写标题，Noto Sans CJK SC 用于说明。

## 文件与复现

重新渲染后，成片会生成在 `output/v5/`，届时打开 `灵动版预览.html` 可切换画质、跳转十二个章节和下载。当前工作区的导出目录已清理。

- `film-v5.cjs`：开头、学习和片尾三个原生 4K 逐帧片段。
- `timing-v5.json`、`soundtrack-v5.py`：统一时序及音乐与键声。
- `edit-v5.py`：复用第四版原生界面片段，按准确帧边界提取其他功能镜头并合成。
- `render-v5.sh`：串行处理，默认 Skia 两个线程、FFmpeg 三个线程。
- `output/v5/交付核验.json`：最终编码及解码核验结果。

制作依赖 Node.js、skia-canvas 3.0.8、Python + NumPy、FFmpeg（libx264 / AAC）及上述字体，不是客户端安装依赖。原始 MP3 和视频输出已忽略。第五版渲染需使用 `output/v4/` 的 `native-2160p.mp4`、`learning-2160p.mp4`、`schemes-2160p.mp4`；缺少时先运行 `render-v4.sh`，其依赖第二版原片。

```bash
npm install
npm run render
```

本机可复用已安装工具：

```bash
SKIA_CANVAS_MODULE=/home/wsl/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/@oai/artifact-tool/node_modules/skia-canvas \
FILM_PYTHON=/home/wsl/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python \
FFMPEG=/home/wsl/.cache/uv/archive-v0/J9PogZR9dvFQLkH6/imageio_ffmpeg/binaries/ffmpeg-linux-x86_64-v7.0.2 \
bash render-v5.sh
```

`npm run stills` 导出新增段落关键帧；`npm run poster` 导出封面；`--segment opening|learning|ending` 可单独重渲染。核验仅覆盖本次媒体产物与播放页，不涉及客户端构建及发布验收。
